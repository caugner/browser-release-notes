# Firefox 30 release notes for developers

Firefox 30 was released on [June 10th, 2014](https://whattrainisitnow.com/release/?version=30 "External link (opens in new tab)"). This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   A Box Model Highlighter has been implemented ([Firefox bug 663778](https://bugzil.la/663778 "External link (opens in new tab)")).
*   Anywhere a DOM node appears in the console output, it is highlighted when you hover over that console output ([Firefox bug 757866](https://bugzil.la/757866 "External link (opens in new tab)")). Similarly all JS functions and objects are highlighted in the console output ([Firefox bug 584733](https://bugzil.la/584733 "External link (opens in new tab)")). More information about the console improvement can be found in this [blog post](https://web.archive.org/web/20150427210606/http://mihai.sucan.ro/mihai/blog/web-console-improvements-episode-30 "External link (opens in new tab)").
*   Support for [`console.count()`](/en-US/docs/Web/API/console/count_static "console.count()") has been added ([Firefox bug 922208](https://bugzil.la/922208 "External link (opens in new tab)")).

### [CSS](#css)

*   The property [`background-blend-mode`](/en-US/docs/Web/CSS/Reference/Properties/background-blend-mode) has been enabled by default ([Firefox bug 970600](https://bugzil.la/970600 "External link (opens in new tab)")).
*   The non-standard `overflow-clip-box` property has been implemented for use in UA stylesheets only ([Firefox bug 966992](https://bugzil.la/966992 "External link (opens in new tab)")).
*   The [`line-height`](/en-US/docs/Web/CSS/Reference/Properties/line-height) property now affects single-line text inputs (`<input type=text|password|email|search|tel|url|unknown>` types) although it cannot shrink them below a line height of `1.0` ([Firefox bug 349259](https://bugzil.la/349259 "External link (opens in new tab)")).
*   The [`line-height`](/en-US/docs/Web/CSS/Reference/Properties/line-height) property now also affects `type=button`, with no restrictions ([Firefox bug 697451](https://bugzil.la/697451 "External link (opens in new tab)")).
*   Change to keyframes' name does not affect current elements ([Firefox bug 978648](https://bugzil.la/978648 "External link (opens in new tab)")).
*   positioned internal table elements not abs pos containing block(relative position for table rows) ([Firefox bug 63895](https://bugzil.la/63895 "External link (opens in new tab)")).

### [HTML](#html)

_No change._

### [JavaScript](#javascript)

*   New ES2015-compatible [array comprehensions](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features) `[for (item of iterable) item]` and [generator comprehensions](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features) `(for (item of iterable) item)` have been implemented ([Firefox bug 979865](https://bugzil.la/979865 "External link (opens in new tab)")).
*   [Typed arrays](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray#property_access) are now extensible and support new named properties ([Firefox bug 695438](https://bugzil.la/695438 "External link (opens in new tab)")).
*   The [`Error.prototype.stack`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/stack) property now contains column numbers ([Firefox bug 762556](https://bugzil.la/762556 "External link (opens in new tab)")) and has been improved [when using `Function()` and `eval()` calls](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/stack#description). This can help you to better debug minified or generated JavaScript code.
*   The `Promise.cast()` method has been renamed to [`Promise.resolve()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/resolve) ([Firefox bug 966348](https://bugzil.la/966348 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   [`Navigator.sendBeacon`](/en-US/docs/Web/API/Navigator/sendBeacon) has been implemented, easing telemetry collection ([Firefox bug 936340](https://bugzil.la/936340 "External link (opens in new tab)")).
*   Added a `relList` property returning a [`DOMTokenList`](/en-US/docs/Web/API/DOMTokenList) to [`HTMLLinkElement`](/en-US/docs/Web/API/HTMLLinkElement), [`HTMLAreaElement`](/en-US/docs/Web/API/HTMLAreaElement) and [`HTMLAnchorElement`](/en-US/docs/Web/API/HTMLAnchorElement) ([Firefox bug 968637](https://bugzil.la/968637 "External link (opens in new tab)")).
*   As per the latest specification, the first argument of [`AudioScheduledSourceNode.start`](/en-US/docs/Web/API/AudioScheduledSourceNode/start) and [`AudioScheduledSourceNode.stop`](/en-US/docs/Web/API/AudioScheduledSourceNode/stop) is now optional and defaults to `0` ([Firefox bug 982541](https://bugzil.la/982541 "External link (opens in new tab)")).
*   The method `Navigator.requestWakeLock()` and the non-standard `MozWakeLock` are no longer available from the Web on Desktop ([Firefox bug 963366](https://bugzil.la/963366 "External link (opens in new tab)")).
*   The `DOM_VK_ENTER` constant has been removed from [`KeyboardEvent`](/en-US/docs/Web/API/KeyboardEvent) ([Firefox bug 969247](https://bugzil.la/969247 "External link (opens in new tab)")).
*   Web components' `Document.register()` has been adapted to follow the behavior described in the latest version of the specification ([Firefox bug 856140](https://bugzil.la/856140 "External link (opens in new tab)")).
*   The non-standard, and deprecated since Firefox 15, `Blob.mozSlice` is no longer supported ([Firefox bug 961804](https://bugzil.la/961804 "External link (opens in new tab)")).
*   The non-standard `ArchiveReader` and `ArchiveRequest` are no longer exposed to the Web ([Firefox bug 968883](https://bugzil.la/968883 "External link (opens in new tab)")).
*   [WebIDL constructors](https://searchfox.org/firefox-main/source/dom/webidl/ "External link (opens in new tab)") cannot be called as functions anymore. They need to be preceded by the keyword `new`. ([Firefox bug 916644](https://bugzil.la/916644 "External link (opens in new tab)"))
*   Added support for a new value (`alpha`) for the second, optional, parameter of the [`HTMLCanvasElement.getContext()`](/en-US/docs/Web/API/HTMLCanvasElement/getContext) method allowing you to define if alpha blending must be stored or not for this context. When not, the per-pixel alpha value in this store is always `1.0`. This allows the back-end to implement a fast-track. ([Firefox bug 982480](https://bugzil.la/982480 "External link (opens in new tab)"))
*   `WorkerGlobalScope.console` now returns for the regular [`console`](/en-US/docs/Web/API/console); `WorkerConsole` has been removed ([Firefox bug 965860](https://bugzil.la/965860 "External link (opens in new tab)")).
*   The [`WEBGL_debug_shaders`](/en-US/docs/Web/API/WEBGL_debug_shaders) WebGL extension has been implemented ([Firefox bug 968374](https://bugzil.la/968374 "External link (opens in new tab)")).

### [MathML](#mathml)

_No change._

### [SVG](#svg)

*   [`<feDropShadow>`](/en-US/docs/Web/SVG/Reference/Element/feDropShadow), and its interface [`SVGFEDropShadowElement`](/en-US/docs/Web/API/SVGFEDropShadowElement), from the Filter Effects Module are now supported ([Firefox bug 964200](https://bugzil.la/964200 "External link (opens in new tab)")).

### [Audio/Video](#audiovideo)

*   On Linux, GStreamer 1.0 is now supported (instead of 0.10) ([Firefox bug 806917](https://bugzil.la/806917 "External link (opens in new tab)")).

## [Security](#security)

*   `<form autocomplete="off">` no longer prevents passwords from being saved. See [Managing autofill for login fields](/en-US/docs/Web/Security/Practical_implementation_guides/Turning_off_form_autocompletion#managing_autofill_for_login_fields) for more information. ([Firefox bug 956906](https://bugzil.la/956906 "External link (opens in new tab)")).

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

*   The interface `nsIDOMWindowUtils` now supports the Boolean attribute `audioMuted` and `audioVolume`, a float in the range `[0.0 , 1.0]`, allowing you to control the sound produced by a window (that is any tab or iframe). There is no UI for this, but is available to add-ons. ([Firefox bug 923247](https://bugzil.la/923247 "External link (opens in new tab)"))
