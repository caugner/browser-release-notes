# Firefox 88 release notes for developers

This article provides information about the changes in Firefox 88 that will affect developers. Firefox 88 was released on April 19, 2021.

**Note:** See also [Never too late for Firefox 88](https://hacks.mozilla.org/2021/04/never-too-late-for-firefox-88/ "External link (opens in new tab)") on Mozilla Hacks.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   The toggle button for switching between raw and formatted response views has been implemented ([Firefox bug 1693147](https://bugzil.la/1693147 "External link (opens in new tab)")). For examples, see [Network request details > Response tab](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_details/index.html#response-tab "External link (opens in new tab)").

### [HTML](#html)

_No changes._

### [CSS](#css)

*   The [`:user-valid`](/en-US/docs/Web/CSS/Reference/Selectors/:user-valid) and [`:user-invalid`](/en-US/docs/Web/CSS/Reference/Selectors/:user-invalid) pseudo-classes have been implemented ([Firefox bug 1694141](https://bugzil.la/1694141 "External link (opens in new tab)")).
*   The [`image-set()`](/en-US/docs/Web/CSS/Reference/Values/image/image-set) functional notation is now enabled ([Firefox bug 1698133](https://bugzil.la/1698133 "External link (opens in new tab)")), and was made available for [`content`](/en-US/docs/Web/CSS/Reference/Properties/content) and [`cursor`](/en-US/docs/Web/CSS/Reference/Properties/cursor) in [Firefox bug 1695402](https://bugzil.la/1695402 "External link (opens in new tab)") and [Firefox bug 1695403](https://bugzil.la/1695403 "External link (opens in new tab)").
*   The default `monospace` font for macOS has been changed to Menlo ([Firefox bug 1342741](https://bugzil.la/1342741 "External link (opens in new tab)")).
*   The `collapse` value of [`visibility`](/en-US/docs/Web/CSS/Reference/Properties/visibility) is now implemented for ruby annotations ([Firefox bug 1697529](https://bugzil.la/1697529 "External link (opens in new tab)")).
*   The `alternate` value for [`ruby-position`](/en-US/docs/Web/CSS/Reference/Properties/ruby-position) has been implemented, and is the new initial value for the property ([Firefox bug 1694748](https://bugzil.la/1694748 "External link (opens in new tab)")).
*   The [`outline`](/en-US/docs/Web/CSS/Reference/Properties/outline) CSS property has been updated to follow the outline created by [`border-radius`](/en-US/docs/Web/CSS/Reference/Properties/border-radius). As part of this work the non-standard `-moz-outline-radius` property has been removed. ([Firefox bug 315209](https://bugzil.la/315209 "External link (opens in new tab)") and [Firefox bug 1694146](https://bugzil.la/1694146 "External link (opens in new tab)").)

#### Removals

*   The [`:-moz-submit-invalid`](/en-US/docs/Web/CSS/Reference/Selectors/:-moz-submit-invalid) pseudo-class has been hidden behind a preference, thereby removing it from web content ([Firefox bug 1694129](https://bugzil.la/1694129 "External link (opens in new tab)")).
*   Default styling for the non-standard `:-moz-ui-invalid` and `:-moz-ui-valid` has been removed ([Firefox bug 1693969](https://bugzil.la/1693969 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   Added support for [RegExp match indices](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/exec) ([Firefox bug 1519483](https://bugzil.la/1519483 "External link (opens in new tab)")).
*   [`Intl.DisplayNames()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DisplayNames/DisplayNames) and [`Intl.ListFormat()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/ListFormat/ListFormat) now have stricter checking that `options` passed to the constructor are [objects](/en-US/docs/Learn_web_development/Extensions/Advanced_JavaScript_objects), and will throw an exception if a string or other primitive is used instead ([Firefox bug 1696881](https://bugzil.la/1696881 "External link (opens in new tab)")).

### [HTTP](#http)

*   FTP has been disabled on all releases (preference `network.ftp.enabled` now defaults to `false`), with the intent of removing it altogether in Firefox 90 ([Firefox bug 1691890](https://bugzil.la/1691890 "External link (opens in new tab)")). Complementing this change, the extension setting [`browserSettings.ftpProtocolEnabled`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browserSettings/ftpProtocolEnabled) has been made read-only, and web extensions can now register themselves as [protocol handlers](/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/protocol_handlers) for FTP ([Firefox bug 1626365](https://bugzil.la/1626365 "External link (opens in new tab)")).

### [Security](#security)

_No changes._

### [APIs](#apis)

#### DOM

*   Code can now use the new static method [`AbortSignal.abort()`](/en-US/docs/Web/API/AbortSignal/abort_static) to return an [`AbortSignal`](/en-US/docs/Web/API/AbortSignal) that is already set as [`aborted`](/en-US/docs/Web/API/AbortSignal/aborted) ([Firefox bug 1698468](https://bugzil.la/1698468 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Marionette will no longer be enabled unless the `--marionette` command-line argument or the `MOZ_MARIONETTE` environment variable is specified. As such the `marionette.enabled` preference is no longer used. With this change the state of `navigator.webdriver` now correctly reflects the enabled state of Marionette ([Firefox bug 1593343](https://bugzil.la/1593343 "External link (opens in new tab)")).
*   Fixed a bug where pointer actions other than `down` and `up` inappropriately led to buttons being pressed ([Firefox bug 1686361](https://bugzil.la/1686361 "External link (opens in new tab)")).
*   Fixed a race condition in `WebDriver:GetCurrentURL` that could have led the command to return the URL of the previously opened page, or even a hang in Marionette ([Firefox bug 1664881](https://bugzil.la/1664881 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   `url` can now be used to limit the properties for which the [`tabs.onUpdated`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/tabs/onUpdated) event is triggered ([Firefox bug 1680279](https://bugzil.la/1680279 "External link (opens in new tab)")).
