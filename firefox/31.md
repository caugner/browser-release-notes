# Firefox 31 release notes for developers

Firefox 31 was released on July 22, 2014. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   [Eyedropper tool to select colors in web pages](https://firefox-source-docs.mozilla.org/devtools-user/eyedropper/index.html "External link (opens in new tab)")
*   [full stack traces for console error messages](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html "External link (opens in new tab)")
*   [editable Box Model View](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_the_box_model/index.html "External link (opens in new tab)")
*   [%c formatting to style console messages](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html "External link (opens in new tab)")
*   ["copy as cURL" command in Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html#copy-as-curl "External link (opens in new tab)")
*   [Sublime Text keybindings in the source editor](https://firefox-source-docs.mozilla.org/devtools-user/keyboard_shortcuts/index.html#source-editor "External link (opens in new tab)")
*   [Option to make Network Monitor logs persistent](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html#network-request-list "External link (opens in new tab)")
*   [JavaScript warnings on by default in the Web Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html#javascript-errors-and-warnings "External link (opens in new tab)")
*   [Alt+click to expand all descendants of a node](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/ui_tour/index.html#page-inspector-ui-tour-html-pane "External link (opens in new tab)")

[All devtools bugs fixed between Firefox 30 and Firefox 31](https://bugzilla.mozilla.org/buglist.cgi?resolution=FIXED&classification=Client%20Software&chfieldto=2014-04-28&chfield=resolution&query_format=advanced&chfieldfrom=2014-03-17&chfieldvalue=FIXED&bug_status=RESOLVED&bug_status=VERIFIED&component=Developer%20Tools&component=Developer%20Tools%3A%203D%20View&component=Developer%20Tools%3A%20App%20Manager&component=Developer%20Tools%3A%20Canvas%20Debugger&component=Developer%20Tools%3A%20Console&component=Developer%20Tools%3A%20Debugger&component=Developer%20Tools%3A%20Framework&component=Developer%20Tools%3A%20Graphic%20Commandline%20and%20Toolbar&component=Developer%20Tools%3A%20Inspector&component=Developer%20Tools%3A%20Memory&component=Developer%20Tools%3A%20Netmonitor&component=Developer%20Tools%3A%20Object%20Inspector&component=Developer%20Tools%3A%20Profiler&component=Developer%20Tools%3A%20Responsive%20Mode&component=Developer%20Tools%3A%20Scratchpad&component=Developer%20Tools%3A%20Source%20Editor&component=Developer%20Tools%3A%20Style%20Editor&component=Developer%20Tools%3A%20User%20Stories&component=Developer%20Tools%3A%20WebGL%20Shader%20Editor&product=Firefox&list_id=10022921 "External link (opens in new tab)").

### [CSS](#css)

*   Changed `var-` prefix of CSS Variables to `--` to reflect the final spec change ([Firefox bug 985838](https://bugzil.la/985838 "External link (opens in new tab)")).
*   The [`hyphens`](/en-US/docs/Web/CSS/Reference/Properties/hyphens) property now support Polish hyphenation rules ([Firefox bug 987668](https://bugzil.la/987668 "External link (opens in new tab)")).
*   Removed an unwanted white space for multiple of 10,000 in Korean counter styles ([Firefox bug 985186](https://bugzil.la/985186 "External link (opens in new tab)")).
*   CSS opacity transition broken with parent pseudo :before and overflow auto ([Firefox bug 990340](https://bugzil.la/990340 "External link (opens in new tab)")).
*   The `::-moz-math-stretchy` pseudo-element has been removed ([Firefox bug 1000879](https://bugzil.la/1000879 "External link (opens in new tab)")).

### [HTML](#html)

*   [`<track>`](/en-US/docs/Web/HTML/Reference/Elements/track) has been implemented ([Firefox bug 629350](https://bugzil.la/629350 "External link (opens in new tab)")).

### [JavaScript](#javascript)

New ECMAScript 2015 features implemented:

*   New `Array` built-in: [`Array.prototype.fill()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/fill) ([Firefox bug 911147](https://bugzil.la/911147 "External link (opens in new tab)"))
*   New `Math` function: [`Math.clz32()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/clz32) ([Firefox bug 925123](https://bugzil.la/925123 "External link (opens in new tab)"))
*   New `String` built-in: [`String.prototype.normalize()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/normalize) is available in Firefox Desktop ([Firefox bug 918987](https://bugzil.la/918987 "External link (opens in new tab)")).
*   New `Object` method [`Object.setPrototypeOf()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/setPrototypeOf).
*   New `Number` constants: [`Number.MAX_SAFE_INTEGER`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/MAX_SAFE_INTEGER) and [`Number.MIN_SAFE_INTEGER`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/MIN_SAFE_INTEGER).
*   The ES2015 Proxy [`isExtensible`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy/Proxy/isExtensible) trap have been implemented ([Firefox bug 978235](https://bugzil.la/978235 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   Constructor of `KeyboardEvent` has been implemented ([Firefox bug 930893](https://bugzil.la/930893 "External link (opens in new tab)")).
*   The Resource Timing API has been implemented (see [Firefox bug 822480](https://bugzil.la/822480 "External link (opens in new tab)")).
*   `KeyboardEvent.isComposing` attribute has been implemented ([Firefox bug 993234](https://bugzil.la/993234 "External link (opens in new tab)")).
*   `InputEvent` interface has been implemented ([Firefox bug 993253](https://bugzil.la/993253 "External link (opens in new tab)")).
*   `InputEvent.isComposing` attribute has been implemented ([Firefox bug 993253](https://bugzil.la/993253 "External link (opens in new tab)")).
*   [`CSS.escape()`](/en-US/docs/Web/API/CSS/escape_static "CSS.escape()") has been implemented ([Firefox bug 955860](https://bugzil.la/955860 "External link (opens in new tab)")).
*   [`mousemove`](/en-US/docs/Web/API/Element/mousemove_event "mousemove") is now cancelable like in other browsers ([Firefox bug 704423](https://bugzil.la/704423 "External link (opens in new tab)")). Calling `preventDefault()` only sets `defaultPrevented` attribute to `true;` any other behaviors are not changed. E.g., it cannot prevent to set `:hover` state.
*   The [`Path2D`](/en-US/docs/Web/API/Path2D) interface has been implemented.
*   The [`CanvasRenderingContext2D.isPointInPath()`](/en-US/docs/Web/API/CanvasRenderingContext2D/isPointInPath), [`CanvasRenderingContext2D.isPointInStroke()`](/en-US/docs/Web/API/CanvasRenderingContext2D/isPointInStroke), [`CanvasRenderingContext2D.clip()`](/en-US/docs/Web/API/CanvasRenderingContext2D/clip), [`CanvasRenderingContext2D.fill()`](/en-US/docs/Web/API/CanvasRenderingContext2D/fill) and [`CanvasRenderingContext2D.stroke()`](/en-US/docs/Web/API/CanvasRenderingContext2D/stroke) methods have been updated to optionally accept a [`Path2D`](/en-US/docs/Web/API/Path2D) object.
*   Implemented [`HTMLMediaElement.fastSeek()`](/en-US/docs/Web/API/HTMLMediaElement/fastSeek).
*   The `Connection` interface has been renamed to [`NetworkInformation`](/en-US/docs/Web/API/NetworkInformation) and has been modified to match the new specification ([Firefox bug 960426](https://bugzil.la/960426 "External link (opens in new tab)")).
*   The [`Navigator.sendBeacon()`](/en-US/docs/Web/API/Navigator/sendBeacon) has been implemented; this allows asynchronous transmission of analytics or other data in a manner that doesn't rely on the transmitting page remaining loaded, so that it can be used in an [`unload`](/en-US/docs/Web/API/Window/unload_event "unload") or [`beforeunload`](/en-US/docs/Web/API/Window/beforeunload_event "beforeunload") handler.

### [MathML](#mathml)

*   Partial implementation of the [OpenType MATH table](https://learn.microsoft.com/en-us/typography/opentype/spec/math "External link (opens in new tab)"), section 6.3.6 ([Firefox bug 407059](https://bugzil.la/407059 "External link (opens in new tab)")). For details, try the [MathML torture test](https://web.archive.org/web/20210605072117/https://developer.mozilla.org/en-US/docs/Mozilla/MathML_Project/MathML_Torture_Test "External link (opens in new tab)").
*   The `::-moz-math-stretchy` pseudo-element has been removed ([Firefox bug 1000879](https://bugzil.la/1000879 "External link (opens in new tab)")).
*   When available, the Unicode Mathematical alphanumeric characters are used for bold, italic and bold-italic math variants ([Firefox bug 930504](https://bugzil.la/930504 "External link (opens in new tab)")).

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

*   The `align` attribute on the `urlbar-wrapper` (formerly on the `urlbar-container`) which was set to `center` since time immemorial, has been removed. This is known to affect third-party themes. You should look carefully at what the right fix is for your theme, but for maintaining the equivalent effect, you can add the following CSS rule to your theme:
    
    css
    
    ```
    #urlbar-wrapper {
      -moz-box-align: center;
    }
    ```
    
*   `nsIDOMWindowUtils.sendQueryContentEvent()` and `nsIDOMWindowUtils.sendSelectionSetEvent()` have `aAdditionalFlags` as optional argument. If you called `nsIDOMWindowUtils.sendSelectionSetEvent()` with `true` for `aReverse`, the behavior would be broken by this change. See [explanation of each flag](https://web.archive.org/web/20210518041413/https://developer.mozilla.org/en-US/docs/mozilla/tech/xpcom/reference/interface/nsidomwindowutils#constants "External link (opens in new tab)") (`QUERY_CONTENT_FLAG_*` and `SELECTION_SET_FLAG_*`) for the detail of `aAdditionalFlags`.

*   Updated the default theme used for panels on Mac OS X.
*   Added [contentStyle and contentStyleFile](https://web.archive.org/web/20201201022417/https://developer.mozilla.org/en-US/docs/Archive/Add-ons/Add-on_SDK/High-Level_APIs/panel#styling_panel_content "External link (opens in new tab)") options to panel.
