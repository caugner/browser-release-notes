# Firefox 45 release notes for developers

To test the latest developer features of Firefox, install Firefox Developer Edition Firefox 45 was released on March 8, 2016. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   [Full-text search in the Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_html/index.html#searching "External link (opens in new tab)")
*   [Heap snapshot diffing in the Memory tool](https://firefox-source-docs.mozilla.org/devtools-user/memory/basic_operations/index.html#comparing-snapshots "External link (opens in new tab)")
*   [DomContentLoaded and load events shown in the Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html#timeline "External link (opens in new tab)")
*   [Animation inspector improvements](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/work_with_animations/index.html "External link (opens in new tab)")

### [HTML](#html)

*   Content Security Policy can now be set directly on the [`<meta>`](/en-US/docs/Web/HTML/Reference/Elements/meta) element ([Firefox bug 663570](https://bugzil.la/663570 "External link (opens in new tab)")).
*   The attribute `referrer` has been renamed `referrerpolicy` on [`<img>`](/en-US/docs/Web/HTML/Reference/Elements/img), [`<area>`](/en-US/docs/Web/HTML/Reference/Elements/area), [`<a>`](/en-US/docs/Web/HTML/Reference/Elements/a), and [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) ([Firefox bug 1187357](https://bugzil.la/1187357 "External link (opens in new tab)")).
*   Changes in the viewport, or a resize, now trigger the reselection of responsive images for `<img srcset>` ([Firefox bug 1166138](https://bugzil.la/1166138 "External link (opens in new tab)")).

### [CSS](#css)

*   [`word-spacing`](/en-US/docs/Web/CSS/Reference/Properties/word-spacing) now allows percentage values ([Firefox bug 1038663](https://bugzil.la/1038663 "External link (opens in new tab)")).
    
*   Our implementation of CSS Grids has been improved and is no more considered experimental; it is now activated by default in nightly and developer edition, but not for beta and release ([Firefox bug 1000592](https://bugzil.la/1000592 "External link (opens in new tab)")):
    
    *   Gutters, that is the `grid-column-gap`, `grid-row-gap`, and `grid-gap` properties are now supported ([Firefox bug 1176792](https://bugzil.la/1176792 "External link (opens in new tab)")).
    *   The implied minimum size of grid Items, that is the special [`min-width`](/en-US/docs/Web/CSS/Reference/Properties/min-width) and [`min-height`](/en-US/docs/Web/CSS/Reference/Properties/min-height) `auto` behavior has been implemented ([Firefox bug 1176775](https://bugzil.la/1176775 "External link (opens in new tab)")).
    *   [`align-self`](/en-US/docs/Web/CSS/Reference/Properties/align-self) and [`justify-self`](/en-US/docs/Web/CSS/Reference/Properties/justify-self) are now supported on grid layouts ([Firefox bug 1151213](https://bugzil.la/1151213 "External link (opens in new tab)")).
    *   [`align-content`](/en-US/docs/Web/CSS/Reference/Properties/align-content) and [`justify-content`](/en-US/docs/Web/CSS/Reference/Properties/justify-content) are now supported on grid layouts ([Firefox bug 1151214](https://bugzil.la/1151214 "External link (opens in new tab)")).
    *   Resolved value of grid-template-columns, grid-template-rows in px units ([Firefox bug 978212](https://bugzil.la/978212 "External link (opens in new tab)")).
    *   The related feature [`display`](/en-US/docs/Web/CSS/Reference/Properties/display): contents has been supported since [Firefox 37](/en-US/docs/Mozilla/Firefox/Releases/37)
*   Implement full support for CSS Box Alignment for CSS Grid, support the missing values: `start`, `end`, `self-start`, `self-end`, `left`, `right`, `last-baseline`, `space-evenly` ([Firefox bug 1176782](https://bugzil.la/1176782 "External link (opens in new tab)")). CSS Box Alignment currently applies only to CSS Flexbox and CSS Grid.
    
*   \[css-grid\]\[css-flexbox\] Implement grid/flex layout for <fieldset> ([Firefox bug 1230207](https://bugzil.la/1230207 "External link (opens in new tab)")).
    
*   The `inline-start` and `inline-end` values have been added to [`float`](/en-US/docs/Web/CSS/Reference/Properties/float) and [`clear`](/en-US/docs/Web/CSS/Reference/Properties/clear) ([Firefox bug 1122918](https://bugzil.la/1122918 "External link (opens in new tab)")). They are enabled by default on Nightly and Aurora (Dev edition), as well as on Firefox OS; to activate it on a release or beta version, you need to flip the `layout.css.float-logical-values.enabled` to `true`.
    
*   The [`text-emphasis`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis), [`text-emphasis-style`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis-style), [`text-emphasis-color`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis-color), and [`text-emphasis-position`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis-position) have been implemented; they are disabled by default (set `layout.css.text-emphasis.enabled` to true to activate them ([Firefox bug 1040668](https://bugzil.la/1040668 "External link (opens in new tab)")).
    
*   Several `-webkit` prefixed properties and values have been added for web compatibility, behind the preference `layout.css.prefixes.webkit`, defaulting to `false`:
    
    *   Added `-webkit-backface-visibility`, `-webkit-perspective` and `-webkit-perspective-origin` for web compatibility, behind the preference `layout.css.prefixes.webkit`, defaulting to `false` ([Firefox bug 1179444](https://bugzil.la/1179444 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   ES2015 [Classes](/en-US/docs/Web/JavaScript/Reference/Classes) are now enabled by default ([Firefox bug 1197932](https://bugzil.la/1197932 "External link (opens in new tab)")).
*   [Expression closures](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#statements_2) are deprecated and will now present a warning in the console ([Firefox bug 995610](https://bugzil.la/995610 "External link (opens in new tab)")).
*   [`String.prototype.replace`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/replace) does not restore [RegExp static properties](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/n) after executing function parameter anymore ([Firefox bug 1226936](https://bugzil.la/1226936 "External link (opens in new tab)")).
*   [`Math.random()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random) has been updated to the better XorShift128+ algorithm ([Firefox bug 322529](https://bugzil.la/322529 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

#### DOM & HTML DOM

*   For compatibility, the non-standard property [`Node.innerText`](/en-US/docs/Web/API/HTMLElement/innerText) has been implemented ([Firefox bug 264412](https://bugzil.la/264412 "External link (opens in new tab)")).
*   The [`HTMLImageElement.srcset`](/en-US/docs/Web/API/HTMLImageElement/srcset) attribute now reacts to resize/viewport changes ([Firefox bug 1166138](https://bugzil.la/1166138 "External link (opens in new tab)")).
*   [`Element.getAttributeNames()`](/en-US/docs/Web/API/Element/getAttributeNames) has been implemented ([Firefox bug 1228634](https://bugzil.la/1228634 "External link (opens in new tab)")).

#### WebGL

Our implementation of WebGL 2 has been extended:

*   Support of programs and shaders has been added ([Firefox bug 1048743](https://bugzil.la/1048743 "External link (opens in new tab)")).
*   Support for uniforms and attributes has been added ([Firefox bug 1048745](https://bugzil.la/1048745 "External link (opens in new tab)")).
*   Framebuffer objects have been implemented ([Firefox bug 1048732](https://bugzil.la/1048732 "External link (opens in new tab)")).
*   Renderbuffer objects have been implemented ([Firefox bug 1048733](https://bugzil.la/1048733 "External link (opens in new tab)")).

#### IndexedDB

_No change._

#### Service Workers

*   [`Clients.get()`](/en-US/docs/Web/API/Clients/get) and [`FetchEvent.clientId`](/en-US/docs/Web/API/FetchEvent/clientId) have been implemented ([Firefox bug 1222464](https://bugzil.la/1222464 "External link (opens in new tab)").)
*   [`Clients.openWindow()`](/en-US/docs/Web/API/Clients/openWindow) has been implemented ([Firefox bug 1172870](https://bugzil.la/1172870 "External link (opens in new tab)").)
*   The options object that can be passed as a parameter when invoking [`Clients.matchAll()`](/en-US/docs/Web/API/Clients/matchAll) can now include an `includeUncontrolled` property. This is a boolean value — if set to `true`, the matching operation will return all service worker clients who share the same origin as the current service worker. Otherwise, it returns only the service worker clients controlled by the current service worker. The default is `false`.

#### WebRTC

_No change._

#### New APIs

_No change._

#### Miscellaneous

*   [Web Speech Synthesis API](/en-US/docs/Web/API/Web_Speech_API) has been implemented on Firefox Desktop ([Firefox bug 1003439](https://bugzil.la/1003439 "External link (opens in new tab)")).
*   The [`storage`](/en-US/docs/Web/API/Window/storage_event "storage") event has been added.
*   The interface `ComputedTiming` have been added to our experimental implementation of [Web Animations API](/en-US/docs/Web/API/Web_Animations_API) ([Firefox bug 1108055](https://bugzil.la/1108055 "External link (opens in new tab)")).
*   The [`Document.onselectionchange`](/en-US/docs/Web/API/Document/selectionchange_event "Document.onselectionchange") event handler property has been added ([Firefox bug 1231193](https://bugzil.la/1231193 "External link (opens in new tab)")).
*   After removing a video track from a media stream by calling [`MediaStream.removeTrack()`](/en-US/docs/Web/API/MediaStream/removeTrack) you can now add another video track later using [`MediaStream.addTrack()`](/en-US/docs/Web/API/MediaStream/addTrack) and have it played ([Firefox bug 1223696](https://bugzil.la/1223696 "External link (opens in new tab)")).

## [HTTP](#http)

*   The `jar:` protocol has been disabled by default when accessed from Web content; you may enable this if necessary by setting the `network.jar.block-remote-files` preference to `false` ([Firefox bug 1215235](https://bugzil.la/1215235 "External link (opens in new tab)")).

## [Security](#security)

*   A [`Content-Security-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) can now be specified using a [`<meta>`](/en-US/docs/Web/HTML/Reference/Elements/meta) element ([Firefox bug 663570](https://bugzil.la/663570 "External link (opens in new tab)")).
*   Support of the [`child-src`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/child-src) CSP policy directive has been implemented ([Firefox bug 1045891](https://bugzil.la/1045891 "External link (opens in new tab)")).
*   EV certificates with a validity greater than 27 months are now considered and handled as DV certificates ([Firefox bug 1222903](https://bugzil.la/1222903 "External link (opens in new tab)")).

### [Search plugins](#search_plugins)

Starting in Firefox 45, search plugins located in the user's profile's `searchplugins` directory are no longer automatically loaded on startup. Instead, a list of user-installed plugins is maintained and only those plugins are loaded. In effect, this means that the only ways to install new search plugins are for the user to do so in the Firefox UX (via [OpenSearch discovery](/en-US/docs/Web/XML/Guides/OpenSearch), for instance) or for an add-on to install it. Also, when a new search plugin is installed, more information is recorded about where it came from, for future use by profile debugging and cleaning tools.

### [Other](#other)

*   WebIDL constructors could be called without the [`new`](/en-US/docs/Web/JavaScript/Reference/Operators/new) operator in chrome context. Now such code will raise a [`TypeError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypeError) as in Web content since Firefox 30. For example, `var req = XMLHttpRequest();` needs to be `var req = new XMLHttpRequest();`.
