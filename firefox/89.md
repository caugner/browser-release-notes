# Firefox 89 release notes for developers

This article provides information about the changes in Firefox 89 that will affect developers. Firefox 89 was released on June 1, 2021.

**Note:** See also [Looking fine with Firefox 89](https://hacks.mozilla.org/2021/06/looking-fine-with-firefox-89/ "External link (opens in new tab)") on Mozilla Hacks.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

_No changes._

### [CSS](#css)

*   The [`forced-colors`](/en-US/docs/Web/CSS/Reference/At-rules/@media/forced-colors) media feature has been implemented ([Firefox bug 1659511](https://bugzil.la/1659511 "External link (opens in new tab)")).
*   The [`ascent-override`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face/ascent-override), [`descent-override`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face/descent-override), and [`line-gap-override`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face/line-gap-override) `@font-face` descriptors have been implemented ([Firefox bug 1681691](https://bugzil.la/1681691 "External link (opens in new tab)") and [Firefox bug 1704494](https://bugzil.la/1704494 "External link (opens in new tab)")).
*   The `type()` function for [`image-set()`](/en-US/docs/Web/CSS/Reference/Values/image/image-set) has been implemented ([Firefox bug 1695404](https://bugzil.la/1695404 "External link (opens in new tab)")).
*   The [`aspect-ratio`](/en-US/docs/Web/CSS/Reference/Properties/aspect-ratio) CSS property is now supported ([Firefox bug 1672073](https://bugzil.la/1672073 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   Top-level [`await`](/en-US/docs/Web/JavaScript/Reference/Operators/await#top_level_await) is now enabled by default ([Firefox bug 1681046](https://bugzil.la/1681046 "External link (opens in new tab)")).
*   [ArrayBuffer](/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer)s can now be created with a length greater than 2GB-1 (up to 8GB) on 64-bit systems ([Firefox bug 1703505](https://bugzil.la/1703505 "External link (opens in new tab)")).

### [HTTP](#http)

_No changes._

### [APIs](#apis)

#### DOM

*   [`PerformanceEventTiming`](/en-US/docs/Web/API/PerformanceEventTiming) is now enabled by default ([Firefox bug 1701029](https://bugzil.la/1701029 "External link (opens in new tab)")).
*   The content of [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) and [`<textarea>`](/en-US/docs/Web/HTML/Reference/Elements/textarea) elements can now be manipulated using [`Document.execCommand()`](/en-US/docs/Web/API/Document/execCommand) commands by default, preserving edit history and providing parity with other browsers, without [`contentEditable`](/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable) or any lengthy workarounds required ([Firefox bug 1220696](https://bugzil.la/1220696 "External link (opens in new tab)")).

#### Removals

*   The following sensor events and their associated handlers have been removed (primarily for better compatibility with other major browser engines, and to address concerns related to privacy leaks):
    *   `DeviceProximityEvent` and its event handler `window.ondeviceproximity` ([Firefox bug 1699707](https://bugzil.la/1699707 "External link (opens in new tab)")).
    *   `UserProximityEvent` and its event handler `window.onuserproximity`) ([Firefox bug 1699707](https://bugzil.la/1699707 "External link (opens in new tab)")).
    *   `DeviceLightEvent` and its event handler `window.ondevicelight` ([Firefox bug 1701824](https://bugzil.la/1701824 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

#### Removals

*   The `rotatable` capability that is not part of the WebDriver specification is no longer used ([Firefox bug 1697630](https://bugzil.la/1697630 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   [Dynamic JS module imports](/en-US/docs/Web/JavaScript/Guide/Modules#dynamic_module_loading) are now working in WebExtension content scripts ([Firefox bug 1536094](https://bugzil.la/1536094 "External link (opens in new tab)")).
*   Extension resources listed in [web\_accessible\_resources](/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/web_accessible_resources) can be loaded regardless of the request's CORS mode ([Firefox bug 1694679](https://bugzil.la/1694679 "External link (opens in new tab)")).
*   Firefox's UI has been redesigned, which affects usage of the [`theme`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/theme) API. The `tab_background_separator` and `toolbar_field_separator` properties are no longer supported. The `tab_line` and `toolbar_vertical_separator` will behave differently. For more information, see [Changes to themeable areas of Firefox in version 89](https://blog.mozilla.org/addons/2021/04/19/changes-to-themeable-areas-of-firefox-in-version-89/ "External link (opens in new tab)").
*   The [`pageAction`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/pageAction) button can no longer be pinned or unpinned from the address bar, because the three-dot meatball menu is no longer visible by default ([Firefox bug 1691454](https://bugzil.la/1691454 "External link (opens in new tab)")). As a result, the `pinned` property of the [`page_action`](/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/page_action) manifest key no longer has any effect ([Firefox bug 1703537](https://bugzil.la/1703537 "External link (opens in new tab)")).
*   The "Remove from Address Bar" context menu item has been removed from the [`pageAction`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/pageAction) button ([Firefox bug 1704474](https://bugzil.la/1704474 "External link (opens in new tab)")). For alternatives to this functionality, see [Firefox bug 1712556](https://bugzil.la/1712556 "External link (opens in new tab)").
