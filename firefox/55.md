# Firefox 55 release notes for developers

Firefox 55 was released on August 8, 2017. This article lists key changes that are useful for web developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   Added filtering of network requests by column values and other properties ([Firefox bug 1041895](https://bugzil.la/1041895 "External link (opens in new tab)"), [Firefox bug 1354508](https://bugzil.la/1354508 "External link (opens in new tab)"), [Firefox bug 1354507](https://bugzil.la/1354507 "External link (opens in new tab)")) and by using regular expressions ([Firefox bug 1354495](https://bugzil.la/1354495 "External link (opens in new tab)")).
*   Made it possible to show and hide columns within the [Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html "External link (opens in new tab)") ([Firefox bug 862855](https://bugzil.la/862855 "External link (opens in new tab)")).
*   Added remote IP ([Firefox bug 1344523](https://bugzil.la/1344523 "External link (opens in new tab)")), protocol ([Firefox bug 1345489](https://bugzil.la/1345489 "External link (opens in new tab)")), scheme ([Firefox bug 1356867](https://bugzil.la/1356867 "External link (opens in new tab)")), cookies and set cookies columns ([Firefox bug 1356869](https://bugzil.la/1356869 "External link (opens in new tab)")) to Network Monitor.
*   The [`SourceMap`](/en-US/docs/Web/HTTP/Reference/Headers/SourceMap) HTTP header is now supported (prior versions supported the deprecated `X-SourceMap` header, see [Firefox bug 1346936](https://bugzil.la/1346936 "External link (opens in new tab)")).

### [HTML](#html)

*   Elements on which [`contenteditable`](/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable) has been set to `true` now use [`<div>`](/en-US/docs/Web/HTML/Reference/Elements/div) elements to separate different lines of text, to give Firefox parity with other modern browsers ([Firefox bug 1297414](https://bugzil.la/1297414 "External link (opens in new tab)")).
*   Enable `dom.forms.datetime` by default on Nightly ([Firefox bug 1366188](https://bugzil.la/1366188 "External link (opens in new tab)")).

### [CSS](#css)

*   Exposed the [`transform-box`](/en-US/docs/Web/CSS/Reference/Properties/transform-box) property by default ([Firefox bug 1208550](https://bugzil.la/1208550 "External link (opens in new tab)")).
*   Implemented the `frames()` timing function ([Firefox bug 1248340](https://bugzil.la/1248340 "External link (opens in new tab)")).
*   Implemented the [`text-justify`](/en-US/docs/Web/CSS/Reference/Properties/text-justify) property ([Firefox bug 1343512](https://bugzil.la/1343512 "External link (opens in new tab)"), [Firefox bug 276079](https://bugzil.la/276079 "External link (opens in new tab)")).
*   \[css-grid\] [`fit-content`](/en-US/docs/Web/CSS/Reference/Values/fit-content) unexpectedly reserves space for full clamp size in [`repeat()`](/en-US/docs/Web/CSS/Reference/Values/repeat) ([Firefox bug 1359060](https://bugzil.la/1359060 "External link (opens in new tab)")).
*   The [`float`](/en-US/docs/Web/CSS/Reference/Properties/float) / [`clear`](/en-US/docs/Web/CSS/Reference/Properties/clear) logical values — `inline-start` and `inline-end` — which were previously implemented but preffed off in release channels, are now available in all channels by default ([Firefox bug 1253919](https://bugzil.la/1253919 "External link (opens in new tab)")).
*   The `layout.css.variables.enabled` preference has been removed completely meaning that the [CSS variables](/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties) feature is enabled all the time and can no longer be disabled ([Firefox bug 1312328](https://bugzil.la/1312328 "External link (opens in new tab)")).
*   Implemented the proprietary `-moz-context-properties` property ([Firefox bug 1058040](https://bugzil.la/1058040 "External link (opens in new tab)")).
*   Zero (0) angle value without degree unit is not correctly interpreted in [`linear-gradient()`](/en-US/docs/Web/CSS/Reference/Values/gradient/linear-gradient) ([Firefox bug 1363292](https://bugzil.la/1363292 "External link (opens in new tab)")).
*   The [`::cue`](/en-US/docs/Web/CSS/Reference/Selectors/::cue) pseudo-element is now supported; it matches on text cues presented within a media element ([Firefox bug 1318542](https://bugzil.la/1318542 "External link (opens in new tab)")).

### [SVG](#svg)

*   The [`<radialGradient>`](/en-US/docs/Web/SVG/Reference/Element/radialGradient) [`fr`](/en-US/docs/Web/SVG/Reference/Attribute/fr) attribute has been implemented ([Firefox bug 1240275](https://bugzil.la/1240275 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The [`SharedArrayBuffer`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/SharedArrayBuffer) and [`Atomics`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Atomics) objects are now enabled by default. See [A Taste of JavaScript's New Parallel Primitives](https://hacks.mozilla.org/2016/05/a-taste-of-javascripts-new-parallel-primitives/ "External link (opens in new tab)") for an introduction to JavaScript Shared Memory and Atomics.
*   The rest operator (`...`) is now supported in [object destructuring](/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring) and the spread operator (`...`) now works in [object literals](/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax#spread_in_object_literals) (Stage 3 ECMAScript proposal: [Object Rest/Spread Properties](https://github.com/tc39/proposal-object-rest-spread "External link (opens in new tab)"), [Firefox bug 1339395](https://bugzil.la/1339395 "External link (opens in new tab)")).
*   [Async generator methods](/en-US/docs/Web/JavaScript/Reference/Functions/Method_definitions#async_generator_methods) are now supported ([Firefox bug 1353693](https://bugzil.la/1353693 "External link (opens in new tab)")).
*   The [`String.prototype.toLocaleLowerCase()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/toLocaleLowerCase) and [`String.prototype.toLocaleUpperCase()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/toLocaleUpperCase) methods now support an optional `locale` parameter to specify a language tag for locale-specific case mappings ([Firefox bug 1318403](https://bugzil.la/1318403 "External link (opens in new tab)")).
*   The [`Intl.Collator`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Collator) object now supports the `caseFirst` option ([Firefox bug 866473](https://bugzil.la/866473 "External link (opens in new tab)")).
*   The [Intl API](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl) now uses the browser's default locale instead of the operating system's default locale when no locale setting is provided ([Firefox bug 1346674](https://bugzil.la/1346674 "External link (opens in new tab)")).
*   [Template call sites objects](/en-US/docs/Web/JavaScript/Reference/Template_literals) are now canonicalized per realm, based upon their list of raw strings ([Firefox bug 1108941](https://bugzil.la/1108941 "External link (opens in new tab)")).
*   [`TypedArray`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray) constructors (like [`Int8Array`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Int8Array), [`Float32Array`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Float32Array), etc.) have been updated to ES2017. They now use the `ToIndex` operation and allow constructors without arguments, which return zero-length typed arrays ([Firefox bug 1317383](https://bugzil.la/1317383 "External link (opens in new tab)")).

### [APIs](#apis)

#### New APIs

*   The [Collaborative Scheduling of Background Tasks API](/en-US/docs/Web/API/Background_Tasks_API) (also known as the **Background Tasks API** or the `requestIdleCallback` API) is now enabled by default after being available behind a preference since Firefox 53. This API lets you schedule tasks to be executed when the browser determines that there's free time available before the next repaint occurs, so that your code can make use of that time without causing visible performance lag ([Firefox bug 1314959](https://bugzil.la/1314959 "External link (opens in new tab)")).
*   The [WebVR 1.1 API](/en-US/docs/Web/API/WebVR_API) is now turned on by default on Windows (and is available on macOS in Nightly). This API exposes virtual reality devices — for example head-mounted displays like the Oculus Rift or HTC Vive — to web apps, enabling developers to translate position and movement information from the display into movement around a 3D scene, and present content into such displays.
*   The [Intersection Observer API](/en-US/docs/Web/API/Intersection_Observer_API) — which provides a way to asynchronously observe changes in the intersection of a target element with an ancestor element or with a top-level document's [viewport](/en-US/docs/Glossary/Viewport) — has been added ([Firefox bug 1321865](https://bugzil.la/1321865 "External link (opens in new tab)")).

#### DOM

*   The [`Window`](/en-US/docs/Web/API/Window) properties [`scrollX`](/en-US/docs/Web/API/Window/scrollX "scrollX") and [`scrollY`](/en-US/docs/Web/API/Window/scrollY "scrollY") (as well as their aliases `pageXOffset` and `pageYOffset` have been updated to be subpixel precise. Instead of returning an integer, these now return a floating-point value which more accurately describes the scroll position on subpixel-precise displays ([Firefox bug 1151421](https://bugzil.la/1151421 "External link (opens in new tab)")). If need be, you can use [`Math.round()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/round) to convert them into integers.
*   [`MediaQueryList`](/en-US/docs/Web/API/MediaQueryList) (and other related features) have been updated to match the latest spec. See [Firefox bug 1354441](https://bugzil.la/1354441 "External link (opens in new tab)"), and also see [`MediaQueryList`](/en-US/docs/Web/API/MediaQueryList) and [`MediaQueryListEvent`](/en-US/docs/Web/API/MediaQueryListEvent).
*   Methods of the [`DOMTokenList`](/en-US/docs/Web/API/DOMTokenList) that modify the list value now automatically trim whitespace and remove duplicate tokens ([Firefox bug 869788](https://bugzil.la/869788 "External link (opens in new tab)"), also see [Trimming of whitespace and removal of duplicates](/en-US/docs/Web/API/DOMTokenList#trimming_of_whitespace_and_removal_of_duplicates)).
*   The [`HTMLInputElement`](/en-US/docs/Web/API/HTMLInputElement)'s `maxLength` property can now be dynamically altered with JavaScript after the equivalent HTML has been created ([Firefox bug 1352799](https://bugzil.la/1352799 "External link (opens in new tab)")).
*   The [`URL()`](/en-US/docs/Web/API/URL/URL "URL()") constructor can no longer accept a `DOMString` as its base (2nd parameter) — it only accepts a `USVString`. It can still use an existing [`URL`](/en-US/docs/Web/API/URL) object for the base, which stringifies itself to the object's `href` attribute ([Firefox bug 1368950](https://bugzil.la/1368950 "External link (opens in new tab)")).

#### DOM events

*   The event types supported by the [`Document.createEvent()`](/en-US/docs/Web/API/Document/createEvent) method have been updated as per the latest DOM spec ([Firefox bug 1251198](https://bugzil.la/1251198 "External link (opens in new tab)")).
*   The [`MessageEvent.origin`](/en-US/docs/Web/API/MessageEvent/origin) property value is now of type `USVString`, not `DOMString`, and the [`MessageEvent.source`](/en-US/docs/Web/API/MessageEvent/source) property now takes a `MessageEventSource` value (which can be a [WindowProxy](/en-US/docs/Glossary/WindowProxy), [`MessagePort`](/en-US/docs/Web/API/MessagePort), or [`ServiceWorker`](/en-US/docs/Web/API/ServiceWorker) object) ([Firefox bug 1311324](https://bugzil.la/1311324 "External link (opens in new tab)")).
*   The pinch-to-zoom gesture has now been mapped to the [`wheel`](/en-US/docs/Web/API/Element/wheel_event "wheel") event plus the + `Ctrl` key. This mapping was implemented to allow developers to implement simple zooming functionality using the pinch-to-zoom gesture on mobile screens/trackpads (mousewheel + `Ctrl` commonly zooms) ([Firefox bug 1052253](https://bugzil.la/1052253 "External link (opens in new tab)")).

#### Selection API

*   The [Selection API](/en-US/docs/Web/API/Selection) has been updated so that it has parity with other browsers in terms of how editing hosts are given focus when the selection moves inside them ([Firefox bug 1318312](https://bugzil.la/1318312 "External link (opens in new tab)")). See [Behavior of Selection API in terms of editing host focus changes](/en-US/docs/Web/API/Selection#behavior_of_selection_api_in_terms_of_editing_host_focus_changes) for more details.
    
*   The [`Selection`](/en-US/docs/Web/API/Selection) API has been updated to match some recent spec changes ([Firefox bug 1359371](https://bugzil.la/1359371 "External link (opens in new tab)")):
    
    *   The [`collapse()`](/en-US/docs/Web/API/Selection/collapse "collapse()") and [`extend()`](/en-US/docs/Web/API/Selection/extend "extend()") methods' `offset` parameter is now optional.
    *   The [`collapse()`](/en-US/docs/Web/API/Selection/collapse "collapse()") method's `node` parameter is now nullable.
    *   The [`containsNode()`](/en-US/docs/Web/API/Selection/containsNode "containsNode()") method's `partialContainment` parameter is now optional.
    *   The [`deleteFromDocument()`](/en-US/docs/Web/API/Selection/deleteFromDocument "deleteFromDocument()") method has been added.
*   Also in the [`Selection`](/en-US/docs/Web/API/Selection) API, `Selection.empty()` and `Selection.setPosition()` have been added as aliases of [`Selection.removeAllRanges()`](/en-US/docs/Web/API/Selection/removeAllRanges) and [`Selection.collapse()`](/en-US/docs/Web/API/Selection/collapse), for web compat and WebKit/Blink parity reasons ([Firefox bug 1359387](https://bugzil.la/1359387 "External link (opens in new tab)")).
    
*   The [`StorageManager.persist()`](/en-US/docs/Web/API/StorageManager/persist) and [`StorageManager.persisted()`](/en-US/docs/Web/API/StorageManager/persisted) methods of the [Storage API](/en-US/docs/Web/API/Storage_API) have been implemented and exposed to `Window` contexts ([Firefox bug 1286717](https://bugzil.la/1286717 "External link (opens in new tab)")).
    

#### Workers

*   Workers and shared workers can now be created with an identifying `name` property. See the [`Worker()`](/en-US/docs/Web/API/Worker/Worker "Worker()") and [`SharedWorker()`](/en-US/docs/Web/API/SharedWorker/SharedWorker "SharedWorker()") constructors, and the [`DedicatedWorkerGlobalScope`](/en-US/docs/Web/API/DedicatedWorkerGlobalScope) and [`SharedWorkerGlobalScope`](/en-US/docs/Web/API/SharedWorkerGlobalScope) interfaces. ([Firefox bug 1364297](https://bugzil.la/1364297 "External link (opens in new tab)")).
*   [`Window.setTimeout()`](/en-US/docs/Web/API/Window/setTimeout), [`WorkerGlobalScope.setTimeout()`](/en-US/docs/Web/API/WorkerGlobalScope/setTimeout), [`Window.setInterval()`](/en-US/docs/Web/API/Window/setInterval) and [`WorkerGlobalScope.setInterval()`](/en-US/docs/Web/API/WorkerGlobalScope/setInterval) are now subject to minimum interval throttling for tracking scripts in background tabs — see [Throttling of tracking scripts](/en-US/docs/Web/API/Window/setTimeout#throttling_of_tracking_scripts) ([Firefox bug 1355311](https://bugzil.la/1355311 "External link (opens in new tab)")).

#### Service Workers/Push

*   Messages sent to service worker contexts (e.g., as the event object of [`onmessage`](/en-US/docs/Web/API/ServiceWorkerGlobalScope/message_event "onmessage")) are now represented by [`MessageEvent`](/en-US/docs/Web/API/MessageEvent) objects, for consistency with other web messaging features.
*   The [`PushManager.subscribe()`](/en-US/docs/Web/API/PushManager/subscribe) method now accepts [`ArrayBuffer`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer)s and Base64-encoded strings as `applicationServerKey` values ([Firefox bug 1337348](https://bugzil.la/1337348 "External link (opens in new tab)")).

#### Web Audio API

*   A non-standard constructor (which accepted a string enum value indicating the purpose for which the context would be used) for [`AudioContext`](/en-US/docs/Web/API/AudioContext) interface was causing errors to be thrown when the `options` parameter was provided. We have removed the non-standard constructor. However, please note that the `options` parameter is not yet supported in Firefox and is currently ignored ([Firefox bug 1361475](https://bugzil.la/1361475 "External link (opens in new tab)")).

#### WebRTC

*   [`getUserMedia()`](/en-US/docs/Web/API/MediaDevices/getUserMedia "getUserMedia()") now provides a stereo audio stream by default if the source device provides stereo sound; support to specifically request mono input will come in [Firefox 56](/en-US/docs/Mozilla/Firefox/Releases/56). This only works on desktop at this time; mobile Firefox does not currently support stereo audio input sources ([Firefox bug 971528](https://bugzil.la/971528 "External link (opens in new tab)")).
*   The `getUserMedia()` [media capabilities, constraints, and settings](/en-US/docs/Web/API/Media_Capture_and_Streams_API/Constraints) `autoGainControl` and `noiseSuppression` now match the spec; formerly they were `moz`\-prefixed ([Firefox bug 1366415](https://bugzil.la/1366415 "External link (opens in new tab)")).
*   When called with an empty constraints set, `getUserMedia()` was incorrectly returning `NotSupportedError` instead of `TypeError`. This has been fixed ([Firefox bug 1349480](https://bugzil.la/1349480 "External link (opens in new tab)")).
*   The following new WebRTC statistics are available: `framesEncoded`, `pliCount`, `nackCount`, and `firCount` ([Firefox bug 1348657](https://bugzil.la/1348657 "External link (opens in new tab)")).
*   The `RTCInboundRTPStreamStats` dictionary field formerly called `mozRtt` has been renamed to `roundTripTime` to match the specification; in addition, its behavior has been adjusted to match the standard: it contains a double-precision floating point value which estimates the round-trip time based on the RTCP timestamps in the RTCP Receiver Report, measured in seconds (following the algorithm described in [RFC 3550, section 6.4.1](https://datatracker.ietf.org/doc/html/rfc3550#section-6.4.1 "External link (opens in new tab)")). ([Firefox bug 1344970](https://bugzil.la/1344970 "External link (opens in new tab)")). However, please be aware that _this property is moving_ to a different dictionary (`RTCRemoteInboundRTPStreamStats`) soon ([Firefox bug 1380555](https://bugzil.la/1380555 "External link (opens in new tab)")).
*   The `RTCRTPStreamStats` dictionary now includes the fields `firCount`, `pliCount`, and `nackCount`. These return low-level information that can be used to determine how reliable the connection is ([Firefox bug 1348657](https://bugzil.la/1348657 "External link (opens in new tab)")).
*   The `RTCOutboundRTPStreamStats` dictionary now includes the field `framesEncoded`, which reports the number of frames that have been successfully encoded for the stream; with this information, you can compute the frame rate ([Firefox bug 1348657](https://bugzil.la/1348657 "External link (opens in new tab)")).
*   On Android, there's now a [pref](https://bugzil.la/1265755#c36 "External link (opens in new tab)") to turn on hardware video encoding to improve video call performance and save on battery. To be enabled by default in [Firefox 56](/en-US/docs/Mozilla/Firefox/Releases/56) ([Firefox bug 1265755](https://bugzil.la/1265755 "External link (opens in new tab)")).

#### Encrypted Media Extensions API

*   Firefox currently allows Encrypted Media Extensions to be used in insecure contexts, despite this not being allowed in the specification. This will be changed in the near future, and starting in Firefox 55, deprecation warnings are output to the [web console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html "External link (opens in new tab)") when this is done. ([Firefox bug 1361000](https://bugzil.la/1361000 "External link (opens in new tab)")).
*   Firefox currently doesn't require that at least one `MediaKeySystemCapabilities` object be included in the `suggestedConfigurations` parameter passed into [`Navigator.requestMediaKeySystemAccess()`](/en-US/docs/Web/API/Navigator/requestMediaKeySystemAccess), which the specification does mandate. Starting in Firefox 55, a warning is output to the web console when any audio or video configuration is specified without specifying supported codecs. Soon, failure to include a valid configuration for one or more of audio and video will throw an exception ([Firefox bug 1368683](https://bugzil.la/1368683 "External link (opens in new tab)")).

#### WebGL

*   The [`WEBGL_compressed_texture_s3tc_srgb`](/en-US/docs/Web/API/WEBGL_compressed_texture_s3tc_srgb) extension is now available to [WebGL](/en-US/docs/Web/API/WebGL_API) and [WebGL2](/en-US/docs/Web/API/WebGL2RenderingContext) contexts ([Firefox bug 1325113](https://bugzil.la/1325113 "External link (opens in new tab)")).

### [Security](#security)

*   The [Geolocation API](/en-US/docs/Web/API/Geolocation_API) is now available only to [secure contexts](/en-US/docs/Web/Security/Defenses/Secure_Contexts) ([Firefox bug 1072859](https://bugzil.la/1072859 "External link (opens in new tab)")).
*   The [Storage API](/en-US/docs/Web/API/Storage_API) is now available only to [secure contexts](/en-US/docs/Web/Security/Defenses/Secure_Contexts) ([Firefox bug 1268804](https://bugzil.la/1268804 "External link (opens in new tab)")).
*   The loading of mixed content is now allowed on localhost ([Firefox bug 903966](https://bugzil.la/903966 "External link (opens in new tab)")).
*   Loading of remote JAR files has been disabled again ([Firefox bug 1329336](https://bugzil.la/1329336 "External link (opens in new tab)")).

### [Plugins](#plugins)

*   Flash content is now "click-to-activate" ([Firefox bug 1317856](https://bugzil.la/1317856 "External link (opens in new tab)")). This was immediately put into effect for all users of Nightly, and 50% of beta users. For Firefox 55 release version, the plan is to activate this for 5% of users 2 weeks after release, 25% of users 4 weeks after release, and 100% of users 6 weeks after release ([Firefox bug 1365714](https://bugzil.la/1365714 "External link (opens in new tab)")).
*   Flash and other plugins can no longer be loaded from any URL scheme except for `http://` and `https://` ([Firefox bug 1335475](https://bugzil.la/1335475 "External link (opens in new tab)")).

### [Other](#other)

*   Firefox on Linux can now be made to run in headless mode using the `-headless` flag (see [Firefox bug 1356681](https://bugzil.la/1356681 "External link (opens in new tab)")).

## [Removals from the web platform](#removals_from_the_web_platform)

### [HTML](#html_2)

*   The `xml:base` attribute can no longer be used to set the base URL for paths appearing in the [`style`](/en-US/docs/Web/HTML/Reference/Global_attributes/style) attribute, for example —
    
    `<div xml:base="https://example.com/" style="background:url(picture.jpg)"></div>` ([Firefox bug 1350521](https://bugzil.la/1350521 "External link (opens in new tab)")).
    
*   The [`<style>`](/en-US/docs/Web/HTML/Reference/Elements/style) element's `scoped` attribute has been hidden behind a pref (`layout.css.scoped-style.enabled`) in content documents in Firefox 55+, as no other browsers support it.
    
*   Support for the obscure `MSThemeCompatible` value of the [`<meta>`](/en-US/docs/Web/HTML/Reference/Elements/meta) element's [`http-equiv`](/en-US/docs/Web/HTML/Reference/Elements/meta/http-equiv) attribute has been removed from Firefox. No other modern browsers support it, and it was causing compatibility problems ([Firefox bug 966240](https://bugzil.la/966240 "External link (opens in new tab)")).
    

### [CSS](#css_2)

*   The proprietary `:-moz-bound-element` pseudo-class has been removed ([Firefox bug 1350147](https://bugzil.la/1350147 "External link (opens in new tab)")).
*   The proprietary `-moz-anchor-decoration` value of [`text-decoration-line`](/en-US/docs/Web/CSS/Reference/Properties/text-decoration-line) has been removed ([Firefox bug 1355734](https://bugzil.la/1355734 "External link (opens in new tab)")).

### [APIs](#apis_2)

*   The `UIEvent.isChar` property has never been supported by any browser but Firefox, and it has never been fully implemented except on macOS. For that reason, it was removed in Firefox 55 to align with other browsers.
*   The proprietary Firefox OS Device Storage API has been removed from the platform ([Firefox bug 1299500](https://bugzil.la/1299500 "External link (opens in new tab)")).
*   The `aShowDialog` parameter of the non-standard [`Window.find()`](/en-US/docs/Web/API/Window/find) method (which could be specified to open up a "Find" dialog in the browser) has been removed ([Firefox bug 1348409](https://bugzil.la/1348409 "External link (opens in new tab)")).
*   The `HTMLFormElement.requestAutoComplete()` method has been removed (see [`HTMLFormElement`](/en-US/docs/Web/API/HTMLFormElement)) ([Firefox bug 1270740](https://bugzil.la/1270740 "External link (opens in new tab)")).
*   The non-standard, Mozilla-specific, WebRTC offer options `mozDontOfferDataChannel` and `mozBundleOnly` have been removed from the `RTCOfferOptions` dictionary and are no longer supported by [`RTCPeerConnection.createOffer()`](/en-US/docs/Web/API/RTCPeerConnection/createOffer) ([Firefox bug 1196974](https://bugzil.la/1196974 "External link (opens in new tab)")).
*   Support for the proprietary Firefox OS `Audio Channels API` has been removed from [`HTMLMediaElement`](/en-US/docs/Web/API/HTMLMediaElement) and [`AudioContext`](/en-US/docs/Web/API/AudioContext) ([Firefox bug 1358061](https://bugzil.la/1358061 "External link (opens in new tab)")).

### [SVG](#svg_2)

*   The `SVGZoomEvent` and `SVGZoomEvents` interfaces have been removed from the SVG2 spec and Gecko, along with the `onzoom <svg>` attribute ([Firefox bug 1314388](https://bugzil.la/1314388 "External link (opens in new tab)")).

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

### [WebExtensions](#webextensions)

*   [contextMenus.create()'s command property enables you to open browser action popups, page action popups, and sidebars from the context menu.](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/menus/create)
*   [proxy API](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/proxy)
*   [chrome\_settings\_overrides key enables you to override the browser's homepage.](/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/chrome_settings_overrides)
