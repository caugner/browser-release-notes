# Firefox 17 release notes for developers

Firefox 17 shipped on November 20, 2012. This article lists key changes that are useful for not only web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

*   Support for the [`sandbox`](/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox) attribute on the [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) element has been added. ([Firefox bug 341604](https://bugzil.la/341604 "External link (opens in new tab)"))

### [CSS](#css)

*   Support for [`@supports`](/en-US/docs/Web/CSS/Reference/At-rules/@supports) at-rule defined in [CSS Conditional Rules Module Level 3](https://drafts.csswg.org/css-conditional-3/ "External link (opens in new tab)") has been landed. It is disabled by default. Developers can try it by setting `layout.css.supports-rule.enabled` to true ([bug 649740](https://bugzil.la/649740 "External link (opens in new tab)")).
*   Support for the CSS Selectors Level 4 pseudo-class [`:dir()`](/en-US/docs/Web/CSS/Reference/Selectors/:dir) allowing selection of elements based on their directionality has landed. ([bug 562169](https://bugzil.la/562169 "External link (opens in new tab)"))
*   Support for the newly specified `isolate-override` value of the CSS [`unicode-bidi`](/en-US/docs/Web/CSS/Reference/Properties/unicode-bidi) value has landed ([Firefox bug 774335](https://bugzil.la/774335 "External link (opens in new tab)"))
*   Our prefixed implementation of [`box-sizing`](/en-US/docs/Web/CSS/Reference/Properties/box-sizing) now takes into account [`min-height`](/en-US/docs/Web/CSS/Reference/Properties/min-height) and [`max-height`](/en-US/docs/Web/CSS/Reference/Properties/max-height). One step closer to its unprefixing ([Firefox bug 308801](https://bugzil.la/308801 "External link (opens in new tab)"))

### [DOM/APIs](#domapis)

*   Support for [`CSSSupportsRule`](/en-US/docs/Web/API/CSSSupportsRule) interface defined in [CSS3 Conditional Rules specification](https://drafts.csswg.org/css-conditional-3/ "External link (opens in new tab)") has been landed ([Firefox bug 649740](https://bugzil.la/649740 "External link (opens in new tab)"))
*   Support for [`WheelEvent`](/en-US/docs/Web/API/WheelEvent) object and `wheel` event have been landed ([Firefox bug 719320](https://bugzil.la/719320 "External link (opens in new tab)")).
*   Support DOM Meta key on Linux again ([Firefox bug 751749](https://bugzil.la/751749 "External link (opens in new tab)")).
*   On [`HTMLMediaElement`](/en-US/docs/Web/API/HTMLMediaElement), a new method, `mozGetMetadata`, that returns a JavaScript object whose properties represent metadata from the playing media resource as {key: value} pairs ([Firefox bug 763010](https://bugzil.la/763010 "External link (opens in new tab)")).
*   Support for [`Range.intersectsNode`](/en-US/docs/Web/API/Range/intersectsNode) has been added again; it has been removed in Gecko 1.9 ([Firefox bug 579638](https://bugzil.la/579638 "External link (opens in new tab)").
*   [`Range.compareBoundaryPoints()`](/en-US/docs/Web/API/Range/compareBoundaryPoints) now throws a [`DOMException`](/en-US/docs/Web/API/DOMException) with the `NOT_SUPPORTED_ERR` value when the comparison method is invalid ([Firefox bug 714279](https://bugzil.la/714279 "External link (opens in new tab)")).
*   [`Event.initEvent()`](/en-US/docs/Web/API/Event/initEvent) has been adapted to the spec: it doesn't throw anymore if called after the dispatch of the event, it is only a no-op ([Firefox bug 768310](https://bugzil.la/768310 "External link (opens in new tab)")).
*   The non-standard [`XMLHttpRequest.onuploadrequest`](/en-US/docs/Web/API/XMLHttpRequest "XMLHttpRequest.onuploadrequest") property has been removed ([Firefox bug 761278](https://bugzil.la/761278 "External link (opens in new tab)")).
*   The method [`XMLHttpRequest.getAllResponseHeaders()`](/en-US/docs/Web/API/XMLHttpRequest/getAllResponseHeaders) now separates them with a CRLF (instead of a LF), as requested by the spec ([Firefox bug 730925](https://bugzil.la/730925 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   [`String`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String) object now offers Harmony [`startsWith`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/startsWith), [`endsWith`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/endsWith), and [`contains`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/includes) methods ([Firefox bug 772733](https://bugzil.la/772733 "External link (opens in new tab)")).
*   The String methods [`link()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/link) and [`anchor()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/anchor) now escape the `'"'` (quotation mark) ([Firefox bug 352437](https://bugzil.la/352437 "External link (opens in new tab)")).
*   Experimental support for strawman `ParallelArray` object has been implemented ([Firefox bug 778559](https://bugzil.la/778559 "External link (opens in new tab)")).
*   Support to iterate [`Map`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map)/[`Set`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set) ([Firefox bug 725909](https://bugzil.la/725909 "External link (opens in new tab)")).
*   Disabled ECMAScript for XML (E4X), an abandoned JavaScript extension, for web content by default ([Firefox bug 778851](https://bugzil.la/778851 "External link (opens in new tab)")).
*   `__exposedProps__` must now be set for Chrome JavaScript objects exposed to content. Attempts to access Chrome objects from content without `__exposedProps__` set will fail silently ([Firefox bug 553102](https://bugzil.la/553102 "External link (opens in new tab)")).
*   [`for...of`](/en-US/docs/Web/JavaScript/Reference/Statements/for...of) loops now work in terms of `.iterator()` and `.next()` ([Firefox bug 725907](https://bugzil.la/725907 "External link (opens in new tab)")).

### [WebGL](#webgl)

*   The [`EXT_texture_filter_anisotropic`](/en-US/docs/Web/API/EXT_texture_filter_anisotropic) WebGL extension has been unprefixed. Using `"MOZ_EXT_texture_filter_anisotropic"` will present a warning from now on. The prefixed name is going to be removed in a future release ([Firefox bug 776001](https://bugzil.la/776001 "External link (opens in new tab)")).

### [SVG](#svg)

_No change._

### [MathML](#mathml)

*   The parsing of the `align` attribute on [`<mtable>`](/en-US/docs/Web/MathML/Reference/Element/mtable "<mtable>") elements has been updated to treat optional spaces more correctly.

### [XUL](#xul)

*   XUL `key` element supports "os" modifier which is Win key (Super or Hyper key) ([Firefox bug 778732](https://bugzil.la/778732 "External link (opens in new tab)")).

### [Network](#network)

*   Removed the non-standard feature `XMLHttpRequest.onuploadprogress` which was deprecated in Firefox 14.

_No change._

### [Developer tools](#developer_tools)

*   Change JSTerm's $ helper function from getElementById to querySelector() ([Firefox bug 751749](https://bugzil.la/751749 "External link (opens in new tab)")).

### [User Agent](#user_agent)

The Gecko part of the user agent string changed. The build date (which hadn't been updated since 2010) was removed, and the Gecko version number was put in its place instead. So `Gecko/20100101` -> `Gecko/17.0`. This may affect you if you are doing user agent sniffing.

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

### [Interface changes](#interface_changes)

[`nsIInputStream`](#nsiinputstream)

The `available()` method returns 64-bit length instead of 32-bit ([Firefox bug 215450](https://bugzil.la/215450 "External link (opens in new tab)")).

[`nsIDOMWindowUtils`](#nsidomwindowutils)

The `sendMouseScrollEvent()` method has been replaced with `sendWheelEvent()` ([Firefox bug 719320](https://bugzil.la/719320 "External link (opens in new tab)")).

[`nsIFilePicker`](#nsifilepicker)

The `open()` method, to open the file dialog asynchronously, has been added and the `show()` method has been deprecated ([Firefox bug 731307](https://bugzil.la/731307 "External link (opens in new tab)")).

[`nsIScriptSecurityManager`](#nsiscriptsecuritymanager)

The `checkLoadURIStr()` and `checkLoadURI()` methods have been removed ([Firefox bug 327244](https://bugzil.la/327244 "External link (opens in new tab)")).

[`nsIRefreshURI`](#nsirefreshuri)

The `setupRefreshURIFromHeader()` method has a `principal` parameter added ([Firefox bug 327244](https://bugzil.la/327244 "External link (opens in new tab)")).

#### New interfaces

None.

#### Removed interfaces

None removed.
