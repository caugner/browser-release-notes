# Firefox 160 release notes for developers (Nightly)

This article provides information about the changes in Firefox 160 that affect developers. Firefox 160 is the current [Nightly version of Firefox](https://www.firefox.com/en-US/channel/desktop/#nightly "External link (opens in new tab)") and ships on [November 10, 2026](https://whattrainisitnow.com/release/?version=160 "External link (opens in new tab)").

**Note:** The release notes for this Firefox version are still a work in progress.

## [Changes for add-on developers](#changes_for_add-on_developers)

## [Experimental web features](#experimental_web_features)

These features are shipping in Firefox 160 but are disabled by default. To experiment with them, search for the appropriate preference on the `about:config` page and set it to `true`. You can find more such features on the [Experimental features](/en-US/docs/Mozilla/Firefox/Experimental_features) page.
