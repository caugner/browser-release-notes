# Firefox 28 release notes for developers

Firefox 28 was released on March 18, 2014. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   The `console.exception` property has been added ([Firefox bug 922214](https://bugzil.la/922214 "External link (opens in new tab)")).
*   The [`console.assert()`](/en-US/docs/Web/API/console/assert_static "console.assert()") property has been added ([Firefox bug 760193](https://bugzil.la/760193 "External link (opens in new tab)")).
*   App Manager: a new Manifest Editor was added.
*   App Manager: the toolbox used for debugging apps is now embedded in the app manager UI.
*   Web Console: added a "split console" mode - press Escape to quickly open the console in any other tool.
*   Web Console: added a dark theme for the output.
*   Debugger: pretty-print minified JavaScript.
*   Debugger: hover over any variable or click on it to bring up a pop-up that displays the current value.
*   Inspector: added a color picker in rules view and various tooltips.
*   Browser Toolbox: allows add-on and platform developers to use almost all of the developer tools while targeting the browser itself.

More details in [this post](https://hacks.mozilla.org/2013/12/split-console-pretty-print-minified-js-and-more-firefox-developer-tools-episode-28/ "External link (opens in new tab)").

### [CSS](#css)

*   Support for multi-line [flexbox](/en-US/docs/Web/CSS/Guides/Flexible_box_layout/Basic_concepts) has been added ([Firefox bug 939901](https://bugzil.la/939901 "External link (opens in new tab)")).
*   Longhand East Asian [counter styles](/en-US/docs/Web/CSS/Reference/Properties/list-style-type) have been implemented ([Firefox bug 934072](https://bugzil.la/934072 "External link (opens in new tab)")).
*   Experimental support for the [`background-blend-mode`](/en-US/docs/Web/CSS/Reference/Properties/background-blend-mode) property has been added, but is disabled by default ([Firefox bug 841601](https://bugzil.la/841601 "External link (opens in new tab)")).
*   The `none` value has been added to [`font-variant-ligatures`](/en-US/docs/Web/CSS/Reference/Properties/font-variant-ligatures) ([Firefox bug 913264](https://bugzil.la/913264 "External link (opens in new tab)")).
*   Support for the [`:hover`](/en-US/docs/Web/CSS/Reference/Selectors/:hover) user action pseudo-class on pseudo-elements has been implemented ([Firefox bug 922669](https://bugzil.la/922669 "External link (opens in new tab)")).

### [HTML](#html)

*   `<input type=color>` and `<input type=number>` have been implemented, disabled by default.

### [JavaScript](#javascript)

*   ECMAScript 2015 implementation continues:
    
    *   New `Array` methods have been implemented: [`Array.prototype.entries()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/entries) and [`Array.prototype.keys()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/keys) ([Firefox bug 894658](https://bugzil.la/894658 "External link (opens in new tab)")).
*   A bug causing that [`Object.getOwnPropertyNames()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/getOwnPropertyNames) did not see unresolved properties of [`Error`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error) objects has been fixed ([Firefox bug 724768](https://bugzil.la/724768 "External link (opens in new tab)")).
    

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   `HTMLVideoElement.canPlayType('video/webm')` now reports `maybe`. ([Firefox bug 884275](https://bugzil.la/884275 "External link (opens in new tab)")).
*   The [`DocumentFragment.getElementById()`](/en-US/docs/Web/API/DocumentFragment/getElementById) method has been implemented. E.g. `document.createDocumentFragment().getElementById()` ([Firefox bug 933193](https://bugzil.la/933193 "External link (opens in new tab)")).
*   The [`KeyboardEvent.repeat`](/en-US/docs/Web/API/KeyboardEvent/repeat) attribute has been implemented ([Firefox bug 600117](https://bugzil.la/600117 "External link (opens in new tab)")).
*   The [`File`](/en-US/docs/Web/API/File) constructor, e.g., `new File(["foo"], "foo.txt")` has been implemented. ([Firefox bug 819900](https://bugzil.la/819900 "External link (opens in new tab)")).
*   The [`Navigator.plugins`](/en-US/docs/Web/API/Navigator/plugins) is no more enumerable, for privacy reasons ([Firefox bug 757726](https://bugzil.la/757726 "External link (opens in new tab)")).
*   The two attributes [`Window.screenX`](/en-US/docs/Web/API/Window/screenX) and [`Window.screenY`](/en-US/docs/Web/API/Window/screenY) now return CSS pixels (and no more device pixels) ([Firefox bug 943668](https://bugzil.la/943668 "External link (opens in new tab)")).
*   The two methods `CanvasRenderingContext2D.drawSystemFocusRing()` and [`CanvasRenderingContext2D.drawCustomFocusRing()`](/en-US/docs/Web/API/CanvasRenderingContext2D/drawFocusIfNeeded "CanvasRenderingContext2D.drawCustomFocusRing()") have been implemented. The preference `canvas.focusring.enabled` must be set to `true` to activate both ([Firefox bug 540456](https://bugzil.la/540456 "External link (opens in new tab)")).
*   The `willReadFrequently` context attribute for 2D canvas contexts has been implemented (see [`HTMLCanvasElement.getContext()`](/en-US/docs/Web/API/HTMLCanvasElement/getContext)) ([Firefox bug 884226](https://bugzil.la/884226 "External link (opens in new tab)")).
*   The following attributes and methods of `NavigatorID` have been implemented on [`WorkerNavigator`](/en-US/docs/Web/API/WorkerNavigator) to allow their use in workers: [`Navigator.appCodeName`](/en-US/docs/Web/API/Navigator/appCodeName), [`Navigator.product`](/en-US/docs/Web/API/Navigator/product), and [`Navigator.taintEnabled`](/en-US/docs/Web/API/Navigator/taintEnabled) ([Firefox bug 925847](https://bugzil.la/925847 "External link (opens in new tab)")).
*   The [`previousElementSibling`](/en-US/docs/Web/API/Element/previousElementSibling "previousElementSibling") and [`nextElementSibling`](/en-US/docs/Web/API/Element/nextElementSibling "nextElementSibling") properties has been removed from [`DocumentType`](/en-US/docs/Web/API/DocumentType), because of compatibility problems ([Firefox bug 932501](https://bugzil.la/932501 "External link (opens in new tab)")).

### [MathML](#mathml)

*   Support of the `mathvariant` attribute has been added ([Firefox bug 114365](https://bugzil.la/114365 "External link (opens in new tab)")).

### [SVG](#svg)

_No change._

### [Audio/Video](#audiovideo)

*   Opus in WebM is now supported ([Firefox bug 887978](https://bugzil.la/887978 "External link (opens in new tab)")).
*   The VP9 video decoder is now supported ([Firefox bug 833023](https://bugzil.la/833023 "External link (opens in new tab)")).

### [Network](#network)

*   Support of `SPDY/2` has been removed.

## [Changes for add-ons and Mozilla developers](#changes_for_add-ons_and_mozilla_developers)

*   The interface of `DeferredTask.jsm` has been changed, and the `isPending()`, `start()`, `flush()`, and `cancel()` methods have been removed ([Firefox bug 940408](https://bugzil.la/940408 "External link (opens in new tab)")).

## [Security](#security)

*   CSP was not enforced in sandboxed iframes. This has been fixed ([Firefox bug 886164](https://bugzil.la/886164 "External link (opens in new tab)")).
*   The CSP 1.1 experimental `script-nonce` directive has been implemented. The preference `security.csp.experimentalEnabled` should be set to `true` to enable this functionality ([Firefox bug 855326](https://bugzil.la/855326 "External link (opens in new tab)")).
