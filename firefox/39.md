# Firefox 39 release notes for developers

Firefox 39 was released on July 2, 2015. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   _WebIDE_ now supports debugging Firefox OS devices over Wi-Fi
*   _WebIDE_ now supports Cordova projects
*   [Animations view: rewind, fast-forward, and jump to a specific time](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/work_with_animations/index.html#firefox-39 "External link (opens in new tab)")
*   [The cubic Bézier curve editor now includes 31 presets](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/work_with_animations/index.html#firefox-39 "External link (opens in new tab)")
*   [Drag and drop elements in the Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_html/index.html#drag-and-drop "External link (opens in new tab)")
*   [Web console command history is now persisted across sessions](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html#command-history "External link (opens in new tab)")
*   [$\_ console command to print the last result evaluated](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html#helper-commands "External link (opens in new tab)")
*   [Better box model highlighting for inline elements](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_the_box_model/index.html#firefox-39 "External link (opens in new tab)")

[All devtools bugs fixed between Firefox 38 and Firefox 39](https://bugzilla.mozilla.org/buglist.cgi?resolution=FIXED&classification=Client%20Software&query_based_on=devtools_resolved_week&chfieldto=2015-03-31&chfield=resolution&query_format=advanced&chfieldfrom=2015-02-22&chfieldvalue=FIXED&bug_status=RESOLVED&bug_status=VERIFIED&bug_status=CLOSED&component=Developer%20Tools&component=Developer%20Tools%3A%203D%20View&component=Developer%20Tools%3A%20Canvas%20Debugger&component=Developer%20Tools%3A%20Console&component=Developer%20Tools%3A%20Debugger&component=Developer%20Tools%3A%20Framework&component=Developer%20Tools%3A%20Graphic%20Commandline%20and%20Toolbar&component=Developer%20Tools%3A%20Inspector&component=Developer%20Tools%3A%20Memory&component=Developer%20Tools%3A%20Netmonitor&component=Developer%20Tools%3A%20Object%20Inspector&component=Developer%20Tools%3A%20Performance%20Tools%20%28Profiler%2FTimeline%29&component=Developer%20Tools%3A%20Responsive%20Mode&component=Developer%20Tools%3A%20Scratchpad&component=Developer%20Tools%3A%20Source%20Editor&component=Developer%20Tools%3A%20Storage%20Inspector&component=Developer%20Tools%3A%20Style%20Editor&component=Developer%20Tools%3A%20User%20Stories&component=Developer%20Tools%3A%20Web%20Audio%20Editor&component=Developer%20Tools%3A%20WebGL%20Shader%20Editor&component=Developer%20Tools%3A%20WebIDE&product=Firefox&known_name=devtools_resolved_week&list_id=12157026 "External link (opens in new tab)").

### [CSS](#css)

*   Support of the [`<string>`](/en-US/docs/Web/CSS/Reference/Values/string) type on [`list-style-type`](/en-US/docs/Web/CSS/Reference/Properties/list-style-type), as well as its shorthand property [`list-style`](/en-US/docs/Web/CSS/Reference/Properties/list-style) has been implemented ([Firefox bug 1144607](https://bugzil.la/1144607 "External link (opens in new tab)")).
*   CSS Scroll Snapping has been implemented ([Firefox bug 945584](https://bugzil.la/945584 "External link (opens in new tab)") and [Firefox bug 1138658](https://bugzil.la/1138658 "External link (opens in new tab)")).
*   Cascading of CSS Animations and CSS Transitions has been rewritten to match the latest specification ([Firefox bug 1125455](https://bugzil.la/1125455 "External link (opens in new tab)")).
*   Support for vertical scripts, with the [`writing-mode`](/en-US/docs/Web/CSS/Reference/Properties/writing-mode) is now turned on by default on Nightly and Developer Edition, but not on Firefox Beta and Firefox Release ([Firefox bug 1099032](https://bugzil.la/1099032 "External link (opens in new tab)")). Note that implementation is not yet complete and some widgets, like tables, will not obey to all values.
*   CSS [`filter`](/en-US/docs/Web/CSS/Reference/Properties/filter) acts like position: relative + overflow: hidden ([Firefox bug 1125767](https://bugzil.la/1125767 "External link (opens in new tab)")).

### [HTML](#html)

*   A new [ARIA](/en-US/docs/Glossary/ARIA) role, `switch`, is now supported ([Firefox bug 1136563](https://bugzil.la/1136563 "External link (opens in new tab)")).
*   Support for `<link rel="preconnect">` allowing you to anticipate a future connection without revealing any information has been implemented ([Firefox bug 1135160](https://bugzil.la/1135160 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The [`RegExp` constructor](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp) no longer throws when the first argument is a `RegExp` and the second `flags` argument is present ([Firefox bug 1108949](https://bugzil.la/1108949 "External link (opens in new tab)")).
    
*   The `Object.prototype.__noSuchMethod__` property is now deprecated and throws a console warning (see [Firefox bug 1140428](https://bugzil.la/1140428 "External link (opens in new tab)") and this [platform announcement](https://groups.google.com/forum/#!topic/mozilla.dev.platform/0EkHgphxUo8 "External link (opens in new tab)")).
    
*   The implementation of the [`Proxy`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy) object has been updated to comply more with the ES2015 specification:
    
    *   The [`defineProperty`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy/Proxy/defineProperty) and [`set`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy/Proxy/set) handlers now need to explicitly return `true` to be successful, otherwise a [`TypeError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypeError) exception will be thrown in strict mode ([Firefox bug 1132522](https://bugzil.la/1132522 "External link (opens in new tab)")).
    *   If the [`window`](/en-US/docs/Web/API/Window) object is set as the target, those handlers will now throw a `TypeError` ([Firefox bug 828137](https://bugzil.la/828137 "External link (opens in new tab)")).
*   When using [arrow functions](/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions) (`=>`), a line terminator (`\n`) is no longer allowed after arrow function arguments (`() \n => {}`) ([Firefox bug 1141392](https://bugzil.la/1141392 "External link (opens in new tab)")).
    
*   [`RegExp.prototype.toString`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/toString) is now a generic function ([Firefox bug 1079919](https://bugzil.la/1079919 "External link (opens in new tab)")).
    
*   The non-standard `flags` argument of [`String.prototype.match()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/match), [`String.prototype.search()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/search), and [`String.prototype.replace()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/replace) is now deprecated and throws a console warning ([Firefox bug 1142351](https://bugzil.la/1142351 "External link (opens in new tab)")).
    
*   The try/catch behavior of [`Object.assign()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/assign) has been removed to conform with the latest ES2015 draft ([Firefox bug 1103344](https://bugzil.la/1103344 "External link (opens in new tab)")).
    

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   The experimental `CanvasRenderingContext2D.addHitRegion()` method now accepts a `path` option, which allows you to add hit regions to [`Path2D`](/en-US/docs/Web/API/Path2D) objects ([Firefox bug 1129147](https://bugzil.la/1129147 "External link (opens in new tab)")).
*   New methods have been added to manipulate [`FormData`](/en-US/docs/Web/API/FormData) objects ([Firefox bug 1085283](https://bugzil.la/1085283 "External link (opens in new tab)")) and `FormData` is now supported in Web workers ([Firefox bug 739173](https://bugzil.la/739173 "External link (opens in new tab)")).
*   The non-standard `XMLHttpRequest.sendAsBinary()` method has been removed. Refer to the [Sending and Receiving Binary Data](/en-US/docs/Web/API/XMLHttpRequest_API/Sending_and_Receiving_Binary_Data) documentation for alternatives ([Firefox bug 853162](https://bugzil.la/853162 "External link (opens in new tab)")).
*   Progress in our experimental implementation of Web Animations: [`AnimationPlayer.startTime`](/en-US/docs/Web/API/Animation/startTime "AnimationPlayer.startTime") is now writable ([Firefox bug 1073379](https://bugzil.la/1073379 "External link (opens in new tab)")).
*   Progress in our experimental implementation of [Service Workers](/en-US/docs/Web/API/Service_Worker_API): [`Cache`](/en-US/docs/Web/API/Cache) and [`CacheStorage`](/en-US/docs/Web/API/CacheStorage) interfaces are now implemented ([Firefox bug 940273](https://bugzil.la/940273 "External link (opens in new tab)")).
*   The experimental [Fetch API](/en-US/docs/Web/API/Fetch_API) has been activated by default ([Firefox bug 1133861](https://bugzil.la/1133861 "External link (opens in new tab)")).
*   Progress in our experimental implementation of WebGL2: [`WebGLSync`](/en-US/docs/Web/API/WebGLSync) is now implemented ([Firefox bug 1048721](https://bugzil.la/1048721 "External link (opens in new tab)")).
*   Support for [`MouseEvent.offsetX`](/en-US/docs/Web/API/MouseEvent/offsetX) and [`MouseEvent.offsetY`](/en-US/docs/Web/API/MouseEvent/offsetY) have been added on desktop ([Firefox bug 69787](https://bugzil.la/69787 "External link (opens in new tab)"), but not on Firefox for Android or Firefox OS (they will be added in [Firefox 43](/en-US/docs/Mozilla/Firefox/Releases/43))).

### [Miscellaneous](#miscellaneous)

*   [WOFF2](/en-US/docs/Web/CSS/Guides/Fonts/WOFF) fonts support is now turned on by default in release version of Firefox (Beta and Release, in addition of Nightly and Developer Edition) ([Firefox bug 1084026](https://bugzil.la/1084026 "External link (opens in new tab)")).
*   The [`-remote`](https://wiki.mozilla.org/Firefox/CommandLineOptions#-remote_remote_command "External link (opens in new tab)") command-line option has been removed ([Firefox bug 1080319](https://bugzil.la/1080319 "External link (opens in new tab)")).
*   Support for new [Unicode 8.0 skin tone emoji](https://www.bbc.co.uk/news/newsbeat-32220611 "External link (opens in new tab)") ([Firefox bug 1153460](https://bugzil.la/1153460 "External link (opens in new tab)")).
