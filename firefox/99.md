# Firefox 99 release notes for developers

This article provides information about the changes in Firefox 99 that will affect developers. Firefox 99 was released on April 5, 2022.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

No notable changes.

### [CSS](#css)

No notable changes.

### [JavaScript](#javascript)

No notable changes.

### [APIs](#apis)

*   [`navigator.pdfViewerEnabled`](/en-US/docs/Web/API/Navigator/pdfViewerEnabled) is now enabled, and is the recommended way to determine whether a browser supports inline display of PDF files when navigating to them. Sites that use the deprecated properties [`navigator.plugins`](/en-US/docs/Web/API/Navigator/plugins) and [`navigator.mimeTypes`](/en-US/docs/Web/API/Navigator/mimeTypes) to infer PDF viewer support should now use the new property, even though these now return hard-coded mock values that match the signal provided by `pdfViewerEnabled` ([Firefox bug 1720353](https://bugzil.la/1720353 "External link (opens in new tab)")).

#### Media, WebRTC, and Web Audio

*   The [`RTCPeerConnection.setConfiguration()`](/en-US/docs/Web/API/RTCPeerConnection/setConfiguration) method is now supported. Among other things, this allows sites to adjust the configuration to changing network conditions ([Firefox bug 1253706](https://bugzil.la/1253706 "External link (opens in new tab)")).

#### Removals

*   The [Network Information API](/en-US/docs/Web/API/Network_Information_API) was previously enabled on Android (only), but is now disabled by default on all platforms. This API is on the path for removal because it exposes a significant amount of user information that might be used for fingerprinting. ([Firefox bug 1637922](https://bugzil.la/1637922 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Fixed a bug where the Shift key was not handled properly when part of a key sequence of the `WebDriver:ElementSendKeys` command ([Firefox bug 1757636](https://bugzil.la/1757636 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

No notable changes.
