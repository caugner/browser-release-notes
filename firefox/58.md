# Firefox 58 release notes for developers

This article provides information about the changes in Firefox 58 that will affect developers. Firefox 58 was released on January 23, 2018.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   The [Shape Path Editor](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/edit_css_shapes/index.html "External link (opens in new tab)") has been enabled by default for shapes generated via [`clip-path`](/en-US/docs/Web/CSS/Reference/Properties/clip-path) ([Firefox bug 1405339](https://bugzil.la/1405339 "External link (opens in new tab)")).
*   The [Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html "External link (opens in new tab)") now has a button to [pause/play recording of network traffic](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html#pausing-and-resume-network-traffic-recording "External link (opens in new tab)") ([Firefox bug 1005755](https://bugzil.la/1005755 "External link (opens in new tab)")).
*   In the [Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html "External link (opens in new tab)") the "Flash" filter button is no longer available, and Flash requests are included in the "Others" filter ([Firefox bug 1413540](https://bugzil.la/1413540 "External link (opens in new tab)")).
*   The code for the old Responsive Design Mode (enabled by default pre-Firefox 52) has now been removed from the DevTools ([Firefox bug 1305777](https://bugzil.la/1305777 "External link (opens in new tab)")). See [Responsive Design Mode](https://firefox-source-docs.mozilla.org/devtools-user/responsive_design_mode/index.html "External link (opens in new tab)") for information on the new tools.
*   The option to view MDN docs from the CSS pane of the page inspector has been removed ([Firefox bug 1382171](https://bugzil.la/1382171 "External link (opens in new tab)")) (was disabled since 55, [Firefox bug 1352801](https://bugzil.la/1352801 "External link (opens in new tab)")).

### [HTML](#html)

_No changes._

### [CSS](#css)

*   The [`font-display`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face/font-display) descriptor is now available by default on all platforms ([Firefox bug 1317445](https://bugzil.la/1317445 "External link (opens in new tab)")).

### [SVG](#svg)

_No changes._

### [JavaScript](#javascript)

*   The [`Promise.prototype.finally()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/finally) method has been implemented ([Firefox bug 1019116](https://bugzil.la/1019116 "External link (opens in new tab)")).
*   The [`Intl.PluralRules`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) object has been implemented ([Firefox bug 1403318](https://bugzil.la/1403318 "External link (opens in new tab)")).
*   The [`Intl.NumberFormat.prototype.formatToParts()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/formatToParts) method has been implemented ([Firefox bug 1403319](https://bugzil.la/1403319 "External link (opens in new tab)")).
*   The [`Intl.DateTimeFormat`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat) object now supports the `hourCycle` option and the `hc` language tag ([Firefox bug 1386146](https://bugzil.la/1386146 "External link (opens in new tab)")).
*   The [optional catch binding proposal](https://github.com/tc39/proposal-optional-catch-binding "External link (opens in new tab)") has been implemented ([Firefox bug 1380881](https://bugzil.la/1380881 "External link (opens in new tab)")).

### [APIs](#apis)

#### New APIs

*   The [`PerformanceNavigationTiming`](/en-US/docs/Web/API/PerformanceNavigationTiming) API has been implemented ([Firefox bug 1263722](https://bugzil.la/1263722 "External link (opens in new tab)")).
    *   Gecko has also been given a pref that can be used to disable the interface if required — `dom.enable_performance_navigation_timing`, defaulting to `true` ([Firefox bug 1403926](https://bugzil.la/1403926 "External link (opens in new tab)")).

#### DOM

*   Errors reported via error objects in certain APIs — for example in the `error` property of [`FileReader`](/en-US/docs/Web/API/FileReader), [`IDBRequest`](/en-US/docs/Web/API/IDBRequest), and [`IDBTransaction`](/en-US/docs/Web/API/IDBTransaction), and when requests made via certain methods of [`RTCPeerConnection`](/en-US/docs/Web/API/RTCPeerConnection) are unsuccessful — are now represented by [`DOMException`](/en-US/docs/Web/API/DOMException) instances. [`DOMError`](/en-US/docs/Web/API/DOMError) is now deprecated, having been removed from the DOM4 spec ([Firefox bug 1120178](https://bugzil.la/1120178 "External link (opens in new tab)")).
*   The [`PerformanceResourceTiming.workerStart`](/en-US/docs/Web/API/PerformanceResourceTiming/workerStart) property is now supported ([Firefox bug 1191943](https://bugzil.la/1191943 "External link (opens in new tab)")).
*   Budget-based background timeout throttling has been implemented — see [Policies in place to aid background page performance](/en-US/docs/Web/API/Page_Visibility_API#policies_in_place_to_aid_background_page_performance) for more details ([Firefox bug 1377766](https://bugzil.la/1377766 "External link (opens in new tab)")).

#### DOM events

_No changes._

#### Media and WebRTC

*   The prefixed version of [`HTMLMediaElement.srcObject`](/en-US/docs/Web/API/HTMLMediaElement/srcObject) has been removed; make sure code is updated to use the standard `srcObject` instead of `mozSrcObject` ([Firefox bug 1183495](https://bugzil.la/1183495 "External link (opens in new tab)")).
*   Using [`MediaStream.addTrack()`](/en-US/docs/Web/API/MediaStream/addTrack) to add tracks to a stream obtained using [`getUserMedia()`](/en-US/docs/Web/API/MediaDevices/getUserMedia "getUserMedia()"), then attempting to record the resulting stream now works as expected. Previously, only the tracks originally included in the stream returned by `getUserMedia()` were being included in the recorded media ([Firefox bug 1296531](https://bugzil.la/1296531 "External link (opens in new tab)")).
*   The [WebVTT](/en-US/docs/Web/API/WebVTT_API) [`VTTRegion`](/en-US/docs/Web/API/VTTRegion) interface has always been created when interpreting WebVTT files, but the resulting regions were not previously utilized. Starting in Firefox 58, they are, if you enable the preference `media.webvtt.regions.enabled` by setting its value to `true`.

#### Canvas and WebGL

*   Support for prefixed WebGL extensions has been removed ([Firefox bug 1403413](https://bugzil.la/1403413 "External link (opens in new tab)")):
    *   For `MOZ_WEBGL_compressed_texture_atc` use `WEBGL_compressed_texture_atc` instead.
    *   For `MOZ_WEBGL_compressed_texture_pvrtc` use [`WEBGL_compressed_texture_pvrtc`](/en-US/docs/Web/API/WEBGL_compressed_texture_pvrtc) instead.
    *   For `MOZ_WEBGL_compressed_texture_s3tc` use [`WEBGL_compressed_texture_s3tc`](/en-US/docs/Web/API/WEBGL_compressed_texture_s3tc) instead.
    *   For `MOZ_WEBGL_depth_texture` use [`WEBGL_depth_texture`](/en-US/docs/Web/API/WEBGL_depth_texture) instead.
    *   For `MOZ_WEBGL_lose_context` use [`WEBGL_lose_context`](/en-US/docs/Web/API/WEBGL_lose_context) instead.

### [HTTP](#http)

*   [`frame-ancestors`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors) is no longer ignored in [`Content-Security-Policy-Report-Only`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy-Report-Only) ([Firefox bug 1380755](https://bugzil.la/1380755 "External link (opens in new tab)")).
*   Firefox now implements a TLS handshake timeout with a default value of 30 seconds. The timeout value can be varied by editing the `network.http.tls-handshake-timeout` pref in about:config ([Firefox bug 1393691](https://bugzil.la/1393691 "External link (opens in new tab)")).
*   The [`worker-src`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/worker-src) CSP directive has been implemented ([Firefox bug 1302667](https://bugzil.la/1302667 "External link (opens in new tab)")).
*   The [425: Too Early](/en-US/docs/Web/HTTP/Reference/Status/425) status code and related [`Early-Data`](/en-US/docs/Web/HTTP/Reference/Headers/Early-Data) request header are now supported ([Firefox bug 1406908](https://bugzil.la/1406908 "External link (opens in new tab)")).

### [Security](#security)

_No changes._

### [Plugins](#plugins)

_No changes._

### [Other](#other)

*   "Add to home screen" is now supported in Firefox for Android, part of the [Progressive Web Apps](/en-US/docs/Web/Progressive_web_apps) effort ([Firefox bug 1212648](https://bugzil.la/1212648 "External link (opens in new tab)")).
*   [WebAssembly](/en-US/docs/WebAssembly) now has a tiered compiler providing load time optimizations ([Firefox bug 1277562](https://bugzil.la/1277562 "External link (opens in new tab)")), and new streaming APIs — [`WebAssembly.compileStreaming()`](/en-US/docs/WebAssembly/Reference/JavaScript_interface/compileStreaming_static) and [`WebAssembly.instantiateStreaming()`](/en-US/docs/WebAssembly/Reference/JavaScript_interface/instantiateStreaming_static) [Firefox bug 1347644](https://bugzil.la/1347644 "External link (opens in new tab)").

## [Removals from the web platform](#removals_from_the_web_platform)

### [HTML](#html_2)

*   You can no longer nest an [`<a>`](/en-US/docs/Web/HTML/Reference/Elements/a) element inside a [`<map>`](/en-US/docs/Web/HTML/Reference/Elements/map) element to create a hotspot region — an [`<area>`](/en-US/docs/Web/HTML/Reference/Elements/area) element needs to be used instead ([Firefox bug 1317937](https://bugzil.la/1317937 "External link (opens in new tab)")).

### [CSS](#css_2)

*   The following proprietary Mozilla system metric pseudo-classes are no longer available to web content ([Firefox bug 1396066](https://bugzil.la/1396066 "External link (opens in new tab)")):
    
    *   `:-moz-system-metric(images-in-menus)`
    *   `:-moz-system-metric(mac-graphite-theme)`
    *   `:-moz-system-metric(scrollbar-end-backward)`
    *   `:-moz-system-metric(scrollbar-end-forward)`
    *   `:-moz-system-metric(scrollbar-start-backward)`
    *   `:-moz-system-metric(scrollbar-start-forward)`
    *   `:-moz-system-metric(scrollbar-thumb-proportional)`
    *   `:-moz-system-metric(touch-enabled)`
    *   `:-moz-system-metric(windows-default-theme)`
*   The following proprietary Mozilla media features are no longer available to web content ([Firefox bug 1396066](https://bugzil.la/1396066 "External link (opens in new tab)")):
    
    *   `-moz-color-picker-available`
    *   `-moz-is-glyph`
    *   `-moz-mac-graphite-theme`
    *   `-moz-mac-yosemite-theme`
    *   `-moz-os-version`
    *   `-moz-overlay-scrollbars`
    *   `-moz-physical-home-button`
    *   `-moz-scrollbar-end-backward`
    *   `-moz-scrollbar-end-forward`
    *   `-moz-scrollbar-start-backward`
    *   `-moz-scrollbar-start-forward`
    *   `-moz-scrollbar-thumb-proportional`
    *   `-moz-swipe-animation-enabled`
    *   `-moz-windows-accent-color-in-titlebar`
    *   `-moz-windows-classic`
    *   `-moz-windows-compositor`
    *   `-moz-windows-default-theme`
    *   `-moz-windows-glass`
    *   `-moz-windows-theme`
*   The proprietary Mozilla `:-moz-styleeditor-transitioning` pseudo-class is no longer available to web content ([Firefox bug 1396099](https://bugzil.la/1396099 "External link (opens in new tab)")).
    

### [JavaScript](#javascript_2)

*   The non-standard [`Date.prototype.toLocaleFormat()`](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#date_2) method has been removed ([Firefox bug 818634](https://bugzil.la/818634 "External link (opens in new tab)")).
*   The non-standard and deprecated [`Object.prototype.watch()` and `Object.prototype.unwatch()`](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#object_2) methods have been removed and will no longer work ([Firefox bug 638054](https://bugzil.la/638054 "External link (opens in new tab)")). Consider using [setters and getters](/en-US/docs/Web/JavaScript/Guide/Working_with_objects#defining_getters_and_setters) or [proxies](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy) instead.
*   The [legacy Iterator protocol](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#legacy_generator_and_iterator), the `StopIteration` object, the [legacy generator functions](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features) and the non-standard `Function.prototype.isGenerator()` method have been removed. Use the ES2015 [iteration protocols](/en-US/docs/Web/JavaScript/Reference/Iteration_protocols) and standards-compliant [iterators and generators](/en-US/docs/Web/JavaScript/Guide/Iterators_and_generators) instead ([Firefox bug 1083482](https://bugzil.la/1083482 "External link (opens in new tab)"), [Firefox bug 1413867](https://bugzil.la/1413867 "External link (opens in new tab)"), [Firefox bug 1119777](https://bugzil.la/1119777 "External link (opens in new tab)")).
*   The non-standard [Array comprehensions](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features) and [Generator comprehensions](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features) have been removed ([Firefox bug 1414340](https://bugzil.la/1414340 "External link (opens in new tab)")).

### [APIs](#apis_2)

*   The proprietary `moz-blob` and `moz-chunked-text` values of the [`XMLHttpRequest.responseType`](/en-US/docs/Web/API/XMLHttpRequest/responseType) property were removed completely in Firefox 58 ([Firefox bug 1397145](https://bugzil.la/1397145 "External link (opens in new tab)"), [Firefox bug 1397151](https://bugzil.la/1397151 "External link (opens in new tab)"), [Firefox bug 1120171](https://bugzil.la/1120171 "External link (opens in new tab)")).
*   The `dom.abortController.enabled` and `dom.abortController.fetch.enabled` prefs that controlled exposure of the [Abort API functionality](/en-US/docs/Web/API/Fetch_API/Using_Fetch#canceling_a_request) have now been removed, since those features are now enabled by default ([Firefox bug 1402317](https://bugzil.la/1402317 "External link (opens in new tab)")).
*   The proprietary `mozSrcObject` property was removed in Firefox 58 ([Firefox bug 1183495](https://bugzil.la/1183495 "External link (opens in new tab)")). Use the standard [`HTMLMediaElement.srcObject`](/en-US/docs/Web/API/HTMLMediaElement/srcObject) property instead.

### [SVG](#svg_2)

_No changes._

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

### [WebExtensions](#webextensions)

*   [browserSettings](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browserSettings)
    
    *   [browserSettings.webNotificationsDisabled](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browserSettings/webNotificationsDisabled) has been implemented (bug 1364942)
*   [browsingData](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browsingData)
    
    *   [browsingData.localStorage](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browsingData/removeLocalStorage) now supports deleting localStorage by host (bug 1388428)
*   [pkcs11](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/pkcs11) API to manage security devices (Bug 1357391)
    
*   privacy
    
    *   first party isolation can now be toggled though firstPartyIsolate (bug 1409045)
    *   resist fingerprinting pref can now be toggle through resistFingerprinting (bug [1397611)](https://bugzil.la/1397611 "External link (opens in new tab)")
*   tabs
    
    *   [`tabs.discard`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/tabs/discard) has been implemented (Bug 1322485)
    *   isArticle, isInReaderMode properties of Tab implemented (Bug 1381992)
    *   [`toggleReaderMode()`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/tabs/toggleReaderMode) method implemented (Bug 1381992)
    *   openInReaderMode option of tabs.created implemented (Bug 1408993)
    *   tabs.onUpdated now notifies when entering/exiting reader mode (Bug 1402921)
*   theme
    
    *   [`getCurrent()`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/theme/getCurrent) method to obtain current theme properties (Bug [1349944](https://bugzil.la/1349944 "External link (opens in new tab)"))
    *   onUpdated method to receive WebExtension theme updates (Bug [1349944](https://bugzil.la/1349944 "External link (opens in new tab)"))
    *   colors.bookmark\_text now supported as alias of colors.toolbar\_text (Bug [1412595](https://bugzil.la/1412595 "External link (opens in new tab)"))
    *   colors.toolbar\_top\_separator, colors.toolbar\_bottom\_separator and colors.toolbar\_vertical\_separator implemented (Bug [1347190)](https://bugzil.la/1347190 "External link (opens in new tab)")
*   webRequest
    
    *   [webRequest.onBeforeRequest](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest/onBeforeRequest) now includes a "frameAncestors" parameter
