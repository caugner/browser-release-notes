# Firefox 73 release notes for developers

This article provides information about the changes in Firefox 73 that will affect developers. Firefox 73 was released on February 11, 2020.

## [Changes for web developers](#changes_for_web_developers)

### [Developer tools](#developer_tools)

*   [CORS errors](/en-US/docs/Web/HTTP/Guides/CORS/Errors) now appear as errors in the console (and no longer as warnings) giving them the appropriate visibility ([Firefox bug 1602093](https://bugzil.la/1602093 "External link (opens in new tab)")).
*   Text and regular expression searches in the web console [can now be negated by prefixing them with '-'](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#filtering-and-searching "External link (opens in new tab)") ([Firefox bug 1291192](https://bugzil.la/1291192 "External link (opens in new tab)")).

### [HTML](#html)

_No changes._

### [CSS](#css)

*   We've implemented [`overscroll-behavior-block`](/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior-block) and [`overscroll-behavior-inline`](/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior-inline), the logical mappings for [`overscroll-behavior-x`](/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior-x) and [`overscroll-behavior-y`](/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior-y) ([Firefox bug 833953](https://bugzil.la/833953 "External link (opens in new tab)")).

#### Removals

*   The proprietary `-moz-touch-enabled` media query has been removed ([Firefox bug 1486964](https://bugzil.la/1486964 "External link (opens in new tab)")). You should use [`pointer: coarse`](/en-US/docs/Web/CSS/Reference/At-rules/@media/pointer) instead.

### [SVG](#svg)

*   The [`letter-spacing`](/en-US/docs/Web/SVG/Reference/Attribute/letter-spacing) and [`word-spacing`](/en-US/docs/Web/SVG/Reference/Attribute/word-spacing) properties now work in SVG ([Firefox bug 371787](https://bugzil.la/371787 "External link (opens in new tab)")).

### [MathML](#mathml)

#### Removals

*   The deprecated [`<mfenced>`](/en-US/docs/Web/MathML/Reference/Element/mfenced "<mfenced>") element has been removed ([Firefox bug 1603773](https://bugzil.la/1603773 "External link (opens in new tab)")). Use the [`<mrow>`](/en-US/docs/Web/MathML/Reference/Element/mrow "<mrow>") and [`<mo>`](/en-US/docs/Web/MathML/Reference/Element/mo "<mo>") elements instead.

### [JavaScript](#javascript)

*   The `yearName` and `relatedYear` fields have been made available in the [`DateTimeFormat.prototype.formatToParts()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/formatToParts) method, enabling useful formatting options for CJK calendars ([Firefox bug 1591664](https://bugzil.la/1591664 "External link (opens in new tab)")).

### [APIs](#apis)

#### DOM

*   The [`innerWidth`](/en-US/docs/Web/API/Window/innerWidth "innerWidth") and [`innerHeight`](/en-US/docs/Web/API/Window/innerHeight "innerHeight") properties on [`Window`](/en-US/docs/Web/API/Window) objects have been updated to return the width and height of the layout viewport in all situations, rather than sometimes being based on the visual viewport. In particular, previously when using [Responsive Design Mode](https://firefox-source-docs.mozilla.org/devtools-user/responsive_design_mode/index.html "External link (opens in new tab)"), these returned the visual viewport dimensions, causing the behavior to vary from what was expected ([Firefox bug 1514429](https://bugzil.la/1514429 "External link (opens in new tab)")).

#### WebVR

*   The deprecated [WebVR API](/en-US/docs/Web/API/WebVR_API)—which has been supplanted by [WebXR](/en-US/docs/Web/API/WebXR_Device_API), which supports both [augmented](https://en.wikipedia.org/wiki/Augmented_reality "External link (opens in new tab)") and [virtual reality](https://en.wikipedia.org/wiki/Virtual_reality "External link (opens in new tab)") applications—now [requires a secure context](/en-US/docs/Web/API/WebVR_API#api_availability) using the [HTTPS](/en-US/docs/Glossary/HTTPS) protocol to operate. This is due to the availability of sensitive input sources that may include private information ([Firefox bug 1381645](https://bugzil.la/1381645 "External link (opens in new tab)")).

#### Removals

*   Support for the [`VideoPlaybackQuality`](/en-US/docs/Web/API/VideoPlaybackQuality) property [`corruptedVideoFrames`](/en-US/docs/Web/API/VideoPlaybackQuality/corruptedVideoFrames "corruptedVideoFrames"), which has been deprecated in the specification, has been removed from Firefox ([Firefox bug 1602163](https://bugzil.la/1602163 "External link (opens in new tab)")).

### [Security](#security)

_No changes._

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Added `WebDriver:Print` to print the current page as a PDF document ([Firefox bug 1604506](https://bugzil.la/1604506 "External link (opens in new tab)")).
*   `Webdriver:TakeScreenshot` now always captures the top-level browsing context and not the currently-selected browsing context, if no element to capture has been specified ([Firefox bug 1398087](https://bugzil.la/1398087 "External link (opens in new tab)"), [Firefox bug 1606794](https://bugzil.la/1606794 "External link (opens in new tab)")).
*   Using `Webdriver:TakeScreenshot`'s `full` argument causes the complete page to be captured ([Firefox bug 1571424](https://bugzil.la/1571424 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

### [API changes](#api_changes)

*   The [`sidebarAction.toggle()`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/sidebarAction/toggle) function has been implemented ([bug 1453355](https://bugzil.la/1453355 "External link (opens in new tab)")).

### [Manifest changes](#manifest_changes)

_No changes._
