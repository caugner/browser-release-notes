# Firefox 33 release notes for developers

Firefox 33 was released on October 14, 2014. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights

*   Event listeners popup
*   @media sidebar
*   Add new rule
*   Edit keyframes
*   Cubic bezier editor
*   Transform highlighter
*   Persistent disable cache
*   New Commands
*   Editor preferences
*   WebIDE

For details please [see the hacks post](https://hacks.mozilla.org/2014/07/event-listeners-popup-media-sidebar-cubic-bezier-editor-more-firefox-developer-tools-episode-33/ "External link (opens in new tab)"). Special thanks to the 33 contributors that added [all the features and fixes](https://mzl.la/1pGLFDs "External link (opens in new tab)") in this release.

### [CSS](#css)

*   Implemented [`@counter-style`](/en-US/docs/Web/CSS/Reference/At-rules/@counter-style) rule ([Firefox bug 966166](https://bugzil.la/966166 "External link (opens in new tab)")).
*   Unprefixed `ethiopic-numeric`, `persian`, `arabic-indic`, `devanagari`, `bengali`, `gurmukhi`, `gujarati`, `oriya`, `tamil`, `telugu`, `kannada`, `malayalam`, `thai`, `lao`, `myanmar`, `khmer`, `cjk-heavenly-stem`, `cjk-earthly-branch` in [`list-style-type`](/en-US/docs/Web/CSS/Reference/Properties/list-style-type) ([Firefox bug 985825](https://bugzil.la/985825 "External link (opens in new tab)") and [Firefox bug 1063856](https://bugzil.la/1063856 "External link (opens in new tab)")).
*   Added support for `mongolian`, `disclosure-open` and `disclosure-closed` counter styles in [`list-style-type`](/en-US/docs/Web/CSS/Reference/Properties/list-style-type) ([Firefox bug 982355](https://bugzil.la/982355 "External link (opens in new tab)") and [Firefox bug 1063856](https://bugzil.la/1063856 "External link (opens in new tab)")).
*   Fixed CSS animations with empty keyframes rule so they also dispatch events ([Firefox bug 1004377](https://bugzil.la/1004377 "External link (opens in new tab)")).
*   Added support for `rebeccapurple`, a new [`<color>`](/en-US/docs/Web/CSS/Reference/Values/color_value) name defined in CSS Colors level 4 ([Firefox bug 1024642](https://bugzil.la/1024642 "External link (opens in new tab)")).
*   Our experimental implementation of CSS Fonts Level 3 is progressing. Its activation is governed by the `layout.css.font-features.enabled` preference, enabled by default in Nightly. Newly implemented features are:
    *   The fallback algorithm of [`font-variant-caps`](/en-US/docs/Web/CSS/Reference/Properties/font-variant-caps), creating synthetic alternates for missing glyphs ([Firefox bug 961558](https://bugzil.la/961558 "External link (opens in new tab)")).
    *   The [`font-synthesis`](/en-US/docs/Web/CSS/Reference/Properties/font-synthesis) CSS property has been implemented ([Firefox bug 871453](https://bugzil.la/871453 "External link (opens in new tab)")).

### [HTML](#html)

*   Added the experimental support for [`<picture>`](/en-US/docs/Web/HTML/Reference/Elements/picture) element ([Firefox bug 870022](https://bugzil.la/870022 "External link (opens in new tab)")), behind the `dom.image.picture.enabled` preference (off by default).
    
*   The [`<label>`](/en-US/docs/Web/HTML/Reference/Elements/label), especially without a [`for`](/en-US/docs/Web/HTML/Reference/Elements/label#for) attribute, doesn't apply anymore to a `<input type=hidden>` field ([Firefox bug 597650](https://bugzil.la/597650 "External link (opens in new tab)")). The previous behavior wasn't spec-compliant.
    
*   The link annotation `noreferrer` has been implemented on [`<a>`](/en-US/docs/Web/HTML/Reference/Elements/a) elements. `<a rel="noreferrer">` will not include the URL of the referrer in the HTTP request sent to fetch it ([Firefox bug 530396](https://bugzil.la/530396 "External link (opens in new tab)")). Note that this works only for in-page links, not for links clicked via the UI, like via contextual menus.
    
*   On Android, support for two new values for the [`name`](/en-US/docs/Web/HTML/Reference/Elements/meta/name) attribute of [`<meta>`](/en-US/docs/Web/HTML/Reference/Elements/meta) has been added: `msapplication-TileImage` and `msapplication-TileColor` ([Firefox bug 1014712](https://bugzil.la/1014712 "External link (opens in new tab)")). Example:
    
    html
    
    ```
    <meta name="msapplication-TileImage" content="images/my-img-144.png" />
    <meta name="msapplication-TileColor" content="#d83434" />
    ```
    

### [JavaScript](#javascript)

*   The non-standard method `Number.toInteger()` has been removed ([Firefox bug 1022396](https://bugzil.la/1022396 "External link (opens in new tab)")).
*   The [`Map.prototype.set()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/set), [`WeakMap.prototype.set()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakMap/set) and [`Set.prototype.add()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/add) methods are now chainable, return their equivalent objects and no longer `undefined` ([Firefox bug 1031632](https://bugzil.la/1031632 "External link (opens in new tab)")).
*   A [default parameter](/en-US/docs/Web/JavaScript/Reference/Functions/Default_parameters) is evaluated before function declarations inside the function body, so those functions cannot be referred from the default parameter ([Firefox bug 1022962](https://bugzil.la/1022962 "External link (opens in new tab)")).
*   Shorthand properties are now allowed in object literals: if not explicitly defined, property keys are initialized by variables of the same name. E.g. `function f(x, y) { return {x, y}; }` is equivalent to `function f(x, y) { return {x: x, y: y}; }` ([Firefox bug 875002](https://bugzil.la/875002 "External link (opens in new tab)")).
*   The parsing of [`yield`](/en-US/docs/Web/JavaScript/Reference/Operators/yield) and [`yield*`](/en-US/docs/Web/JavaScript/Reference/Operators/yield*) has been updated to conform with the latest ES2015 specification ([Firefox bug 981599](https://bugzil.la/981599 "External link (opens in new tab)")).
*   The non-standard `hasOwn` trap has been removed ([Firefox bug 980565](https://bugzil.la/980565 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   The [`RadioNodeList`](/en-US/docs/Web/API/RadioNodeList) API has been implemented and the selected radio button is accessible via [`RadioNodeList.value`](/en-US/docs/Web/API/RadioNodeList/value) ([Firefox bug 779723](https://bugzil.la/779723 "External link (opens in new tab)")).
*   The [`DOMMatrix`](/en-US/docs/Web/API/DOMMatrix) has been added ([Firefox bug 1018497](https://bugzil.la/1018497 "External link (opens in new tab)")).
*   A non-standard (but implemented in other browsers) `DOMException.stack` property has been added. It returns a string with a human-friendly formatted stack ([Firefox bug 857648](https://bugzil.la/857648 "External link (opens in new tab)")), in the same format as the existing non-standard [`Error.stack`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/stack) property.
*   For [`<canvas>`](/en-US/docs/Web/HTML/Reference/Elements/canvas), the method [`CanvasPattern.setTransform()`](/en-US/docs/Web/API/CanvasPattern/setTransform), allowing you to modify a pattern using the [`DOMMatrix`](/en-US/docs/Web/API/DOMMatrix) representation of a linear transform ([Firefox bug 1019257](https://bugzil.la/1019257 "External link (opens in new tab)")).
*   Our experimental implementation of Media Source Extensions, behind the `media.mediasource.enabled` preference, enabled by default in Nightly and Aurora only, now supports MP4 ([Firefox bug 1000686](https://bugzil.la/1000686 "External link (opens in new tab)")).
*   The properties [`HTMLMediaElement.audioTracks`](/en-US/docs/Web/API/HTMLMediaElement/audioTracks) and [`HTMLMediaElement.videoTracks`](/en-US/docs/Web/API/HTMLMediaElement/videoTracks) have been experimentally implemented. They are controlled by the `media.track.enabled`, off by default ([Firefox bug 744896](https://bugzil.la/744896 "External link (opens in new tab)")).
*   The non-standard `XMLHttpRequest.mozBackgroundRequest()` is no more accessible from websites. Only Firefox-internal code (Chrome code) can use it ([Firefox bug 1035242](https://bugzil.la/1035242 "External link (opens in new tab)")).
*   The `touchenter` and `touchleave` events, removed from the specification, have been removed ([Firefox bug 1036444](https://bugzil.la/1036444 "External link (opens in new tab)")).
*   The formerly called `loaded` event, sent on a [`HTMLTrackElement`](/en-US/docs/Web/API/HTMLTrackElement) has been renamed [`load`](/en-US/docs/Web/API/Window/load_event "load") to match the specification ([Firefox bug 1035505](https://bugzil.la/1035505 "External link (opens in new tab)")).
*   The IndexedDB interface `FileHandle` has been renamed in `IDBMutableFile` ([Firefox bug 1006485](https://bugzil.la/1006485 "External link (opens in new tab)")).
*   The IndexedDB interface `LockedFile` has been renamed in `IDBFileHandle` ([Firefox bug 1006485](https://bugzil.la/1006485 "External link (opens in new tab)")).
*   The [`ServiceWorker`](/en-US/docs/Web/API/ServiceWorker) interface has been implemented behind the `dom.serviceWorkers.enabled` flag ([Firefox bug 903441](https://bugzil.la/903441 "External link (opens in new tab)")).
*   The [`NetworkInformation.type`](/en-US/docs/Web/API/NetworkInformation/type) now also support the `"unknown"` value ([Firefox bug 1023029](https://bugzil.la/1023029 "External link (opens in new tab)")).

### [MathML](#mathml)

*   The attributes `columnspacing`, `framespacing`, and `rowspacing` of the [`<mtable>`](/en-US/docs/Web/MathML/Reference/Element/mtable "<mtable>") element are now supported ([Firefox bug 330964](https://bugzil.la/330964 "External link (opens in new tab)")).
*   Use [Open Type MATH](https://wiki.mozilla.org/MathML:Open_Type_MATH_Table#Implementation_Status "External link (opens in new tab)") constants for fractions, stacks, radicals, and scripts ([Firefox bug 961365](https://bugzil.la/961365 "External link (opens in new tab)")).

### [SVG](#svg)

_No change._

### [Audio/Video/WebRTC](#audiovideowebrtc)

*   The `RTCOfferOptions` dictionary, used to provide options when calling [`RTCPeerConnection.createOffer()`](/en-US/docs/Web/API/RTCPeerConnection/createOffer), has been implemented.

### [WebGL](#webgl)

*   [`EXT_blend_minmax`](/en-US/docs/Web/API/EXT_blend_minmax) is now exposed. It extends blending capabilities by adding two new blend equations: producing the minimum or maximum color components of the source and destination colors ([Firefox bug 973815](https://bugzil.la/973815 "External link (opens in new tab)")).

## [Security](#security)

*   The [CSP](/en-US/docs/Web/HTTP/Guides/CSP) 1.1 `frame-ancestors` [directive](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) is now supported ([Firefox bug 846978](https://bugzil.la/846978 "External link (opens in new tab)")).

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

*   The JavaScript Debugger Service (JSD) has been removed in favor of the new [Debugger API](https://firefox-source-docs.mozilla.org/devtools-user/debugger-api/index.html "External link (opens in new tab)") ([Firefox bug 800200](https://bugzil.la/800200 "External link (opens in new tab)")).
*   The interface nsIX509CertDB2 has been removed and the methods from that interface have been moved to the nsIX509CertDB interface.

### [Add-on SDK](#add-on_sdk)

#### Highlights

*   Added support for context menus in panels via a new option in the `Panel` constructor.
*   Added `tab.readyState`.
*   Added a `BrowserWindow` parameter to `sidebar.show()` and `sidebar.hide()`, to control the window for which the sidebar will be shown or hidden.
