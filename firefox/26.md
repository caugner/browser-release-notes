# Firefox 26 release notes for developers

Firefox 26 was released on December 10, 2013. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [CSS](#css)

*   The [`text-decoration-line`](/en-US/docs/Web/CSS/Reference/Properties/text-decoration-line) property, still prefixed, now considers `'blink'` as a valid value, though it doesn't blink the content at all ([Firefox bug 812995](https://bugzil.la/812995 "External link (opens in new tab)")).
*   The non-standard `-moz-text-blink` property has been removed ([Firefox bug 812995](https://bugzil.la/812995 "External link (opens in new tab)")).
*   Support for the [`image-orientation`](/en-US/docs/Web/CSS/Reference/Properties/image-orientation) property, in its CSS Images & Values Level 4 version, that is with the `from-image` keyword and EXIF support, has been added ([Firefox bug 825771](https://bugzil.la/825771 "External link (opens in new tab)")).
*   Experimental support for `position: sticky` has been implemented and can be enabled by pref `layout.css.sticky.enabled` ([Firefox bug 886646](https://bugzil.la/886646 "External link (opens in new tab)")).
*   The [`text-align`](/en-US/docs/Web/CSS/Reference/Properties/text-align) property now applies to the `::-moz-placeholder` pseudo-element ([Firefox bug 915551](https://bugzil.la/915551 "External link (opens in new tab)")).

### [HTML](#html)

*   The `HTMLSelectElement.selectedOptions` property has been implemented ([Firefox bug 596681](https://bugzil.la/596681 "External link (opens in new tab)")).
*   In the [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) element of type `email`, values with domain labels longer than 63 chars are no more considered valid ([Firefox bug 884332](https://bugzil.la/884332 "External link (opens in new tab)")).
*   The `HTMLInputElement.width` and `height` properties now return `0` when the `type` is not `image` ([Firefox bug 905240](https://bugzil.la/905240 "External link (opens in new tab)")).
*   A [`<fieldset>`](/en-US/docs/Web/HTML/Reference/Elements/fieldset) element is now invalid, and can be styled using the [`:invalid`](/en-US/docs/Web/CSS/Reference/Selectors/:invalid) pseudo-class, when one of the elements it contains is invalid ([Firefox bug 717181](https://bugzil.la/717181 "External link (opens in new tab)")).

### [JavaScript](#javascript)

ECMAScript 2015 implementation continues!

*   The ECMAScript 2015 compliant syntax for [Generators (yield)](https://web.archive.org/web/20170126155949/http://wiki.ecmascript.org/doku.php?id=harmony:generators "External link (opens in new tab)") has been implemented ([Firefox bug 666399](https://bugzil.la/666399 "External link (opens in new tab)")).
*   Generator/Iterator results are now boxed like `{ value: foo, done: bool }` ([Firefox bug 907744](https://bugzil.la/907744 "External link (opens in new tab)")).
*   New mathematical methods have been implemented on [`Math`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math): [`Math.fround()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/fround) ([Firefox bug 900125](https://bugzil.la/900125 "External link (opens in new tab)")).
*   The [reserved words](/en-US/docs/Web/JavaScript/Reference/Lexical_grammar#keywords) cannot be used for function names:such a usage now throws a [`SyntaxError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/SyntaxError) ([Firefox bug 907958](https://bugzil.la/907958 "External link (opens in new tab)")).
*   The [default parameter](/en-US/docs/Web/JavaScript/Reference/Functions/Default_parameters) syntax has been updated to allow parameters without defaults after default parameters, such as `function f(x=1, y)`. See [Firefox bug 777060](https://bugzil.la/777060 "External link (opens in new tab)").
*   [`GeneratorFunction`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/GeneratorFunction) is implemented ([Firefox bug 904701](https://bugzil.la/904701 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   Make the last argument (doctype) to [`DOMImplementation.createDocument`](/en-US/docs/Web/API/DOMImplementation/createDocument) optional ([Firefox bug 909859](https://bugzil.la/909859 "External link (opens in new tab)")).
*   Implement the new [`element.classList`](/en-US/docs/Web/API/Element/classList) specification which permits adding/removing several classes with one call ([Firefox bug 814014](https://bugzil.la/814014 "External link (opens in new tab)")).
*   The [`URL()`](/en-US/docs/Web/API/URL/URL "URL()") constructor has been implemented on the [`URL`](/en-US/docs/Web/API/URL) interface ([Firefox bug 887364](https://bugzil.la/887364 "External link (opens in new tab)")).
*   The properties [`URLUtils.origin`](/en-US/docs/Web/API/HTMLAnchorElement/origin "URLUtils.origin"), [`URLUtils.password`](/en-US/docs/Web/API/HTMLAnchorElement/password "URLUtils.password"), and [`URLUtils.username`](/en-US/docs/Web/API/HTMLAnchorElement/username "URLUtils.username") are now available to all interfaces implementing the `URLUtils` mixin: [`URL`](/en-US/docs/Web/API/URL), [`Location`](/en-US/docs/Web/API/Location), [`HTMLAnchorElement`](/en-US/docs/Web/API/HTMLAnchorElement), and [`HTMLAreaElement`](/en-US/docs/Web/API/HTMLAreaElement) ([Firefox bug 887364](https://bugzil.la/887364 "External link (opens in new tab)")).
*   The [`URL`](/en-US/docs/Web/API/URL) interface is now accessible from Web Workers ([Firefox bug 887364](https://bugzil.la/887364 "External link (opens in new tab)")).
*   IndexedDB can now be used as an "optimistic" storage area so it doesn't require any prompts and data is stored in a pool with LRU eviction policy, in short temporary storage ([Firefox bug 785884](https://bugzil.la/785884 "External link (opens in new tab)")).
*   Support for [`WaveShaperNode.oversample`](/en-US/docs/Web/API/WaveShaperNode/oversample) has been added ([Firefox bug 875277](https://bugzil.la/875277 "External link (opens in new tab)")).
*   Path of the persistent storage has been changed from `<profile>/indexedDB` to `<profile>/storage/persistent` (on b2g from `/data/local/indexedDB` to `/data/local/storage/persistent`).
*   The [`Screen.orientation`](/en-US/docs/Web/API/Screen/orientation) property and [`Screen.lockOrientation()`](/en-US/docs/Web/API/Screen/lockOrientation) method now support the `default` value, mapping to `portrait-primary` or `landscape-primary`, depending on the device ([Firefox bug 908058](https://bugzil.la/908058 "External link (opens in new tab)")) This works only for Firefox OS and Firefox for Android. Firefox Desktop is not supported.
*   [`Event`](/en-US/docs/Web/API/Event) constructors can be used in Web workers ([Firefox bug 910910](https://bugzil.la/910910 "External link (opens in new tab)")).
*   Trying to set the [`Document.domain`](/en-US/docs/Web/API/Document/domain) property on a page embedded in an [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) with the `sandbox` attribute now throws a security error ([Firefox bug 907892](https://bugzil.la/907892 "External link (opens in new tab)")).
*   The [`MessageEvent`](/en-US/docs/Web/API/MessageEvent) interface has been updated to comply with the latest spec. The `initMessageEvent` method has been removed while the interface has now a constructor ([Firefox bug 848294](https://bugzil.la/848294 "External link (opens in new tab)")).
*   The HTML5 `MessageChannel` API has been implemented, behind the `dom.messageChannel.enabled` preference ([Firefox bug 677638](https://bugzil.la/677638 "External link (opens in new tab)")).
*   Support for `VTTCue`, behind the `media.webvtt.enabled` preference, like for all WebVTT-related implementations, has been added ([Firefox bug 868509](https://bugzil.la/868509 "External link (opens in new tab)")).
*   The [Web Audio API](/en-US/docs/Web/API/Web_Audio_API) has been made available by default ([Firefox bug 885505](https://bugzil.la/885505 "External link (opens in new tab)")).

### [MathML](#mathml)

*   Inconsistent renderings of [`<mmultiscripts>`](/en-US/docs/Web/MathML/Reference/Element/mmultiscripts "<mmultiscripts>"), [`<msub>`](/en-US/docs/Web/MathML/Reference/Element/msub "<msub>"), [`<msup>`](/en-US/docs/Web/MathML/Reference/Element/msup "<msup>") and [`<msubsup>`](/en-US/docs/Web/MathML/Reference/Element/msubsup "<msubsup>") have been unified and the error handling of these elements has been improved ([Firefox bug 827713](https://bugzil.la/827713 "External link (opens in new tab)")).

### [SVG](#svg)

*   The inclusion of SVG glyphs inside OpenType, _SVG-in-OpenType_, has been updated to match the current version of the specification ([Firefox bug 906521](https://bugzil.la/906521 "External link (opens in new tab)")).
*   The `SVGElement.ownerSVGElement()` method doesn't throw anymore ([Firefox bug 835048](https://bugzil.la/835048 "External link (opens in new tab)")).

## [Development tools](#development_tools)

*   The Inspector is now remotable ([Firefox bug 805526](https://bugzil.la/805526 "External link (opens in new tab)")).
*   The web console text can be selected, [`::before`](/en-US/docs/Web/CSS/Reference/Selectors/::before) and [`::after`](/en-US/docs/Web/CSS/Reference/Selectors/::after) now inspectable, debugger and responsive design features are planned for this release. ([https://hacks.mozilla.org/2013/09/new-features-in-the-firefox-developer-tools-episode-26/](https://hacks.mozilla.org/2013/09/new-features-in-the-firefox-developer-tools-episode-26/ "External link (opens in new tab)"))
