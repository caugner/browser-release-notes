# Firefox 72 release notes for developers

This article provides information about the changes in Firefox 72 that will affect developers. Firefox 72 was released on January 7, 2020.

## [Changes for web developers](#changes_for_web_developers)

### [Developer tools](#developer_tools)

[Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html "External link (opens in new tab)"):

*   In the [multi-line mode of the interactive JS interpreter](https://firefox-source-docs.mozilla.org/devtools-user/web_console/the_command_line_interpreter/index.html#multi-line-mode "External link (opens in new tab)"), you can open and save files using the keyboard shortcuts `Ctrl` + `O` and `Ctrl` + `S`, respectively ([Firefox bug 1592308](https://bugzil.la/1592308 "External link (opens in new tab)")).
*   You can set a [preference so that asynchronous messages are visually separated](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#async-stack-frames "External link (opens in new tab)") ([Firefox bug 1592969](https://bugzil.la/1592969 "External link (opens in new tab)")).

[JavaScript debugger](https://firefox-source-docs.mozilla.org/devtools-user/debugger/index.html "External link (opens in new tab)"):

*   You can now right/`Ctrl` click on objects in the Scopes panel, and choose _Property set_ or _Property get_ to [set watchpoints](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/use_watchpoints/index.html#set-a-watchpoint "External link (opens in new tab)") ([Firefox bug 1574192](https://bugzil.la/1574192 "External link (opens in new tab)")).

[Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html "External link (opens in new tab)"):

*   The Timings tab now shows [queued, started, and downloaded](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_details/index.html#queued-started-downloaded "External link (opens in new tab)") times for each resource ([Firefox bug 1580431](https://bugzil.la/1580431 "External link (opens in new tab)")).

[Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html "External link (opens in new tab)"):

*   You can set a [preference to enable a simulator](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#view-media-rules-for-color-scheme-preference "External link (opens in new tab)") for different values of the [`prefers-color-scheme`](/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme) media feature ([Firefox bug 1550804](https://bugzil.la/1550804 "External link (opens in new tab)")).

#### Removals

*   The _Scratchpad_ feature has been removed ([Firefox bug 1519103](https://bugzil.la/1519103 "External link (opens in new tab)")).

### [HTML](#html)

_No changes._

### [CSS](#css)

*   CSS Shadow Parts are now enabled. This includes the [`part` attribute](/en-US/docs/Web/HTML/Reference/Global_attributes/part) and [`::part` pseudo-element](/en-US/docs/Web/CSS/Reference/Selectors/::part), which allow shadow hosts to selectively expose chosen elements from their shadow tree to the outside page for styling purposes ([Firefox bug 1559074](https://bugzil.la/1559074 "External link (opens in new tab)")).
    
*   [CSS Motion Path](/en-US/docs/Web/CSS/Guides/Motion_path) has been shipped ([Firefox bug 1582554](https://bugzil.la/1582554 "External link (opens in new tab)"), also see the [Intent to Ship](https://groups.google.com/forum/#!topic/mozilla.dev.platform/nOOIRsuxvuc "External link (opens in new tab)")). This includes:
    
    *   [`offset`](/en-US/docs/Web/CSS/Reference/Properties/offset)
    *   [`offset-path`](/en-US/docs/Web/CSS/Reference/Properties/offset-path)
    *   [`offset-anchor`](/en-US/docs/Web/CSS/Reference/Properties/offset-anchor)
    *   [`offset-distance`](/en-US/docs/Web/CSS/Reference/Properties/offset-distance)
    *   [`offset-rotate`](/en-US/docs/Web/CSS/Reference/Properties/offset-rotate)
*   The individual transform properties — [`scale`](/en-US/docs/Web/CSS/Reference/Properties/scale), [`rotate`](/en-US/docs/Web/CSS/Reference/Properties/rotate), and [`translate`](/en-US/docs/Web/CSS/Reference/Properties/translate) — are now enabled by default ([Firefox bug 1424900](https://bugzil.la/1424900 "External link (opens in new tab)")).
    

#### Removals

### [SVG](#svg)

_No changes._

### [JavaScript](#javascript)

*   The [nullish coalescing operator](/en-US/docs/Web/JavaScript/Reference/Operators/Nullish_coalescing) has been implemented ([Firefox bug 1566141](https://bugzil.la/1566141 "External link (opens in new tab)")).

### [APIs](#apis)

#### New APIs

*   [`FormDataEvent`](/en-US/docs/Web/API/FormDataEvent) and [event-based form participation](/en-US/docs/Web/API/XMLHttpRequest_API/Using_FormData_Objects#using_a_formdata_event) is now enabled by default ([Firefox bug 1594708](https://bugzil.la/1594708 "External link (opens in new tab)")).
*   The [`Window.crossOriginIsolated`](/en-US/docs/Web/API/Window/crossOriginIsolated) property and the [`WorkerGlobalScope.crossOriginIsolated`](/en-US/docs/Web/API/WorkerGlobalScope/crossOriginIsolated) property is now supported ([Firefox bug 1591892](https://bugzil.la/1591892 "External link (opens in new tab)")).

#### DOM

*   The [Geolocation API](/en-US/docs/Web/API/Geolocation_API) has had some interface name updates, as per recent spec changes ([Firefox bug 1575144](https://bugzil.la/1575144 "External link (opens in new tab)")):
    
    *   `Coordinates` has been changed to [`GeolocationCoordinates`](/en-US/docs/Web/API/GeolocationCoordinates).
    *   `Position` has been changed to [`GeolocationPosition`](/en-US/docs/Web/API/GeolocationPosition).
    *   `PositionError` has been changed to [`GeolocationPositionError`](/en-US/docs/Web/API/GeolocationPositionError).
*   A number of properties have been updated to use standard stringifiers ([Firefox bug 824857](https://bugzil.la/824857 "External link (opens in new tab)")):
    
    *   [`DOMTokenList.value`](/en-US/docs/Web/API/DOMTokenList/value)
    *   [`HTMLAnchorElement.href`](/en-US/docs/Web/API/HTMLAnchorElement/href)
    *   [`Location.href`](/en-US/docs/Web/API/Location/href)
    *   [`MediaList.mediaText`](/en-US/docs/Web/API/MediaList/mediaText)
    *   [`URL.href`](/en-US/docs/Web/API/URL/href)
    *   [`WorkerLocation.href`](/en-US/docs/Web/API/WorkerLocation/href)

#### DOM events

*   [`Notification.requestPermission()`](/en-US/docs/Web/API/Notification/requestPermission_static "Notification.requestPermission()") and [`PushManager.subscribe()`](/en-US/docs/Web/API/PushManager/subscribe) can now only be called in response to a user gesture such as a [`click`](/en-US/docs/Web/API/Element/click_event) event ([Firefox bug 1593644](https://bugzil.la/1593644 "External link (opens in new tab)")).

#### Media, Web Audio, and WebRTC

*   The [`MediaDevices.getDisplayMedia()`](/en-US/docs/Web/API/MediaDevices/getDisplayMedia) method can now only be called in response to a user gesture such as a [`click`](/en-US/docs/Web/API/Element/click_event) event ([Firefox bug 1580944](https://bugzil.la/1580944 "External link (opens in new tab)")).
*   The `RTCRtpContributingSource` dictionary can now include the `rtpTimestamp` property, which is a source-generated time at which the packet's media was generated or sampled ([Firefox bug 1583867](https://bugzil.la/1583867 "External link (opens in new tab)")).

#### Removals

*   Removed the non-standard `window.mozPaintCount` property. ([Firefox bug 1591968](https://bugzil.la/1591968 "External link (opens in new tab)"))
*   The [`BatteryManager`](/en-US/docs/Web/API/BatteryManager) interface is no longer exposed to web content ([Firefox bug 1441976](https://bugzil.la/1441976 "External link (opens in new tab)")).
*   [`Navigator.vibrate()`](/en-US/docs/Web/API/Navigator/vibrate) is no longer supported in cross-origin [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe)s ([Firefox bug 1591113](https://bugzil.la/1591113 "External link (opens in new tab)")).
*   WebRTC no longer supports the `rid=` and `pt=` parameters on the `simulcast` attribute. The new syntax for a line such as `a=simulcast: send rid=7 recv rid=8` is now `a=simulcast: send 7 recv 8`. The new syntax has been supported since Firefox 68, so now it's time tor retire support for the old syntax ([Firefox bug 1470568](https://bugzil.la/1470568 "External link (opens in new tab)")).

### [Security](#security)

*   Opting-out of MIME sniffing using [`X-Content-Type-Options`](/en-US/docs/Web/HTTP/Reference/Headers/X-Content-Type-Options) is now also applied to top-level documents if a [`Content-type`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Type) is provided. This can cause HTML web pages to be downloaded instead of being rendered when they are served with a MIME type other than `text/html`. Make sure to set both headers correctly. ([Firefox bug 1591932](https://bugzil.la/1591932 "External link (opens in new tab)")).
*   Dropped the support for HTTP Public Key Pinning (HPKP) because of the low adoption rate and interoperability risk. The `Public-Key-Pins` and `Public-Key-Pins-Report-Only` headers are now silently ignored [Firefox bug 1412438](https://bugzil.la/1412438 "External link (opens in new tab)").

### [Plugins](#plugins)

_No changes._

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Removed `Anon` and `AnonAttribute` strategies from `WebDriver:FindElement` and `WebDriver:FindElements` commands ([Firefox bug 1587627](https://bugzil.la/1587627 "External link (opens in new tab)")).
*   `Webdriver:TakeScreenshot` no longer fails if captured area exceeds upper maximum bound for the canvas width, height, or size ([Firefox bug 1590064](https://bugzil.la/1590064 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

### [API changes](#api_changes)

*   The [`browserSettings.ftpProtocolEnabled`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browserSettings/ftpProtocolEnabled) property has been implemented ([Firefox bug 1592687](https://bugzil.la/1592687 "External link (opens in new tab)")).
*   The [`BrowserSetting.onChange`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/types/BrowserSetting/onChange) event has been implemented ([Firefox bug 1410412](https://bugzil.la/1410412 "External link (opens in new tab)")).
*   The [`captivePortal.canonicalURL`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/captivePortal/canonicalURL) property has been implemented ([Firefox bug 1592932](https://bugzil.la/1592932 "External link (opens in new tab)")).
*   The callback functions for the [`browserAction.onClicked`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browserAction/onClicked) and [`pageAction.onClicked`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/pageAction/onClicked) events now include an `OnClickData` property containing an object whose properties describe the mouse button pressed along with any keyboard modifiers ([Firefox bug 1405031](https://bugzil.la/1405031 "External link (opens in new tab)")). This allows support for additional types of mouse click.
*   The [`browserSettings.tlsVersionRestrictionConfig`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/browserSettings/tlsVersionRestrictionConfig) property has been implemented and enables the highest and lowest versions of TLS supported by the browser to be read ([Firefox bug 1593635](https://bugzil.la/1593635 "External link (opens in new tab)")).

### [Manifest changes](#manifest_changes)

_No changes._
