# Firefox 46 release notes for developers

[To test the latest developer features of Firefox, install Firefox Developer Edition](https://www.firefox.com/en-US/channel/desktop/developer/ "External link (opens in new tab)"). Firefox 46 was released on April 26, 2016. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   [Dominators view in the Memory tool](https://firefox-source-docs.mozilla.org/devtools-user/memory/dominators_view/index.html "External link (opens in new tab)")
*   [Allocations view in the Performance tool](https://web.archive.org/web/20211207010022/https://firefox-source-docs.mozilla.org/devtools-user/performance/allocations/index.html "External link (opens in new tab)")
*   [One click to apply @media rule conditions in the Style Editor](https://firefox-source-docs.mozilla.org/devtools-user/style_editor/index.html#the-media-sidebar "External link (opens in new tab)")

[All devtools bugs fixed between Firefox 45 and Firefox 46.](https://bugzilla.mozilla.org/buglist.cgi?list_id=13263754&resolution=FIXED&classification=Client%20Software&chfieldto=2016-01-25&query_format=advanced&chfield=resolution&chfieldfrom=2015-12-14&chfieldvalue=FIXED&bug_status=RESOLVED&bug_status=VERIFIED&component=Developer%20Tools&component=Developer%20Tools%3A%20about%3Adebugging&component=Developer%20Tools%3A%20Animation%20Inspector&component=Developer%20Tools%3A%20Canvas%20Debugger&component=Developer%20Tools%3A%20Computed%20Styles%20Inspector&component=Developer%20Tools%3A%20Console&component=Developer%20Tools%3A%20CSS%20Rules%20Inspector&component=Developer%20Tools%3A%20Debugger&component=Developer%20Tools%3A%20DOM&component=Developer%20Tools%3A%20Font%20Inspector&component=Developer%20Tools%3A%20Framework&component=Developer%20Tools%3A%20Graphic%20Commandline%20and%20Toolbar&component=Developer%20Tools%3A%20Inspector&component=Developer%20Tools%3A%20JSON%20Viewer&component=Developer%20Tools%3A%20Memory&component=Developer%20Tools%3A%20Netmonitor&component=Developer%20Tools%3A%20Object%20Inspector&component=Developer%20Tools%3A%20Performance%20Tools%20%28Profiler%2FTimeline%29&component=Developer%20Tools%3A%20Responsive%20Design%20Mode&component=Developer%20Tools%3A%20Scratchpad&component=Developer%20Tools%3A%20Shared%20Components&component=Developer%20Tools%3A%20Source%20Editor&component=Developer%20Tools%3A%20Storage%20Inspector&component=Developer%20Tools%3A%20Style%20Editor&component=Developer%20Tools%3A%20User%20Stories&component=Developer%20Tools%3A%20Web%20Audio%20Editor&component=Developer%20Tools%3A%20WebGL%20Shader%20Editor&component=Developer%20Tools%3A%20WebIDE&product=Firefox "External link (opens in new tab)")

### [HTML](#html)

*   When faced with an invalid `type` value, [`<ul>`](/en-US/docs/Web/HTML/Reference/Elements/ul) no longer maps to `decimal`, but now behaves as if no `type` value were specified ([Firefox bug 241719](https://bugzil.la/241719 "External link (opens in new tab)")).
*   The attribute `pattern` on [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) is now treated as [a regular expression](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp) with `"u"` (unicode) flag ([Firefox bug 1227906](https://bugzil.la/1227906 "External link (opens in new tab)")).

### [CSS](#css)

*   Our implementation of CSS Grids has been updated:
    
    *   The keywords `auto-fill` and `auto-fit` are now allowed in the `repeat()` function ([Firefox bug 1118820](https://bugzil.la/1118820 "External link (opens in new tab)")).
    *   The `true` value has been renamed to `unsafe`; this affects the properties [`justify-content`](/en-US/docs/Web/CSS/Reference/Properties/justify-content), [`align-content`](/en-US/docs/Web/CSS/Reference/Properties/align-content), [`justify-self`](/en-US/docs/Web/CSS/Reference/Properties/justify-self), [`align-self`](/en-US/docs/Web/CSS/Reference/Properties/align-self), [`justify-items`](/en-US/docs/Web/CSS/Reference/Properties/justify-items) and [`align-items`](/en-US/docs/Web/CSS/Reference/Properties/align-items) ([Firefox bug 1230478](https://bugzil.la/1230478 "External link (opens in new tab)")).
*   The properties [`text-emphasis`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis), [`text-emphasis-style`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis-style), [`text-emphasis-color`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis-color) and [`text-emphasis-position`](/en-US/docs/Web/CSS/Reference/Properties/text-emphasis-position) are now enabled by default ([Firefox bug 1231485](https://bugzil.la/1231485 "External link (opens in new tab)")).
    
*   Gecko now accepts the `-webkit-` prefixed version of [some properties](https://wiki.mozilla.org/Compatibility/Mobile/Non_Standard_Compatibility "External link (opens in new tab)"); it requires to switch `layout.css.prefixes.webkit` to `true` ([Firefox bug 1213126](https://bugzil.la/1213126 "External link (opens in new tab)")).
    
*   The experimental support of the [`font-display`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face/font-display) descriptor (of [`@font-face`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face); it requires to switch `layout.css.font-display.enabled` to `true` ([Firefox bug 1157064](https://bugzil.la/1157064 "External link (opens in new tab)")).
    
*   Added support for [`@media (-webkit-transform-3d)`](/en-US/docs/Web/CSS/Reference/At-rules/@media/-webkit-transform-3d) as a media query for 3D transform support, if about:config pref `layout.css.prefixes.webkit` is set to `true` ([Firefox bug 1239799](https://bugzil.la/1239799 "External link (opens in new tab)")).
    
*   [`linear-gradient()`](/en-US/docs/Web/CSS/Reference/Values/gradient/linear-gradient) support for the omission of `0deg` units ([Firefox bug 1239153](https://bugzil.la/1239153 "External link (opens in new tab)")).
    
*   Added `-webkit-filter` for web compatibility, behind the preference `layout.css.prefixes.webkit`, defaulting to `false` ([Firefox bug 1236506](https://bugzil.la/1236506 "External link (opens in new tab)")).
    
*   \[css-align\] "unsafe start" (formerly "true start") should serialize to "start", etc. ([Firefox bug 1230398](https://bugzil.la/1230398 "External link (opens in new tab)")).
    

### [JavaScript](#javascript)

*   The ES2015 [RegExp unicode (u) flag](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/unicode) has been implemented ([Firefox bug 1135377](https://bugzil.la/1135377 "External link (opens in new tab)")).
*   The ES2015 block-level functions have been implemented ([Firefox bug 1071646](https://bugzil.la/1071646 "External link (opens in new tab)")).
*   The ES2015 [`TypedArray.prototype.sort()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/sort) method has been implemented ([Firefox bug 1121937](https://bugzil.la/1121937 "External link (opens in new tab)")).
*   The ES2015 [`arguments[Symbol.iterator]()`](/en-US/docs/Web/JavaScript/Reference/Functions/arguments/Symbol.iterator) has been implemented ([Firefox bug 1067049](https://bugzil.la/1067049 "External link (opens in new tab)")).
*   The experimental [ECMAScript Shared Memory API](https://web.archive.org/web/20220124015148/https://tc39.es/ecmascript_sharedmem/shmem.html "External link (opens in new tab)") has been implemented. See the [`SharedArrayBuffer`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/SharedArrayBuffer) and [`Atomics`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Atomics) objects. To use this experimental API set `javascript.options.shared_memory` to `true` in about:config.
*   Redeclaration of [`let`](/en-US/docs/Web/JavaScript/Reference/Statements/let) and [`const`](/en-US/docs/Web/JavaScript/Reference/Statements/const) variables now throws a [`SyntaxError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/SyntaxError) instead of a [`TypeError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypeError) as per the ECMAScript specification ([Firefox bug 1198833](https://bugzil.la/1198833 "External link (opens in new tab)")).
*   In [Strict mode](/en-US/docs/Web/JavaScript/Reference/Strict_mode), setting properties on [primitive](/en-US/docs/Glossary/Primitive) values will now throw a [`TypeError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypeError) ([Firefox bug 603201](https://bugzil.la/603201 "External link (opens in new tab)")).
*   The non-standard `WeakMap.prototype.clear()` and `WeakSet.prototype.clear()` methods have been removed ([Firefox bug 1101817](https://bugzil.la/1101817 "External link (opens in new tab)")).
*   The non-standard, static `RegExp.multiline` property is now deprecated ([Firefox bug 1220457](https://bugzil.la/1220457 "External link (opens in new tab)")).
*   Built-in accessor function names now have a "get" or "set" prefix ([Firefox bug 1180290](https://bugzil.la/1180290 "External link (opens in new tab)"), [Firefox bug 1235656](https://bugzil.la/1235656 "External link (opens in new tab)")).
*   [JS1.7/JS1.8 (legacy) array comprehensions and generator comprehensions](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#legacy_generator_and_iterator) have been removed ([Firefox bug 1220564](https://bugzil.la/1220564 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

#### DOM & HTML DOM

*   The deprecated `Window.showModalDialog()` method is no more available when Firefox runs in multi-process mode (e10s) ([Firefox bug 1234700](https://bugzil.la/1234700 "External link (opens in new tab)")).
*   Added support for [`Document.elementsFromPoint()`](/en-US/docs/Web/API/Document/elementsFromPoint) ([Firefox bug 1164427](https://bugzil.la/1164427 "External link (opens in new tab)")).
*   When a non-existent option of a [`<select>`](/en-US/docs/Web/HTML/Reference/Elements/select) element is programmatically selected, instead of being incorrectly left unchanged, the [`selectedIndex`](/en-US/docs/Web/API/HTMLSelectElement/selectedIndex) value is now set to `-1`, the [`selectedOptions`](/en-US/docs/Web/API/HTMLSelectElement/selectedOptions) to an empty [`HTMLCollection`](/en-US/docs/Web/API/HTMLCollection), and [`value`](/en-US/docs/Web/API/HTMLSelectElement/value) to an empty string ([Firefox bug 1203668](https://bugzil.la/1203668 "External link (opens in new tab)")).

#### Canvas

*   The remaining parts of the experimental [`OffscreenCanvas`](/en-US/docs/Web/API/OffscreenCanvas) API has been implemented; new features: [`OffscreenCanvas()`](/en-US/docs/Web/API/OffscreenCanvas/OffscreenCanvas "OffscreenCanvas()") constructor, `OffscreenCanvas.toBlob()`, and [`OffscreenCanvas.transferToImageBitmap()`](/en-US/docs/Web/API/OffscreenCanvas/transferToImageBitmap). To use this experimental API set `gfx.offscreencanvas.enabled` to `true` in about:config ([Firefox bug 1172796](https://bugzil.la/1172796 "External link (opens in new tab)")).
*   The [`ImageBitmap.close()`](/en-US/docs/Web/API/ImageBitmap/close) method is now supported ([Firefox bug 1172796](https://bugzil.la/1172796 "External link (opens in new tab)")).
*   A new [`ImageBitmapRenderingContext`](/en-US/docs/Web/API/ImageBitmapRenderingContext) rendering context is now implemented. Use `"bitmaprenderer"` with [`OffscreenCanvas.getContext()`](/en-US/docs/Web/API/OffscreenCanvas/getContext) or [`HTMLCanvasElement.getContext()`](/en-US/docs/Web/API/HTMLCanvasElement/getContext) to obtain this context. ([Firefox bug 1172796](https://bugzil.la/1172796 "External link (opens in new tab)")).

#### WebGL

*   The [`WEBGL_compressed_texture_etc`](/en-US/docs/Web/API/WEBGL_compressed_texture_etc) extension has been implemented, allowing the use of [ETC2 compressed texture formats](https://en.wikipedia.org/wiki/Ericsson_Texture_Compression "External link (opens in new tab)") ([Firefox bug 917505](https://bugzil.la/917505 "External link (opens in new tab)")). To use this extension, set the preference `webgl.enable-draft-extensions` to `true` in about:config.

#### IndexedDB

_No change._

#### Service Workers

*   [`FetchEvent.request`](/en-US/docs/Web/API/FetchEvent/request) is now non-nullable (see [Firefox bug 1238213](https://bugzil.la/1238213 "External link (opens in new tab)").)
*   [`Navigator.serviceWorker`](/en-US/docs/Web/API/Navigator/serviceWorker) has now been marked as SameObject (see [Firefox bug 1238205](https://bugzil.la/1238205 "External link (opens in new tab)").)
*   [`ExtendableMessageEvent.ports`](/en-US/docs/Web/API/ExtendableMessageEvent/ports) has now been marked as SameObject (see [Firefox bug 1238225](https://bugzil.la/1238225 "External link (opens in new tab)").)

#### Fetch

*   [`Request.mode`](/en-US/docs/Web/API/Request/mode) now has a new value available, `navigate`, for supporting requests generated while navigating between documents (see [Firefox bug 1209081](https://bugzil.la/1209081 "External link (opens in new tab)").)

#### WebRTC

*   The [`RTCPeerConnection.createOffer()`](/en-US/docs/Web/API/RTCPeerConnection/createOffer) method now supports the VP9 video codec, although this is disabled by default. To enable it, set the preference `media.peerconnection.video.vp9_enabled` to `true` in `about:config`. When enabled, VP9 is the preferred codec; previously VP8 was preferred ([Firefox bug 1242324](https://bugzil.la/1242324 "External link (opens in new tab)")).
*   The method [`RTCRtpSender.setParameters()`](/en-US/docs/Web/API/RTCRtpSender/setParameters) has been added to allow changing the values of parameters after the [`RTCRtpSender`](/en-US/docs/Web/API/RTCRtpSender) was initially created.

#### New APIs

*   In SVG, the [`SVGStyleElement`](/en-US/docs/Web/API/SVGStyleElement) interface now implements the `LinkStyle` mixin ([Firefox bug 1239128](https://bugzil.la/1239128 "External link (opens in new tab)")).

#### Miscellaneous

*   The asynchronous [`FileReader`](/en-US/docs/Web/API/FileReader) is now available in Web workers ([Firefox bug 901097](https://bugzil.la/901097 "External link (opens in new tab)")).
    
*   Our experimental implementation of [Web Animations API](/en-US/docs/Web/API/Web_Animations_API) has been updated:
    
    *   The `AnimationEffectTimingReadOnly` dictionary and [`AnimationEffectReadOnly.timing`](/en-US/docs/Web/API/AnimationEffect/getTiming "AnimationEffectReadOnly.timing") have been implemented ([Firefox bug 1214536](https://bugzil.la/1214536 "External link (opens in new tab)")).
*   The [Permissions API](/en-US/docs/Web/API/Permissions_API) has now been enabled by default, for all release versions, not just Nightly as it previously was ([Firefox bug 1221106](https://bugzil.la/1221106 "External link (opens in new tab)").)
    
*   Sanitization of WOFF fonts has been loosened a bit ([Firefox bug 1244693](https://bugzil.la/1244693 "External link (opens in new tab)")).

## [Networking](#networking)

*   Support of [RFC 7686](https://datatracker.ietf.org/doc/html/rfc7686 "External link (opens in new tab)") has been added: by default there is no attempt to resolve domain with the TLD `.onion`. This is controlled by the preference `network.dns.blockDotOnion`. Add-ons supporting Tor can swap this pref. ([Firefox bug 1228457](https://bugzil.la/1228457 "External link (opens in new tab)"))
