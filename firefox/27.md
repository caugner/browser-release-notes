# Firefox 27 release notes for developers

Firefox 27 was released on February 4, 2014. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   Breakpoints can now be set on DOM events.
*   JavaScript in the debugger panel can be unminified, using the { } button.
*   The inspector now has an "edit-element-html" feature, without needing an add-on.
*   Background-URLs and colors have preview in inspector. Even hovering over canvas elements will give a pop-up with an image preview.
*   Reflow logging has been added.
*   Styles of SVG elements are now inspectable ([Firefox bug 921191](https://bugzil.la/921191 "External link (opens in new tab)")).
*   Failure to find the image when clicking URL link in CSS inspector has been fixed ([Firefox bug 921686](https://bugzil.la/921686 "External link (opens in new tab)")).
*   The [`X-SourceMap`](/en-US/docs/Web/HTTP/Reference/Headers/SourceMap) header is now supported ([Firefox bug 765993](https://bugzil.la/765993 "External link (opens in new tab)")).

More details in [this post](https://hacks.mozilla.org/2013/11/firefox-developer-tools-episode-27-edit-as-html-codemirror-more/ "External link (opens in new tab)").

### [CSS](#css)

*   The `-moz-grab` and `-moz-grabbing` keywords on the CSS [`cursor`](/en-US/docs/Web/CSS/Reference/Properties/cursor) property have been unprefixed to `grab` and `grabbing` ([Firefox bug 880672](https://bugzil.la/880672 "External link (opens in new tab)")).
*   Support for the `-moz-hsla()` and `-moz-rgba()` functional notations has been dropped. Only the unprefixed versions, `hsla()` and `rgba()` are supported from now on ([Firefox bug 893319](https://bugzil.la/893319 "External link (opens in new tab)")).
*   The `true` value for [`text-align`](/en-US/docs/Web/CSS/Reference/Properties/text-align) has been added ([Firefox bug 929991](https://bugzil.la/929991 "External link (opens in new tab)")).
*   Experimental support of `position:sticky` is now active by default on non-release builds ([Firefox bug 902992](https://bugzil.la/902992 "External link (opens in new tab)")). For releases builds, the `layout.css.sticky.enabled` preference still needs to be set to `true`.
*   The [`all`](/en-US/docs/Web/CSS/Reference/Properties/all) shorthand property has been added ([Firefox bug 842329](https://bugzil.la/842329 "External link (opens in new tab)")).
*   The [`unset`](/en-US/docs/Web/CSS/Reference/Values/unset) global value has been added; it allows you to reset any CSS property ([Firefox bug 921731](https://bugzil.la/921731 "External link (opens in new tab)")).
*   Curly braces are no longer allowed in HTML `style` attributes: doing `<div style="{ display: none }">` was working in quirks mode, but won't anymore [Firefox bug 915053](https://bugzil.la/915053 "External link (opens in new tab)").
*   The [`overflow`](/en-US/docs/Web/CSS/Reference/Properties/overflow) property now works on [`<fieldset>`](/en-US/docs/Web/HTML/Reference/Elements/fieldset) ([Firefox bug 261037](https://bugzil.la/261037 "External link (opens in new tab)")).

### [HTML](#html)

*   The `color` value of the [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) [`type`](/en-US/docs/Web/HTML/Reference/Elements/input#type) attribute has been implemented on desktop platforms. It was already available on mobile ones.
*   The `allow-popups` directive is now supported with the [`sandbox`](/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox) attribute of the [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) element ([Firefox bug 766282](https://bugzil.la/766282 "External link (opens in new tab)")).
*   Blending of HTML elements using the [`mix-blend-mode`](/en-US/docs/Web/CSS/Reference/Properties/mix-blend-mode) property has been implemented. The `layout.css.mix-blend-mode.enabled` preference must be set to `true` ([Firefox bug 902525](https://bugzil.la/902525 "External link (opens in new tab)")).
*   The `typeMustMatch` property of the [`<object>`](/en-US/docs/Web/HTML/Reference/Elements/object) element is now supported ([Firefox bug 827160](https://bugzil.la/827160 "External link (opens in new tab)")).

### [JavaScript](#javascript)

[ECMAScript 2015](https://web.archive.org/web/20210612110055/https://developer.mozilla.org/en-US/docs/Archive/Web/JavaScript/New_in_JavaScript/ECMAScript_2015_support_in_Mozilla "External link (opens in new tab)") implementation continues!

*   The [spread operator](/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax) is now supported in Function calls ([Firefox bug 762363](https://bugzil.la/762363 "External link (opens in new tab)")).
*   The mathematical function [`Math.hypot()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/hypot) has been implemented ([Firefox bug 896264](https://bugzil.la/896264 "External link (opens in new tab)")).
*   The [`yield*`](/en-US/docs/Web/JavaScript/Reference/Operators/yield*) expression is now implemented ([Firefox bug 666396](https://bugzil.la/666396 "External link (opens in new tab)")).
*   The `MapIterator`, `SetIterator` and `ArrayIterator` objects now match the specification ([Firefox bug 881226](https://bugzil.la/881226 "External link (opens in new tab)")).
*   [for...of](/en-US/docs/Web/JavaScript/Reference/Statements/for...of) loops now expect the ES2015 standard [iterator protocol](/en-US/docs/Web/JavaScript/Reference/Iteration_protocols) moving away from SpiderMonkey old iterator protocol using `StopIteration`.
*   [`String.match`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/match) and [`String.replace`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/replace) now reset [`RegExp.lastIndex`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/lastIndex) ([Firefox bug 501739](https://bugzil.la/501739 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   Support for the two `setRange()` methods on the [`HTMLInputElement`](/en-US/docs/Web/API/HTMLInputElement) interface has been added ([Firefox bug 850364](https://bugzil.la/850364 "External link (opens in new tab)")).
*   Support for the two `setRange()` methods on the [`HTMLTextAreaElement`](/en-US/docs/Web/API/HTMLTextAreaElement) interface has been added ([Firefox bug 918940](https://bugzil.la/918940 "External link (opens in new tab)")).
*   The methods `getAllKeys()` and `openKeyCursor()` have been added to [`IDBObjectStore`](/en-US/docs/Web/API/IDBObjectStore) ([Firefox bug 920633](https://bugzil.la/920633 "External link (opens in new tab)") and [Firefox bug 920800](https://bugzil.la/920800 "External link (opens in new tab)")).
*   The [`HTMLFormControlsCollection`](/en-US/docs/Web/API/HTMLFormControlsCollection) interface has been implemented ([Firefox bug 913920](https://bugzil.la/913920 "External link (opens in new tab)")).
*   The [`CanvasRenderingContext2D`](/en-US/docs/Web/API/CanvasRenderingContext2D) interface now supports the two methods [`getLineDash()`](/en-US/docs/Web/API/CanvasRenderingContext2D/getLineDash "getLineDash()") and [`setLineDash()`](/en-US/docs/Web/API/CanvasRenderingContext2D/setLineDash "setLineDash()") and the [`lineDashOffset`](/en-US/docs/Web/API/CanvasRenderingContext2D/lineDashOffset "lineDashOffset") property ([Firefox bug 768067](https://bugzil.la/768067 "External link (opens in new tab)")).
*   The `typeMustMatch` attribute has been implemented on the [`HTMLObjectElement`](/en-US/docs/Web/API/HTMLObjectElement) interface ([Firefox bug 827160](https://bugzil.la/827160 "External link (opens in new tab)")).
*   The `copyFromChannel()` and `copyToChannel()` methods have been added to [`AudioBuffer`](/en-US/docs/Web/API/AudioBuffer) ([Firefox bug 915524](https://bugzil.la/915524 "External link (opens in new tab)")).
*   `Event.isTrusted()` is now unforgeable ([Firefox bug 637248](https://bugzil.la/637248 "External link (opens in new tab)")).
*   The WebRTC API's [`RTCIceCandidate`](/en-US/docs/Web/API/RTCIceCandidate) object now includes a [`toJSON()`](/en-US/docs/Web/API/RTCIceCandidate/toJSON "toJSON()") method to help with signaling and debugging ([Firefox bug 928304](https://bugzil.la/928304 "External link (opens in new tab)")).
*   The [`Navigator.vibrate()`](/en-US/docs/Web/API/Navigator/vibrate) method has been adapted to match the final specification: It now returns `false` when the list is too long or has too large entries, instead of throwing ([Firefox bug 884935](https://bugzil.la/884935 "External link (opens in new tab)")).
*   As part of the ongoing effort to standardize global objects, the non-standard stylesheet change event interfaces, including `StyleRuleChangeEvent`, `StyleSheetApplicableStateChangeEvent` and `StyleSheetChangeEvent`, are no longer available from Web content. The `CSSGroupRuleRuleList` interface, the implementation detail of [`CSSRuleList`](/en-US/docs/Web/API/CSSRuleList), has also been removed ([Firefox bug 872934](https://bugzil.la/872934 "External link (opens in new tab)") and [Firefox bug 916871](https://bugzil.la/916871 "External link (opens in new tab)")).
*   [`Window.atob()`](/en-US/docs/Web/API/Window/atob) now ignores whitespaces ([Firefox bug 711180](https://bugzil.la/711180 "External link (opens in new tab)")).
*   [WebGL](/en-US/docs/Web/API/WebGL_API): `MOZ_` prefixed extension strings are deprecated. Support for them will be removed in the future. Use unprefixed extension string only. To get draft extensions, set the `webgl.enable-draft-extensions` preferences ([Firefox bug 924176](https://bugzil.la/924176 "External link (opens in new tab)")).

### [MathML](#mathml)

_No change._

### [SVG](#svg)

*   Blending of SVG elements using the [`mix-blend-mode`](/en-US/docs/Web/CSS/Reference/Properties/mix-blend-mode) property has been implemented. The `layout.css.mix-blend-mode.enabled` preference must be set to `true` ([Firefox bug 902525](https://bugzil.la/902525 "External link (opens in new tab)")).

## [Changes for addon and Mozilla developers](#changes_for_addon_and_mozilla_developers)

*   The `downloads-indicator` button has gone away. You should now use the `downloads-button` element. If you need to check that it has loaded its overlay, check for the `indicator` attribute on that button.
*   The `chrome://browser/skin/downloads/indicator.css` stylesheet is no longer referenced in Firefox.

## [Security](#security)

*   TLS 1.2 has been implemented for improved security ([Firefox bug 861266](https://bugzil.la/861266 "External link (opens in new tab)")).
