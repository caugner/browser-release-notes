# Firefox 48 release notes for developers

[To test the latest developer features of Firefox, install Firefox Developer Edition](https://www.firefox.com/en-US/channel/desktop/developer/ "External link (opens in new tab)") Firefox 48 was released on August 2, 2016. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   The position of elements can now be changed within the content ([Firefox bug 1139187](https://bugzil.la/1139187 "External link (opens in new tab)")).
*   Implemented [`console.clear()`](/en-US/docs/Web/API/console/clear_static "console.clear()") to clear the console output ([Firefox bug 659625](https://bugzil.la/659625 "External link (opens in new tab)")).
*   Added [HTTP log inspection to the Web Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#viewing-network-request-details "External link (opens in new tab)") ([Firefox bug 1211525](https://bugzil.la/1211525 "External link (opens in new tab)")).
*   Added a [Firebug theme](https://firefox-source-docs.mozilla.org/devtools-user/tools_toolbox/index.html#choose-devtools-theme "External link (opens in new tab)") ([Firefox bug 1244054](https://bugzil.la/1244054 "External link (opens in new tab)")).
*   Added the [DOM Inspector](https://firefox-source-docs.mozilla.org/devtools-user/dom_property_viewer/index.html "External link (opens in new tab)") ([Firefox bug 1201475](https://bugzil.la/1201475 "External link (opens in new tab)")).
*   [Font inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/ui_tour/index.html#fonts-view "External link (opens in new tab)") has been enabled by default again ([Firefox bug 1280121](https://bugzil.la/1280121 "External link (opens in new tab)")).
*   [Improved suggestions](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#edit-rules "External link (opens in new tab)") for CSS properties ([Firefox bug 1168246](https://bugzil.la/1168246 "External link (opens in new tab)")).
*   Cookies, localStorage and sessionStorage entries are editable via double-click ([Firefox bug 1231154](https://bugzil.la/1231154 "External link (opens in new tab)"), [Firefox bug 1231179](https://bugzil.la/1231179 "External link (opens in new tab)"), [Firefox bug 1231155](https://bugzil.la/1231155 "External link (opens in new tab)")).

### [HTML](#html)

*   The [`<details>`](/en-US/docs/Web/HTML/Reference/Elements/details) and [`<summary>`](/en-US/docs/Web/HTML/Reference/Elements/summary) elements have been activated by default on Nightly and Aurora (DevTools), but not on Beta or Release:
    
    *   The default style for these elements has been adapted to match the spec ([Firefox bug 1258657](https://bugzil.la/1258657 "External link (opens in new tab)")).
    *   The `toggle` event is now sent to the [`<details>`](/en-US/docs/Web/HTML/Reference/Elements/details) element when this one is opened or closed ([Firefox bug 1225412](https://bugzil.la/1225412 "External link (opens in new tab)")).
*   The [`meta`](/en-US/docs/Web/HTML/Reference/Elements/meta) attributes now also supports the `no-referrer-when-downgrade` and `origin-when-cross-origin` values ([Firefox bug 1178337](https://bugzil.la/1178337 "External link (opens in new tab)")).
    

### [CSS](#css)

*   The [`calc()`](/en-US/docs/Web/CSS/Reference/Values/calc) has been improved to be closer to the specification:
    
    *   [`calc()`](/en-US/docs/Web/CSS/Reference/Values/calc) is now supported on the [`line-height`](/en-US/docs/Web/CSS/Reference/Properties/line-height) property ([Firefox bug 594933](https://bugzil.la/594933 "External link (opens in new tab)")).
    *   Added support for nested CSS [`calc()`](/en-US/docs/Web/CSS/Reference/Values/calc) ([Firefox bug 968761](https://bugzil.la/968761 "External link (opens in new tab)")).
*   Our experimental implementation of CSS grids has been updated:
    
    *   Fragmentation for grid layout has been implemented ([Firefox bug 1144096](https://bugzil.la/1144096 "External link (opens in new tab)")).
    *   \[css-grid\] Percentage tracks are now treated as `auto` if grid container size is indefinite ([Firefox bug 1264607](https://bugzil.la/1264607 "External link (opens in new tab)")).
    *   [`<fieldset>`](/en-US/docs/Web/HTML/Reference/Elements/fieldset) now supports grid and flex layouts ([Firefox bug 1230207](https://bugzil.la/1230207 "External link (opens in new tab)")).
*   The `luminance` value for [`mask-mode`](/en-US/docs/Web/CSS/Reference/Properties/mask-mode) has been added; the `auto` value has been renamed to `match-source`, to match the spec ([Firefox bug 1228354](https://bugzil.la/1228354 "External link (opens in new tab)")).
    
*   Interpolation of [`clip-path`](/en-US/docs/Web/CSS/Reference/Properties/clip-path) basic shapes in CSS animations and transitions is now supported ([Firefox bug 1110460](https://bugzil.la/1110460 "External link (opens in new tab)")).
    
*   Support for horizontal-in-vertical (_tate-chu-yoko_) text has been added via the `all` value of the [`text-combine-upright`](/en-US/docs/Web/CSS/Reference/Properties/text-combine-upright) property ([Firefox bug 1097499](https://bugzil.la/1097499 "External link (opens in new tab)")).
    
*   Support for the experimental [`color-adjust`](/en-US/docs/Web/CSS/Reference/Properties/print-color-adjust) property has been added, allowing pages to specify that background colors and images should be printed ([Firefox bug 1209273](https://bugzil.la/1209273 "External link (opens in new tab)")).
    
*   The [`::first-letter`](/en-US/docs/Web/CSS/Reference/Selectors/::first-letter) pseudo-element now also matches punctuation characters of type Pd that precede or immediately follow the actual first letter; this is a new requirement of CSS Pseudo-element module level 4 ([Firefox bug 1260366](https://bugzil.la/1260366 "External link (opens in new tab)")).
    
*   Several `-webkit` prefixed properties and values have been added for web compatibility, behind the preference `layout.css.prefixes.webkit`, defaulting to `false`:
    
    *   [`-webkit-text-fill-color`](/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-fill-color) ([Firefox bug 1247777](https://bugzil.la/1247777 "External link (opens in new tab)")).
    *   [`-webkit-text-stroke`](/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-stroke), [`-webkit-text-stroke-color`](/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-stroke-color), [`-webkit-text-stroke-width`](/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-stroke-width) ([Firefox bug 1248708](https://bugzil.la/1248708 "External link (opens in new tab)")).
    *   `-webkit-background-clip` (as background-clip) text value ([Firefox bug 759568](https://bugzil.la/759568 "External link (opens in new tab)")).
    *   `-webkit-box-direction`, `-webkit-box-orient` ([Firefox bug 1262049](https://bugzil.la/1262049 "External link (opens in new tab)").
    *   The value `-webkit-inline-box` is now an alias of `inline-flex` on the [`display`](/en-US/docs/Web/CSS/Reference/Properties/display) property. ([Firefox bug 1257661](https://bugzil.la/1257661 "External link (opens in new tab)")).
    *   `-webkit-flex-direction`, `-webkit-flex-wrap`, `-webkit-flex-flow`, `-webkit-order`, `-webkit-flex`, `-webkit-flex-grow`, `-webkit-flex-shrink`, `-webkit-flex-basis`, `-webkit-justify-content`, `-webkit-align-items`, `-webkit-align-self` and `-webkit-align-content` were added as aliases for the unprefixed properties and the values `-webkit-flex` and `-webkit-inline-flex` for the [`display`](/en-US/docs/Web/CSS/Reference/Properties/display) property as aliases for the unprefixed values ([Firefox bug 1274096](https://bugzil.la/1274096 "External link (opens in new tab)")).
    *   Added `-webkit-box-flex`, `-webkit-box-ordinal-group`, `-webkit-box-align` and `-webkit-box-pack` properties and `-webkit-box` value to [`display`](/en-US/docs/Web/CSS/Reference/Properties/display) as aliases for modern [CSS Flexbox](/en-US/docs/Web/CSS/Guides/Flexible_box_layout/Use_cases) ([Firefox bug 1208635](https://bugzil.la/1208635 "External link (opens in new tab)")).
*   The `text` value of [`background-clip`](/en-US/docs/Web/CSS/Reference/Properties/background-clip) is now available in all type of Firefox (and not only non-release builds) ([Firefox bug 1263516](https://bugzil.la/1263516 "External link (opens in new tab)")).
    
*   The `absolute` value of [`position`](/en-US/docs/Web/CSS/Reference/Properties/position) properties on the top layer element ([Firefox bug 1236828](https://bugzil.la/1236828 "External link (opens in new tab)")).
    
*   Added an internal-only syntax for [`@supports`](/en-US/docs/Web/CSS/Reference/At-rules/@supports) to detect pref ([Firefox bug 1259889](https://bugzil.la/1259889 "External link (opens in new tab)")).
    

### [JavaScript](#javascript)

#### New APIs

*   The [`String.prototype.padStart()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/padStart) and [`String.prototype.padEnd()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/padEnd) methods have been implemented ([Firefox bug 1260509](https://bugzil.la/1260509 "External link (opens in new tab)")).
*   The ES2015 [`Symbol.unscopables`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol/unscopables) and [`Array.prototype[Symbol.unscopables]`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/Symbol.unscopables) properties have been implemented ([Firefox bug 1054759](https://bugzil.la/1054759 "External link (opens in new tab)") and [Firefox bug 1258163](https://bugzil.la/1258163 "External link (opens in new tab)")).
*   The ES2015 [`Symbol.isConcatSpreadable`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol/isConcatSpreadable) symbol has been implemented ([Firefox bug 1041586](https://bugzil.la/1041586 "External link (opens in new tab)")).
*   The ES2015 [`Array[Symbol.species]`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/Symbol.species) getter has been implemented ([Firefox bug 1165052](https://bugzil.la/1165052 "External link (opens in new tab)")).
*   The ES2015 [`ArrayBuffer[Symbol.species]`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer/Symbol.species) getter and [`TypedArray[Symbol.species]`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/Symbol.species) getter have been implemented ([Firefox bug 1165053](https://bugzil.la/1165053 "External link (opens in new tab)")).
*   The [`Intl.getCanonicalLocales()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/getCanonicalLocales) method of the ECMAScript Internationalization API draft has been implemented ([Firefox bug 1263040](https://bugzil.la/1263040 "External link (opens in new tab)")).

#### Deprecations and removals

*   The deprecated [old Proxy API](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#proxy) (`Proxy.create` and `Proxy.createFunction()`) has been removed. Use the standard [`Proxy`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy) object instead ([Firefox bug 892903](https://bugzil.la/892903 "External link (opens in new tab)")).
*   The `String.prototype.contains()` method has been removed (it was deprecated since version 40). Use the [`String.prototype.includes()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/includes) method instead ([Firefox bug 1103588](https://bugzil.la/1103588 "External link (opens in new tab)")).
*   The non-standard `RegExp.multiline` property (not [`RegExp.prototype.multiline`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/multiline)) has been removed. Use the standard [m flag](/en-US/docs/Web/JavaScript/Guide/Regular_expressions#advanced_searching_with_flags) instead ([Firefox bug 1219757](https://bugzil.la/1219757 "External link (opens in new tab)")).
*   The [`Object.prototype.__defineGetter__()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/__defineGetter__) and [`Object.prototype.__defineSetter__()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/__defineSetter__) methods can no longer be called at the global scope without any object. ([Firefox bug 1253016](https://bugzil.la/1253016 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

#### DOM & HTML DOM

*   Dropped the "Moz" prefix from the [`CSSKeyframeRule`](/en-US/docs/Web/API/CSSKeyframeRule) and [`CSSKeyframesRule`](/en-US/docs/Web/API/CSSKeyframesRule) interfaces ([Firefox bug 1256178](https://bugzil.la/1256178 "External link (opens in new tab)")).
*   The `NavigatorConcurrentHardware` [mixin](/en-US/docs/Glossary/Mixin) has been implemented, which adds the [`Navigator.hardwareConcurrency`](/en-US/docs/Web/API/Navigator/hardwareConcurrency) property to the [`Navigator`](/en-US/docs/Web/API/Navigator) interface. This lets websites and apps get at least an approximation of how many processing cores are available to run [`Worker`](/en-US/docs/Web/API/Worker)s in ([Firefox bug 1008453](https://bugzil.la/1008453 "External link (opens in new tab)")).
*   The [`Node.isSameNode()`](/en-US/docs/Web/API/Node/isSameNode) method, which was removed in Firefox 10, has returned after being added back into the specification after a lengthy absence ([Firefox bug 1256299](https://bugzil.la/1256299 "External link (opens in new tab)")).
*   Firefox now returns proper exceptions instead of numbers when things go wrong during a call to [`Navigator.registerProtocolHandler()`](/en-US/docs/Web/API/Navigator/registerProtocolHandler).
*   [`Element.animate()`](/en-US/docs/Web/API/Element/animate) is now activated by default ([Firefox bug 1245000](https://bugzil.la/1245000 "External link (opens in new tab)")).
*   The two methods [`Element.insertAdjacentText()`](/en-US/docs/Web/API/Element/insertAdjacentText) and [`Element.insertAdjacentElement()`](/en-US/docs/Web/API/Element/insertAdjacentElement) have been implemented ([Firefox bug 811259](https://bugzil.la/811259 "External link (opens in new tab)")).
*   [`Document.scrollingElement`](/en-US/docs/Web/API/Document/scrollingElement) got enabled by default ([Firefox bug 1265032](https://bugzil.la/1265032 "External link (opens in new tab)")).
*   `Node.localName`, `Node.namespaceURI` and `Node.prefix` were moved to the [`Element`](/en-US/docs/Web/API/Element) and [`Attr`](/en-US/docs/Web/API/Attr) APIs ([Firefox bug 1055776](https://bugzil.la/1055776 "External link (opens in new tab)")).
*   Per the latest specification, the values of [`KeyboardEvent.code`](/en-US/docs/Web/API/KeyboardEvent/code) returned for the following keys have been changed see ([Firefox bug 1264150](https://bugzil.la/1264150 "External link (opens in new tab)")):
    *   `"OSLeft"` and `"OSRight"` are now `"MetaLeft"` and `"MetaRight"`.
    *   `"VolumeDown"`, `"VolumeUp"`, and `"VolumeMute"` are now `"AudioVolumeDown"`, `"AudioVolumeUp"`, and `"AudioVolumeMute"`.
    *   `"IntlHash"` has been removed.
    *   All keys whose `code` values were reported as "" in earlier versions of Firefox are now reported as "Unidentified".

#### Canvas 2D

*   The [`CanvasRenderingContext2D.ellipse()`](/en-US/docs/Web/API/CanvasRenderingContext2D/ellipse) method has been implemented ([Firefox bug 910138](https://bugzil.la/910138 "External link (opens in new tab)")).

#### WebRTC

*   The two methods [`MediaStream.clone()`](/en-US/docs/Web/API/MediaStream/clone) and [`MediaStreamTrack.clone()`](/en-US/docs/Web/API/MediaStreamTrack/clone) have been implemented ([Firefox bug 1208371](https://bugzil.la/1208371 "External link (opens in new tab)")).
*   The `iceRestart` entry is now supported in the `RTCOfferOptions` code dictionary, allowing [`createOffer()`](/en-US/docs/Web/API/RTCPeerConnection/createOffer "createOffer()") to be used to request ICE restarts ([Firefox bug 906986](https://bugzil.la/906986 "External link (opens in new tab)")).
*   The [`RTCPeerConnection.createOffer()`](/en-US/docs/Web/API/RTCPeerConnection/createOffer) method now prefers the VP9 video codec by default; previously VP8 was preferred ([Firefox bug 1242324](https://bugzil.la/1242324 "External link (opens in new tab)").
*   WebM/VP8 video that includes video resolution changes that has been recorded using [`MediaRecorder`](/en-US/docs/Web/API/MediaRecorder) can now be played back successfully.

#### Others

*   The [Web Crypto API](/en-US/docs/Web/API/Web_Crypto_API) is now available in [Web workers](/en-US/docs/Web/API/Web_Workers_API) ([Firefox bug 842818](https://bugzil.la/842818 "External link (opens in new tab)")).
*   The [`CustomEvent`](/en-US/docs/Web/API/CustomEvent) interface is now available in [Web Workers](/en-US/docs/Web/API/Web_Workers_API) ([Firefox bug 1003432](https://bugzil.la/1003432 "External link (opens in new tab)")).
*   The `DOMApplicationsManager.getNotInstalled()` method has been removed ([Firefox bug 1255036](https://bugzil.la/1255036 "External link (opens in new tab)")).
*   Several Firefox OS APIs that were erroneously exposed to the Web have now been hidden as they should have been — `mozContact`, `MozContactChangeEvent`, `navigator.mozContacts`, `MozPowerManager`, `MozSettingsEvent` (see [Firefox bug 1043562](https://bugzil.la/1043562 "External link (opens in new tab)"), [Firefox bug 1256414](https://bugzil.la/1256414 "External link (opens in new tab)"), and [Firefox bug 1256046](https://bugzil.la/1256046 "External link (opens in new tab)")).
*   Support for UTF-16 has been removed from [`TextEncoder`](/en-US/docs/Web/API/TextEncoder) ([Firefox bug 1257877](https://bugzil.la/1257877 "External link (opens in new tab)")).
*   [`RTCStatsReport`](/en-US/docs/Web/API/RTCStatsReport) is now a true `maplike` interface: in addition to [`forEach()`](/en-US/docs/Web/API/RTCStatsReport/forEach "forEach()"), [`get()`](/en-US/docs/Web/API/RTCStatsReport/get "get()"), and [`has()`](/en-US/docs/Web/API/RTCStatsReport/has "has()"), the methods [`entries()`](/en-US/docs/Web/API/RTCStatsReport/entries "entries()"), [`values()`](/en-US/docs/Web/API/RTCStatsReport/values "values()"), [`keys()`](/en-US/docs/Web/API/RTCStatsReport/keys "keys()"), as well as the [`size`](/en-US/docs/Web/API/RTCStatsReport/size "size") getter have been implemented ([Firefox bug 906986](https://bugzil.la/906986 "External link (opens in new tab)")).
*   The [`Request.cache`](/en-US/docs/Web/API/Request/cache) property has been added allowing you to control the cache behavior ([Firefox bug 1120715](https://bugzil.la/1120715 "External link (opens in new tab)")).
*   Handling of dead keys on Mac OS X has been changed to work the same as other platforms; they no longer fire a [`keypress`](/en-US/docs/Web/API/Element/keypress_event "keypress") event when no text is generated when the focused element isn't editable (when the focused element is editable, dead key causes composition events instead of keyboard events on Mac OS X). Also, like on other platforms, the value of [`KeyboardEvent.key`](/en-US/docs/Web/API/KeyboardEvent/key) is now `"Dead"` for dead key presses which don't generate text in other situations.

## [HTTP](#http)

*   Support for the [`Upgrade-Insecure-Requests`](/en-US/docs/Web/HTTP/Reference/Headers/Upgrade-Insecure-Requests) header has been added ([Firefox bug 1243586](https://bugzil.la/1243586 "External link (opens in new tab)")).
*   The [`block-all-mixed-content`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/block-all-mixed-content) CSP directive has been implemented ([Firefox bug 1122236](https://bugzil.la/1122236 "External link (opens in new tab)"))

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

*   The Social Worker API has been removed.
*   Added the `-moz-bool-pref()` [CSS](/en-US/docs/Web/CSS) [`@supports`](/en-US/docs/Web/CSS/Reference/At-rules/@supports) function to allow hiding portions of chrome stylesheets behind boolean preferences. ([Firefox bug 1259889](https://bugzil.la/1259889 "External link (opens in new tab)"))
