# Firefox 96 release notes for developers

This article provides information about the changes in Firefox 96 that affect developers. Firefox 96 was released on January 11, 2022.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

No notable changes

### [CSS](#css)

*   The [`hwb()`](/en-US/docs/Web/CSS/Reference/Values/color_value/hwb) function for use as a [CSS color value](/en-US/docs/Web/CSS/Reference/Values/color_value) has been implemented. The `hwb()` functional notation expresses a given color according to its hue, whiteness, and blackness. An optional alpha component represents the color's transparency. ([Firefox bug 1352755](https://bugzil.la/1352755 "External link (opens in new tab)")).
    
*   Firefox now provides support for the [`color-scheme`](/en-US/docs/Web/CSS/Reference/Properties/color-scheme) property. This allows an element to indicate which color schemes it can comfortably be rendered in. Common options include "light" and "dark", or "day mode" and "night mode". ([Firefox bug 1576289](https://bugzil.la/1576289 "External link (opens in new tab)")).
    
*   The [`counter-reset`](/en-US/docs/Web/CSS/Reference/Properties/counter-reset) property now supports the `reversed()` function for creating _reversed_ [CSS counters](/en-US/docs/Web/CSS/Guides/Counter_styles/Using_counters), which are intended for numbering elements in descending order. This can be used with the `list-item` counter to automatically number ordered lists in reverse order, starting from the number of elements in the list (`list-item` is a counter that is automatically applied for ordered lists, such as those created using [`<ol>`](/en-US/docs/Web/HTML/Reference/Elements/ol)). Firefox uses this feature internally to support the `<ol>` [`reversed` attribute](/en-US/docs/Web/HTML/Reference/Elements/ol#reversed). ([Firefox bug 1706346](https://bugzil.la/1706346 "External link (opens in new tab)")).
    

### [JavaScript](#javascript)

No notable changes.

### [HTTP](#http)

No notable changes.

### [APIs](#apis)

*   [`navigator.canShare()`](/en-US/docs/Web/API/Navigator/canShare) is now supported on Android, allowing code to check whether [`navigator.share()`](/en-US/docs/Web/API/Navigator/share) will succeed for particular targets. The feature is behind a preference on desktop operating systems. ([Firefox bug 1666203](https://bugzil.la/1666203 "External link (opens in new tab)")).
*   The [Web Locks API](/en-US/docs/Web/API/Web_Locks_API) is enabled by default, allowing web apps running in multiple tabs or workers to coordinate the use of resources. ([Firefox bug 1740044](https://bugzil.la/1740044 "External link (opens in new tab)")).

#### Canvas

*   Image encoder support has been added for the [WebP](/en-US/docs/Web/Media/Guides/Formats/Image_types#webp_image) image format. This allows canvas elements to export their content as webp data when using the methods: [`HTMLCanvasElement.toDataURL()`](/en-US/docs/Web/API/HTMLCanvasElement/toDataURL), [`HTMLCanvasElement.toBlob()`](/en-US/docs/Web/API/HTMLCanvasElement/toBlob), and [`OffscreenCanvas.toBlob`](/en-US/docs/Web/API/OffscreenCanvas/convertToBlob "OffscreenCanvas.toBlob"). ([Firefox bug 1511670](https://bugzil.la/1511670 "External link (opens in new tab)")).

#### DOM

*   The [`IntersectionObserver()`](/en-US/docs/Web/API/IntersectionObserver/IntersectionObserver "IntersectionObserver()") constructor now sets the default `rootMargin` if an empty string is passed in the associated parameter option, instead of throwing an exception ([Firefox bug 1738791](https://bugzil.la/1738791 "External link (opens in new tab)")).

#### Media, WebRTC, and Web Audio

*   A number of deprecated non-standard statistics fields have been removed from the WebRTC API [`RTCStatsReport`](/en-US/docs/Web/API/RTCStatsReport) interface, including: `bitrateMean`, `bitrateStdDev`, `framerateMean`, `framerateStdDev`, and `droppedFrames`. ([Firefox bug 1367562](https://bugzil.la/1367562 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Added the command `WebDriver:GetElementShadowRoot` to retrieve the shadow root (open or closed) hosted by a given element ([Firefox bug 1700073](https://bugzil.la/1700073 "External link (opens in new tab)")).
*   Fixed a bug in `WebDriver:ExecuteScript` and `WebDriver:ExecuteAsyncScript` that caused a `cyclic object value` error when trying to return the `ShadowRoot` of an element ([Firefox bug 1489490](https://bugzil.la/1489490 "External link (opens in new tab)")).
*   `WebDriver:Print` has been enhanced to support page ranges when printing documents as PDF ([Firefox bug 1678347](https://bugzil.la/1678347 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   Added [`runtime.getFrameId`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/runtime/getFrameId) that gets the frame ID of any window global or frame element from a content script ([Firefox bug 1733104](https://bugzil.la/1733104 "External link (opens in new tab)")).
