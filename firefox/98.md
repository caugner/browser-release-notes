# Firefox 98 release notes for developers

This article provides information about the changes in Firefox 98 that affect developers. Firefox 98 was released on March 8, 2022.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

*   The HTML [`<dialog>`](/en-US/docs/Web/HTML/Reference/Elements/dialog) element is now available by default. This element and its associated [DOM APIs](/en-US/docs/Web/API/Document_Object_Model) provide support for HTML-based modal dialog boxes ([Firefox bug 1733536](https://bugzil.la/1733536 "External link (opens in new tab)")).

### [CSS](#css)

*   The [`hyphenate-character`](/en-US/docs/Web/CSS/Reference/Properties/hyphenate-character) property sets a string that is used instead of a hyphen character (`-`) at the end of a hyphenation line break ([Firefox bug 1751024](https://bugzil.la/1751024 "External link (opens in new tab)")).

### [JavaScript](#javascript)

No notable changes

### [APIs](#apis)

*   [`navigator.registerProtocolHandler()`](/en-US/docs/Web/API/Navigator/registerProtocolHandler) can now register protocol handlers for the `ftp`, `sftp`, and `ftps` schemes ([Firefox bug 1705202](https://bugzil.la/1705202 "External link (opens in new tab)")).

#### DOM

*   [`HTMLElement.outerText`](/en-US/docs/Web/API/HTMLElement/outerText) is now supported ([Firefox bug 1709790](https://bugzil.la/1709790 "External link (opens in new tab)")).
*   The properties `colorSpaceConversion`, `resizeWidth` and `resizeHeight` can be passed to the method [`Window.createImageBitmap()`](/en-US/docs/Web/API/Window/createImageBitmap) and [`WorkerGlobalScope.createImageBitmap()`](/en-US/docs/Web/API/WorkerGlobalScope/createImageBitmap) using the `options` object ([Firefox bug 1748868](https://bugzil.la/1748868 "External link (opens in new tab)") and [Firefox bug 1733559](https://bugzil.la/1733559 "External link (opens in new tab)")).
*   [`ElementInternals`](/en-US/docs/Web/API/ElementInternals) now has new form-associated custom element methods and properties that allow custom elements to interact with a form. These include the [`form`](/en-US/docs/Web/API/ElementInternals/form "form"), [`labels`](/en-US/docs/Web/API/ElementInternals/labels "labels") and [`willValidate`](/en-US/docs/Web/API/ElementInternals/willValidate "willValidate") properties, and the [`setFormValue()`](/en-US/docs/Web/API/ElementInternals/setFormValue "setFormValue()") method. ([Firefox bug 1556362](https://bugzil.la/1556362 "External link (opens in new tab)"), [Firefox bug 1556373](https://bugzil.la/1556373 "External link (opens in new tab)"), [Firefox bug 1556365](https://bugzil.la/1556365 "External link (opens in new tab)"), [Firefox bug 1556449](https://bugzil.la/1556449 "External link (opens in new tab)")).

#### Removals

*   The deprecated [WebVR API](/en-US/docs/Web/API/WebVR_API) is now disabled by default on all builds (previously it was enabled on Windows, macOS, and all nightly/dev builds). It can be re-enabled in `about:config` by setting `dom.vr.enabled` to `true` ([Firefox bug 1750902](https://bugzil.la/1750902 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Improved initial page load checks for newly opened tabs ([Firefox bug 1747359](https://bugzil.la/1747359 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   Web extensions using [`webRequest`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest) were started early during Firefox startup. This has changed to only trigger early start-up for extensions using [`webRequest`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest) blocking calls. Non-blocking calls no longer cause the early startup of an extension. ([Firefox bug 1749871](https://bugzil.la/1749871 "External link (opens in new tab)"))
*   `cookieStoreId` added to [`userScripts.register`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/userScripts/register). This enables extensions to register container-specific user scripts ([Firefox bug 1738567](https://bugzil.la/1738567 "External link (opens in new tab)")).
