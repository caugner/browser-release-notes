# Firefox 108 release notes for developers

This article provides information about the changes in Firefox 108 that will affect developers. Firefox 108 was released on December 13, 2022.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

*   The [`<source>`](/en-US/docs/Web/HTML/Reference/Elements/source) element supports [`height`](/en-US/docs/Web/HTML/Reference/Elements/source#height) & [`width`](/en-US/docs/Web/HTML/Reference/Elements/source#width) attributes when it is a child of a [`<picture>`](/en-US/docs/Web/HTML/Reference/Elements/picture) element. This functionality can be configured via the `dom.picture_source_dimension_attributes.enabled` preference which is now set to `true` by default ([Firefox bug 1795953](https://bugzil.la/1795953 "External link (opens in new tab)")).

### [CSS](#css)

*   [Trigonometric functions](/en-US/docs/Web/CSS/Reference/Values/Functions#trigonometric_functions) are now enabled with the `layout.css.trig.enabled` preference set to `true` by default. This allows the use of `sin()`, `cos()`, `tan()`, `asin()`, `acos()`, `atan()`, and `atan2()` functions ([Firefox bug 1774589](https://bugzil.la/1774589 "External link (opens in new tab)"), [Firefox bug 1787070](https://bugzil.la/1787070 "External link (opens in new tab)")).
*   CSS [`<calc-constant>`](/en-US/docs/Web/CSS/Reference/Values/calc-keyword) type is implemented to allow for well-known constants such as `pi` and `e` within [math functions](/en-US/docs/Web/CSS/Reference/Values/Functions#math_functions) ([Firefox bug 1682444](https://bugzil.la/1682444 "External link (opens in new tab)"), [Firefox bug 1787070](https://bugzil.la/1787070 "External link (opens in new tab)")).
*   Container query length units are now supported via the `layout.css.container-queries.enabled` preference, which is set to `false` by default. Setting this preference to `true` allows the use of `cqw`, `cqh`, `cqi`, `cqb`, `cqmin`, and `cqmax` units of length which are relative to the size of a query container. For more information on these units, see the [CSS Container Queries](/en-US/docs/Web/CSS/Guides/Containment/Container_queries#container_query_length_units) documentation ([Firefox bug 1744231](https://bugzil.la/1744231 "External link (opens in new tab)")).
*   The [`font-variant-emoji`](/en-US/docs/Web/CSS/Reference/Properties/font-variant-emoji) property is now supported via the `layout.css.font-variant-emoji.enabled` preference, which is set to `false` by default. This property allows you to set a default presentation style for displaying emojis ([Firefox bug 1461589](https://bugzil.la/1461589 "External link (opens in new tab)")).

### [JavaScript](#javascript)

No notable changes

### [HTTP](#http)

*   [`Content-Security-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) HTTP header directives [`style-src-elem`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src-elem) and [`style-src-attr`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src-attr) are now supported. A server can use these to specify valid sources for stylesheet `<style>` elements and `<link>` elements with `rel="stylesheet"`, and for styles applied to individual elements, respectively ([Firefox bug 1529338](https://bugzil.la/1529338 "External link (opens in new tab)")).
*   [`Content-Security-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) HTTP header directives [`script-src-elem`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/script-src-elem) and [`script-src-attr`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/script-src-attr) are now supported. A server can use these to specify valid sources for JavaScript `<script>` elements, and for inline script event handlers like `onclick`, respectively ([Firefox bug 1529337](https://bugzil.la/1529337 "External link (opens in new tab)")).
*   [`Content-Security-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) violation reports now include `effective-directive` and `status-code` properties. For more information, see [Violation report syntax](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/report-uri#violation_report_syntax) ([Firefox bug 1192684](https://bugzil.la/1192684 "External link (opens in new tab)")).

### [APIs](#apis)

*   [Import maps](/en-US/docs/Web/HTML/Reference/Elements/script/type/importmap) are now supported. Import maps provide flexibility and additional control over how browsers resolve module specifiers when importing [JavaScript modules](/en-US/docs/Web/JavaScript/Guide/Modules). ([Firefox bug 1795647](https://bugzil.la/1795647 "External link (opens in new tab)")).

#### Media, WebRTC, and Web Audio

*   The [Web MIDI API](/en-US/docs/Web/API/Web_MIDI_API) is now available in [secure contexts](/en-US/docs/Web/Security/Defenses/Secure_Contexts). Calls to [`navigator.requestMIDIAccess()`](/en-US/docs/Web/API/Navigator/requestMIDIAccess) will prompt users with active MIDI devices to install a [Site Permission Add-On](https://support.mozilla.org/en-US/kb/site-permission-add-ons "External link (opens in new tab)"), which is required to enable the API. For more information see [Firefox bug 1795025](https://bugzil.la/1795025 "External link (opens in new tab)").

### [WebDriver conformance (WebDriver BiDi, Marionette)](#webdriver_conformance_webdriver_bidi_marionette)

#### WebDriver BiDi

*   Following a [change in the specification](https://github.com/w3c/webdriver-bidi/pull/259 "External link (opens in new tab)"), log entry level `"warning"` was renamed to `"warn"` ([Firefox bug 1797115](https://bugzil.la/1797115 "External link (opens in new tab)")).
*   When using `script.evaluate` and `script.callFunction` with a sandbox name equal to an empty string, the evaluation will now be done using the default realm ([Firefox bug 1793589](https://bugzil.la/1793589 "External link (opens in new tab)")).
*   Added support for the `browsingContext.domContentLoaded` event ([Firefox bug 1756610](https://bugzil.la/1756610 "External link (opens in new tab)")).

#### Marionette

*   Added support for the `tiltX`, `tiltY` and `twist` properties of pointer actions for `WebDriver:PerformActions` ([Firefox bug 1793832](https://bugzil.la/1793832 "External link (opens in new tab)")).
*   Fixed a bug where `WebDriver:GetElementText` wasn't returning the element text for pretty-printed XML ([Firefox bug 1794099](https://bugzil.la/1794099 "External link (opens in new tab)")).
*   `HTMLDocument` is no longer serialized as a `WebElement` reference ([Firefox bug 1793920](https://bugzil.la/1793920 "External link (opens in new tab)")).
*   `WebDriver:NewWindow` now opens a window with an `about:blank` tab instead of `about:newtab` ([Firefox bug 1533058](https://bugzil.la/1533058 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   Firefox now issues a warning when an extension is installed if its [version number](/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/version) doesn't follow the recommended format ([Firefox bug 1793925](https://bugzil.la/1793925 "External link (opens in new tab)")).
