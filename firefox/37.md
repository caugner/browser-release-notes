# Firefox 37 release notes for developers

Firefox 37 was released on March 31st, 2015. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   [Security panel in the Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html#security "External link (opens in new tab)")
*   [Animations panel in the Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/work_with_animations/index.html#firefox-37 "External link (opens in new tab)")
*   _Support for running a custom build step in WebIDE_

[All devtools bugs fixed between Firefox 36 and Firefox 37](https://bugzilla.mozilla.org/buglist.cgi?resolution=FIXED&classification=Client%20Software&chfieldto=2015-01-12&chfield=resolution&query_format=advanced&chfieldfrom=2014-11-28&chfieldvalue=FIXED&bug_status=RESOLVED&bug_status=VERIFIED&component=Developer%20Tools&component=Developer%20Tools%3A%203D%20View&component=Developer%20Tools%3A%20Canvas%20Debugger&component=Developer%20Tools%3A%20Console&component=Developer%20Tools%3A%20Debugger&component=Developer%20Tools%3A%20Framework&component=Developer%20Tools%3A%20Graphic%20Commandline%20and%20Toolbar&component=Developer%20Tools%3A%20Inspector&component=Developer%20Tools%3A%20Memory&component=Developer%20Tools%3A%20Netmonitor&component=Developer%20Tools%3A%20Object%20Inspector&component=Developer%20Tools%3A%20Profiler&component=Developer%20Tools%3A%20Responsive%20Mode&component=Developer%20Tools%3A%20Scratchpad&component=Developer%20Tools%3A%20Source%20Editor&component=Developer%20Tools%3A%20Storage%20Inspector&component=Developer%20Tools%3A%20Style%20Editor&component=Developer%20Tools%3A%20Timeline&component=Developer%20Tools%3A%20User%20Stories&component=Developer%20Tools%3A%20Web%20Audio%20Editor&component=Developer%20Tools%3A%20WebGL%20Shader%20Editor&component=Developer%20Tools%3A%20WebIDE&product=Firefox&list_id=11892733 "External link (opens in new tab)").

### [CSS](#css)

*   `display: contents` is now activated by default ([Firefox bug 1102374](https://bugzil.la/1102374 "External link (opens in new tab)") and [Firefox bug 1105369](https://bugzil.la/1105369 "External link (opens in new tab)")).
*   [CSS multi-column layout](/en-US/docs/Web/CSS/Guides/Multicol_layout/Using) is now working on elements with `display: table-caption` ([Firefox bug 1109571](https://bugzil.la/1109571 "External link (opens in new tab)")).
*   Relative positioning (`position: relative`) of table cells has been implemented ([Firefox bug 35168](https://bugzil.la/35168 "External link (opens in new tab)")).
*   The quirks mode behavior of [`empty-cells`](/en-US/docs/Web/CSS/Reference/Properties/empty-cells) has been removed: it now defaults to `show` like in standard mode ([Firefox bug 1020400](https://bugzil.la/1020400 "External link (opens in new tab)")).

### [HTML](#html)

*   The value `<a rel="noreferrer">` now also works when the link is opened in new tab ([Firefox bug 1031264](https://bugzil.la/1031264 "External link (opens in new tab)")).
*   The `'.'` followed by the extension is now allowed in `<input accept>`: when used, a file selector filters with this given extension to be proposed to the user ([Firefox bug 826176](https://bugzil.la/826176 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The [`Map`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map), [`Set`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set), [`WeakMap`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakMap) and [`WeakSet`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakSet) constructors now ignore null iterable ([Firefox bug 1092538](https://bugzil.la/1092538 "External link (opens in new tab)")).
    
*   The [`Map`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map), [`Set`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set), [`WeakMap`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakMap) and [`WeakSet`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakSet) constructors now supports monkey-patched `prototype.set` or `prototype.add` ([Firefox bug 804279](https://bugzil.la/804279 "External link (opens in new tab)")).
    
*   The Non-standard `String.prototype.quote()` method has been removed ([Firefox bug 1103181](https://bugzil.la/1103181 "External link (opens in new tab)")).
    
*   The [`RegExp.prototype.flags`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/flags) property has been implemented ([Firefox bug 1108467](https://bugzil.la/1108467 "External link (opens in new tab)")).
    
*   Several [`Array`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) methods have been implemented for [typed arrays](/en-US/docs/Web/JavaScript/Guide/Typed_arrays) as well:
    
    *   The [`every()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/every) and [`some()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/some) methods ([Firefox bug 1116390](https://bugzil.la/1116390 "External link (opens in new tab)")).
    *   The [`find()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/find) and [`findIndex()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/findIndex) methods ([Firefox bug 1078975](https://bugzil.la/1078975 "External link (opens in new tab)")).
    *   The [`fill()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/fill) method ([Firefox bug 1113722](https://bugzil.la/1113722 "External link (opens in new tab)")).
    *   The [`indexOf()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/indexOf) and [`lastIndexOf()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/lastIndexOf) methods ([Firefox bug 1107601](https://bugzil.la/1107601 "External link (opens in new tab)")).
    *   The [`join()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/join) method ([Firefox bug 1115817](https://bugzil.la/1115817 "External link (opens in new tab)")).
    *   The [`reduce()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/reduce) and [`reduceRight()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/reduceRight) methods ([Firefox bug 1117350](https://bugzil.la/1117350 "External link (opens in new tab)")).
    *   The [`reverse()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/reverse) method ([Firefox bug 1111516](https://bugzil.la/1111516 "External link (opens in new tab)")).
    *   The [`keys()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/keys), [`values()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/values), and [`entries()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/entries) methods ([Firefox bug 1119217](https://bugzil.la/1119217 "External link (opens in new tab)")).
*   The ES2015 [`Proxy`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy) enumerate trap for [`for...in`](/en-US/docs/Web/JavaScript/Reference/Statements/for...in) statements is implemented ([Firefox bug 783829](https://bugzil.la/783829 "External link (opens in new tab)")).
    
*   The `configurable` attribute of the [`Function.length`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Function/length) property is now `true` per the ES2015 specification ([Firefox bug 911142](https://bugzil.la/911142 "External link (opens in new tab)")).
    
*   The development of [ParallelJS (PJS)](https://web.archive.org/web/20161113115816/http://wiki.ecmascript.org/doku.php?id=strawman:data_parallelism "External link (opens in new tab)") has been discontinued due to the limited future prospects, little attention and code complexity. The experimental implementation that had been enabled only on the Nightly channel, including the `Array.prototype.mapPar`, `filterPar` and `reducePar` methods, has been completely removed.
    

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   The [`StereoPannerNode`](/en-US/docs/Web/API/StereoPannerNode) [Web Audio](/en-US/docs/Web/API/Web_Audio_API) node has been implemented ([Firefox bug 1100349](https://bugzil.la/1100349 "External link (opens in new tab)")).
    
*   The [`Promise`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise)\-based version of [`OfflineAudioContext`](/en-US/docs/Web/API/OfflineAudioContext) is now available ([Firefox bug 1087944](https://bugzil.la/1087944 "External link (opens in new tab)")).
    
*   The experimental, not activated by default, implementation of [Service Workers](/en-US/docs/Web/API/Service_Worker_API) progresses: [`ServiceWorkerGlobalScope.update()`](/en-US/docs/Web/API/ServiceWorkerRegistration/update "ServiceWorkerGlobalScope.update()") has been implemented [Firefox bug 1065366](https://bugzil.la/1065366 "External link (opens in new tab)").
    
*   The [IndexedDB API](/en-US/docs/Web/API/IndexedDB_API) can now be used in [Web workers](/en-US/docs/Web/API/Web_Workers_API) ([Firefox bug 701634](https://bugzil.la/701634 "External link (opens in new tab)")).
    
*   Our experimental implementation of WebGL 2.0 is going forward!
    
    *   The [`WebGL2RenderingContext.getBufferSubData()`](/en-US/docs/Web/API/WebGL2RenderingContext/getBufferSubData) method has been implemented to provide access to Buffer Objects ([Firefox bug 1048731](https://bugzil.la/1048731 "External link (opens in new tab)")).
*   In keeping with the evolving WebRTC specification, we have deprecated `RTCIceServer.url` in favor of `RTCIceServer.urls`, which lets you specify more than one URL for a given ICE server.
    
*   Some key names of `KeyboardEvent.key` are changed for conforming [the latest DOM Level 3 Events spec](https://w3c.github.io/DOM-Level-3-Events-key/ "External link (opens in new tab)"). See [the tables of `KeyboardEvent.key` values in MDN](/en-US/docs/Web/API/UI_Events/Keyboard_event_key_values). Meta bug for these changes is [Firefox bug 900372](https://bugzil.la/900372 "External link (opens in new tab)").
    
*   The [`console`](/en-US/docs/Web/API/console) interface is now working on [`ServiceWorker`](/en-US/docs/Web/API/ServiceWorker) and [`SharedWorker`](/en-US/docs/Web/API/SharedWorker). It was previously available but not working ([Firefox bug 1058644](https://bugzil.la/1058644 "External link (opens in new tab)")).
    
*   The value of [`KeyboardEvent.key`](/en-US/docs/Web/API/KeyboardEvent/key) was incorrectly being reported as `"RomanCharacters"` when the `英数` (`Eisu`) key was pressed. Now it correctly returns `"Eisu"`.
    

### [MathML](#mathml)

_No change._

### [SVG](#svg)

*   SVG2's `<marker orient="auto-start-reverse">` has been implemented ([Firefox bug 1107584](https://bugzil.la/1107584 "External link (opens in new tab)")).

### [Audio/Video](#audiovideo)

_No change._

## [Networking](#networking)

*   WebSockets now supports the `permessage` compression method, if the server does support it ([Firefox bug 792831](https://bugzil.la/792831 "External link (opens in new tab)")).

## [Security](#security)

*   The usage of weak protocols or ciphers, like SSL 3.0 and RC4, are now logged in the console, to warn sites that are using it ([Firefox bug 1092835](https://bugzil.la/1092835 "External link (opens in new tab)")).
*   The [CSP](/en-US/docs/Web/HTTP/Guides/CSP) 1.1 `referrer` [directive](/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy) is now supported ([Firefox bug 965727](https://bugzil.la/965727 "External link (opens in new tab)")).
