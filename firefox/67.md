# Firefox 67 release notes for developers

This article provides information about the changes in Firefox 67 that will affect developers. Firefox 67 was released on May 21, 2019.

## [Changes for web developers](#changes_for_web_developers)

### [Developer tools](#developer_tools)

*   Debugger updates:
    
    *   [Column breakpoints](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/set_a_breakpoint/index.html "External link (opens in new tab)") allow you to select the specific point (or column) in a line of code where you want the debugger to break ([Firefox bug 1528417](https://bugzil.la/1528417 "External link (opens in new tab)")).
    *   [Log points](https://firefox-source-docs.mozilla.org/devtools-user/debugger/set_a_logpoint/index.html "External link (opens in new tab)") allow you to log specific information to the console during code execution without pausing execution and without the need to change the code.
    *   The [map scopes feature](https://firefox-source-docs.mozilla.org/devtools-user/debugger/using_the_debugger_map_scopes_feature/index.html "External link (opens in new tab)") allows you to view the variables from the original source.
    *   You can [debug worker](/en-US/docs/Web/API/Web_Workers_API/Using_web_workers#debugging_worker_threads) threads directly in the debugger.
*   [Web Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html "External link (opens in new tab)") updates:
    
    *   Navigate details in the console using the keyboard ([Firefox bug 1424159](https://bugzil.la/1424159 "External link (opens in new tab)")).
    *   Cmd + K will now clear the console of its contents on macOS ([Firefox bug 1532939](https://bugzil.la/1532939 "External link (opens in new tab)")).
    *   When the user clears the console, the error messages cache is cleared as well ([Firefox bug 717611](https://bugzil.la/717611 "External link (opens in new tab)")).
    *   The user can import existing modules into the current page using import ([Firefox bug 1517546](https://bugzil.la/1517546 "External link (opens in new tab)")).
    *   A new context menu item allows the user to use the **Copy Link Location** command ([Firefox bug 1457111](https://bugzil.la/1457111 "External link (opens in new tab)")).
    *   Clicking a link in the Console causes the same behavior that it would in a content window ([Firefox bug 1466040](https://bugzil.la/1466040 "External link (opens in new tab)")).
    *   Clicking the source link for a code file in the Console panel navigates to the Debugger if debugger knows the file ([Firefox bug 1447244](https://bugzil.la/1447244 "External link (opens in new tab)")).
    *   When the user has filtered the contents of the console, an icon will be added to the filter text box to clear the filter ([Firefox bug 1525821](https://bugzil.la/1525821 "External link (opens in new tab)")).
*   [Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html "External link (opens in new tab)") enhancements:
    
    *   The [Header](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_details/index.html#headers "External link (opens in new tab)") panel of the Network monitor will now display a notification for resources belonging to a known tracker ([Firefox bug 1485416](https://bugzil.la/1485416 "External link (opens in new tab)")).
    *   In the Network monitor [request columns](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_list/index.html#network-request-columns "External link (opens in new tab)"), you can control the visible columns and column sorting. The context menu now includes a command to restore the list sort parameters to the default ([Firefox bug 1454962](https://bugzil.la/1454962 "External link (opens in new tab)")).
    *   You can change the [width of the columns](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_list/index.html#network-request-columns "External link (opens in new tab)") in the Network Monitor to suit your workflow ([Firefox bug 1358414](https://bugzil.la/1358414 "External link (opens in new tab)")).

#### Removals

*   The following Developer Tools panels have been removed (see [Deprecated tools](https://firefox-source-docs.mozilla.org/devtools-user/deprecated_tools/index.html "External link (opens in new tab)") for details):
    
    *   Canvas debugger ([Firefox bug 1403938](https://bugzil.la/1403938 "External link (opens in new tab)")).
    *   Shader editor ([Firefox bug 1342237](https://bugzil.la/1342237 "External link (opens in new tab)")).
    *   WebAudio editor ([Firefox bug 1403944](https://bugzil.la/1403944 "External link (opens in new tab)")).
*   The following Developer Tools have been deprecated (see [Deprecated tools](https://firefox-source-docs.mozilla.org/devtools-user/deprecated_tools/index.html "External link (opens in new tab)") for details):
    
    *   WebIDE ([Firefox bug 1539462](https://bugzil.la/1539462 "External link (opens in new tab)")).
    *   Connect… page ([Firefox bug 1539462](https://bugzil.la/1539462 "External link (opens in new tab)")).

### [HTML](#html)

*   [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) elements with `autocomplete="new-password"` set on them will no longer have previously saved passwords auto-filled ([Firefox bug 1119063](https://bugzil.la/1119063 "External link (opens in new tab)")).

### [CSS](#css)

*   The [`revert`](/en-US/docs/Web/CSS/Reference/Values/revert) keyword has been implemented ([Firefox bug 1215878](https://bugzil.la/1215878 "External link (opens in new tab)")).
*   The `break-word` value of the [`word-break`](/en-US/docs/Web/CSS/Reference/Properties/word-break) property is now supported ([Firefox bug 1296042](https://bugzil.la/1296042 "External link (opens in new tab)")).
*   The [`prefers-color-scheme`](/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme) media feature is now supported ([Firefox bug 1494034](https://bugzil.la/1494034 "External link (opens in new tab)")).
*   Custom [`cursor`](/en-US/docs/Web/CSS/Reference/Properties/cursor)s of greater than 32px in size are now disallowed, to mitigate potential malware uses of large cursors ([Firefox bug 1445844](https://bugzil.la/1445844 "External link (opens in new tab)")).

#### Removals

*   Use of the proprietary `-moz-binding` property is now restricted to chrome and UA-stylesheets ([Firefox bug 1523712](https://bugzil.la/1523712 "External link (opens in new tab)")).

### [SVG](#svg)

_No changes._

### [JavaScript](#javascript)

*   [`String.prototype.matchAll`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/matchAll) has been implemented and enabled by default ([Firefox bug 1435829](https://bugzil.la/1435829 "External link (opens in new tab)"), [Firefox bug 1531830](https://bugzil.la/1531830 "External link (opens in new tab)")).
*   Support for the dynamic [`import()`](/en-US/docs/Web/JavaScript/Reference/Operators/import) proposal is now available by default ([Firefox bug 1517546](https://bugzil.la/1517546 "External link (opens in new tab)")).
*   The [hashbang grammar](/en-US/docs/Web/JavaScript/Reference/Lexical_grammar#hashbang_comments) proposal is now implemented ([Firefox bug 1519097](https://bugzil.la/1519097 "External link (opens in new tab)")).

### [APIs](#apis)

#### DOM

*   The default value for [`Response.statusText`](/en-US/docs/Web/API/Response/statusText) is now `""` ([Firefox bug 1508996](https://bugzil.la/1508996 "External link (opens in new tab)")).
*   User gestures are now preserved for rejected calls to [`Document.requestStorageAccess`](/en-US/docs/Web/API/Document/requestStorageAccess), as well as fulfilled calls ([Firefox bug 1522912](https://bugzil.la/1522912 "External link (opens in new tab)")).

#### DOM events

*   CSS transition ([Firefox bug 1530239](https://bugzil.la/1530239 "External link (opens in new tab)")) and animation ([Firefox bug 1531605](https://bugzil.la/1531605 "External link (opens in new tab)")) events now fire on disabled (e.g., form) elements.
*   [`InputEvent.data`](/en-US/docs/Web/API/InputEvent/data) and [`InputEvent.dataTransfer`](/en-US/docs/Web/API/InputEvent/dataTransfer) have been implemented ([Firefox bug 998941](https://bugzil.la/998941 "External link (opens in new tab)")).
*   The `insertFromPasteAsQuotation` [`InputEvent.inputType`](/en-US/docs/Web/API/InputEvent/inputType) value is now supported ([Firefox bug 1532527](https://bugzil.la/1532527 "External link (opens in new tab)")).

#### Workers/Service workers

*   Strict MIME type checks are now enforced on scripts imported by [`WorkerGlobalScope.importScripts()`](/en-US/docs/Web/API/WorkerGlobalScope/importScripts) ([Firefox bug 1514680](https://bugzil.la/1514680 "External link (opens in new tab)")).

#### Media, Web Audio, and WebRTC

*   The [AV1 video codec](/en-US/docs/Web/Media/Guides/Formats/Video_codecs#av1) is now supported on Linux.
*   [dav1d](https://code.videolan.org/videolan/dav1d "External link (opens in new tab)") is now the default media decoder for [AV1](https://aomediacodec.github.io/av1-spec/av1-spec.pdf "External link (opens in new tab)") (see for example [Firefox bug 1533742](https://bugzil.la/1533742 "External link (opens in new tab)") and [Firefox bug 1535038](https://bugzil.la/1535038 "External link (opens in new tab)")).
*   Calling [`RTCPeerConnection.addTrack()`](/en-US/docs/Web/API/RTCPeerConnection/addTrack) without specifying any streams to which to add the new track now works as expected: it adds a streamless track to the connection. Each peer is responsible for managing the association between the track and any stream on its end ([Firefox bug 1231414](https://bugzil.la/1231414 "External link (opens in new tab)")).
*   The [`MediaDeviceInfo.groupId`](/en-US/docs/Web/API/MediaDeviceInfo/groupId) property is now implemented ([Firefox bug 1213453](https://bugzil.la/1213453 "External link (opens in new tab)")). While it has existed in Firefox since Firefox 39, it did not actually gather related devices together into the same group IDs.
*   The [`RTCIceCandidate.usernameFragment`](/en-US/docs/Web/API/RTCIceCandidate/usernameFragment) property is now implemented ([Firefox bug 1490658](https://bugzil.la/1490658 "External link (opens in new tab)")).
*   [WebVTT](/en-US/docs/Web/API/WebVTT_API) has been revised to correctly use `auto` as the default for the [`VTTCue`](/en-US/docs/Web/API/VTTCue) object's [`positionAlign`](/en-US/docs/Web/API/VTTCue/positionAlign "positionAlign") property, instead of `center`. This causes the cue box's alignment to correspond to the alignment of the text within it ([Firefox bug 1528420](https://bugzil.la/1528420 "External link (opens in new tab)")).

#### Canvas and WebGL

*   The [`EXT_float_blend`](/en-US/docs/Web/API/EXT_float_blend) WebGL extension has been enabled by default ([Firefox bug 1535808](https://bugzil.la/1535808 "External link (opens in new tab)")).

#### Removals

*   The deprecated `ShadowRoot.getElementsByTagName`, `ShadowRoot.getElementsByTagNameNS`, and `ShadowRoot.getElementsByClassName` properties (part of Shadow DOM v0) have been removed ([Firefox bug 1535438](https://bugzil.la/1535438 "External link (opens in new tab)")).
*   [`document.createEvent("TouchEvent")`](/en-US/docs/Web/API/Document/createEvent), [`document.createTouch()`](/en-US/docs/Web/API/Document/createTouch), [`document.createTouchList()`](/en-US/docs/Web/API/Document/createTouchList), and the `ontouch*` event handler properties have been disabled on desktop to improve web compatibility on websites where touch support is used for mobile detection ([Firefox bug 1412485](https://bugzil.la/1412485 "External link (opens in new tab)")). In such cases, websites have been seen to behave incorrectly or unexpectedly on touchscreen laptops.

### [Security](#security)

*   [Notifications](/en-US/docs/Web/API/Notifications_API) are now only available in a [secure context](/en-US/docs/Web/Security/Defenses/Secure_Contexts) ([Firefox bug 1429432](https://bugzil.la/1429432 "External link (opens in new tab)")).
*   Firefox now blocks the loading of external protocol URLs in [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe)s ([Firefox bug 1527882](https://bugzil.la/1527882 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

#### API changes

*   Made `WebDriver:SendAlertText` conformant to the [WebDriver specification](https://w3c.github.io/webdriver/ "External link (opens in new tab)") ([Firefox bug 1502360](https://bugzil.la/1502360 "External link (opens in new tab)")).

#### Bug fixes

*   `WebDriver:NewWindow` will no longer timeout because inconsistencies across platforms regarding the `focus` event ([Firefox bug 1523234](https://bugzil.la/1523234 "External link (opens in new tab)")).

#### Others

*   Both `WebDriver:ExecuteScript` and `WebDriver:ExecuteAsyncScript` now use `Promises` internally ([Firefox bug 1398095](https://bugzil.la/1398095 "External link (opens in new tab)")).
*   `WebDriver:NewSession` returns Firefox's `BuildID` string as part of the capabilities object ([Firefox bug 1525829](https://bugzil.la/1525829 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

### [API changes](#api_changes_2)

*   Using the `proxy.settings.set()` method to change [`BrowserSetting`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/types/BrowserSetting) values will throw an exception unless the extension was granted private window access by the user ([Firefox bug 1525447](https://bugzil.la/1525447 "External link (opens in new tab)")).

### [Manifest changes](#manifest_changes)

*   A new manifest key, [incognito](/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/incognito), defines the behavior of an extension in private browsing windows or tabs ([Firefox bug 1511636](https://bugzil.la/1511636 "External link (opens in new tab)")).
*   The `toolbar_field_highlight` setting controls the background color used to indicate the current selection of text in the URL bar ([Firefox bug 1450114](https://bugzil.la/1450114 "External link (opens in new tab)")).
*   The `toolbar_field_highlight_text` setting controls the text color used to indicate the current selection of text in the URL bar ([Firefox bug 1450114](https://bugzil.la/1450114 "External link (opens in new tab)")).
