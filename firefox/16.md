# Firefox 16 release notes for developers

Firefox 16 shipped on October 9, 2012. This article lists key changes that are useful for not only Web developers to know about, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer tools](#developer_tools)

*   There's now a handy developer toolbar you can access by going to Tools > Web Developer > Developer Toolbar, or by pressing Ctrl-Shift-V (Cmd-Opt-V on Mac OS X). This toolbar offers a command-line interface as well as buttons for quickly accessing useful tools. The graphical command-line interface _GCLI_ is easy to expand and additional commands are expected in the future. Type "help" to get a list of supported commands.
*   The Web Console now displays an error count so you can quickly see how much work you have ahead of you.
*   The Scratchpad now offers a list of recently opened files.

### [HTML](#html)

*   The [`<meter>`](/en-US/docs/Web/HTML/Reference/Elements/meter) element is now supported.
*   Support for the HTML Microdata API has been added. ([bug 591467](https://bugzil.la/591467 "External link (opens in new tab)"))
*   [`<canvas>`](/en-US/docs/Web/HTML/Reference/Elements/canvas) now supports the CSS `currentColor` in all case. ([Firefox bug 629882](https://bugzil.la/629882 "External link (opens in new tab)"))
*   [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) now allows filtering based on arbitrary mimetypes in `accept` ([Firefox bug 565274](https://bugzil.la/565274 "External link (opens in new tab)")).
*   Two new attributes, `width` and `height` have been added to the [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) element ([bug 683855](https://bugzil.la/683855 "External link (opens in new tab)")).

### [CSS](#css)

*   Support for the standard, unprefixed version of [CSS Animations](/en-US/docs/Web/CSS/Guides/Animations/Using) has been landed ([bug 762302](https://bugzil.la/762302 "External link (opens in new tab)")).
*   Support for reverse animation direction (keywords `reverse` and `alternate-reverse` on the [`animation-direction`](/en-US/docs/Web/CSS/Reference/Properties/animation-direction) property) has been added. ([bug 655920](https://bugzil.la/655920 "External link (opens in new tab)")).
*   You can now animate the CSS [`height`](/en-US/docs/Web/CSS/Reference/Properties/height) and [`width`](/en-US/docs/Web/CSS/Reference/Properties/width) properties.
*   The [`animation-duration`](/en-US/docs/Web/CSS/Reference/Properties/animation-duration) and [`transition-duration`](/en-US/docs/Web/CSS/Reference/Properties/transition-duration) CSS properties now reject negative values (and do not handle them as `0s` anymore) ([bug 773102](https://bugzil.la/773102 "External link (opens in new tab)")).
*   Support for the standard, unprefixed version of [CSS Transforms](/en-US/docs/Web/CSS/Guides/Transforms/Using) has been landed ([bug 745523](https://bugzil.la/745523 "External link (opens in new tab)")). [`<length>`](/en-US/docs/Web/CSS/Reference/Values/length) cannot be used for translation values in `matrix()` and `matrix3d()` anymore ([Firefox bug 719054](https://bugzil.la/719054 "External link (opens in new tab)")).
*   Support for the standard, unprefixed version of [CSS Gradients](/en-US/docs/Web/CSS/Guides/Images/Using_gradients) has been landed. Note that the syntax has changed significantly since the prefixed version, so you should read up on this ([bug 752187](https://bugzil.la/752187 "External link (opens in new tab)")).
*   The [`-moz-box-sizing`](/en-US/docs/Web/CSS/Reference/Properties/box-sizing) implementation has been updated to apply to table cells too ([bug 338554](https://bugzil.la/338554 "External link (opens in new tab)")).
*   Support for the standard, unprefixed version of [`calc()`](/en-US/docs/Web/CSS/Reference/Values/calc) has been landed ([bug 771678](https://bugzil.la/771678 "External link (opens in new tab)")).
*   The [`<resolution>`](/en-US/docs/Web/CSS/Reference/Values/resolution) CSS data type has been extended to support the `dppx` ([bug 741644](https://bugzil.la/741644 "External link (opens in new tab)")).
*   On screen, for [media queries](/en-US/docs/Web/CSS/Guides/Media_queries/Using), `dppx`, `dpi`, and `dpcm` are now representing values based on CSS pixels and no more with the physical units ([bug 771390](https://bugzil.la/771390 "External link (opens in new tab)")).
*   Three new pseudo-classes `:-moz-meter-optimum`, `:-moz-meter-sub-optimum`, and `:-moz-meter-sub-sub-optimum` have been added for accessing/styling a [`<meter>`](/en-US/docs/Web/HTML/Reference/Elements/meter) element in a particular state ([bug 660238](https://bugzil.la/660238 "External link (opens in new tab)")).
*   The [`appearance`](/en-US/docs/Web/CSS/Reference/Properties/appearance) property gains two new values: `meterbar` and `meterchunk`. They represent components inside the [`<meter>`](/en-US/docs/Web/HTML/Reference/Elements/meter) element ([bug 659999](https://bugzil.la/659999 "External link (opens in new tab)")).
*   The [`min-width`](/en-US/docs/Web/CSS/Reference/Properties/min-width) and [`min-height`](/en-US/docs/Web/CSS/Reference/Properties/min-height) now supports the `auto` keyword for flex items (and resolves to `0` for other items) ([Firefox bug 763689](https://bugzil.la/763689 "External link (opens in new tab)")).

### [API/DOM](#apidom)

*   Two new properties `width` and `height` have been added to the [`HTMLInputElement`](/en-US/docs/Web/API/HTMLInputElement) interface ([bug 683855](https://bugzil.la/683855 "External link (opens in new tab)")).
*   IndexedDB properties and methods have been unprefixed. ([bug 726378](https://bugzil.la/726378 "External link (opens in new tab)"))
*   The [Battery API](/en-US/docs/Web/API/Navigator/getBattery) is now unprefixed.
*   The Vibration API has been unprefixed.
*   The non-standard `Keyboard` interface, prefixed as `mozKeyboard`, now has the `Keyboard.setSelectedOption()` and `Keyboard.setValue()` methods, as well as the `Keyboard.onfocuschange`. _This interface, only available for Firefox OS, has been removed in Firefox 31._
*   The [`java`](https://web.archive.org/web/20201004062409/https://developer.mozilla.org/en-US/docs/Archive/Web/LiveConnect_Reference/java "External link (opens in new tab)") and [`Packages`](https://web.archive.org/web/20201031083247/https://developer.mozilla.org/en-US/docs/Archive/Web/LiveConnect_Reference/Packages "External link (opens in new tab)") global objects have been removed. See [LiveConnect](https://web.archive.org/web/20210516230302/https://developer.mozilla.org/en-US/docs/Archive/Web/LiveConnect "External link (opens in new tab)").
*   The `CSSRule.type` associated with [`CSSNamespaceRule`](/en-US/docs/Web/API/CSSNamespaceRule) has been updated from `UNKNOWN_RULE` (`0`) to `NAMESPACE_RULE` (`10`) ([bug 765590](https://bugzil.la/765590 "External link (opens in new tab)")).
*   WebSMS API: `SmsRequest` has been superseded by the more general `DOMRequest`.
*   The non-standard [`Element.scrollTopMax`](/en-US/docs/Web/API/Element/scrollTopMax) and [`Element.scrollLeftMax`](/en-US/docs/Web/API/Element/scrollLeftMax) read-only properties have been added ([Firefox bug 766937](https://bugzil.la/766937 "External link (opens in new tab)")).
*   The second parameter of [`Blob()`](/en-US/docs/Web/API/Blob/Blob "Blob()"), when set to `null` or `undefined`, is now being handled as an empty dictionary ([Firefox bug 7691119](https://bugzil.la/7691119 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   [`Number`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number) objects now offer `isFinite()`, `toInteger()`, and `isInteger()` methods. ([bug 761480](https://bugzil.la/761480 "External link (opens in new tab)"), [bug 761495](https://bugzil.la/761495 "External link (opens in new tab)"))
*   The Harmony [spread operator](https://web.archive.org/web/20161222114355/http://wiki.ecmascript.org/doku.php?id=harmony:spread "External link (opens in new tab)") is now supported in [`Array`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) initializers ([bug 574130](https://bugzil.la/574130 "External link (opens in new tab)")). Note it is not yet supported in calls ([bug 762363](https://bugzil.la/762363 "External link (opens in new tab)")).
*   The experimental `TypedArray.prototype.move()` method has been added (available in Aurora and Nightly channels only) ([Firefox bug 730873](https://bugzil.la/730873 "External link (opens in new tab)")).

### [WebGL](#webgl)

_No change._

### [SVG](#svg)

_No change._

### [MathML](#mathml)

*   The `lspace` and `rspace` attributes of [`<mo>`](/en-US/docs/Web/MathML/Reference/Element/mo "<mo>") now correctly default to `thickmathspace`.

## [Changes for Open Web App developers](#changes_for_open_web_app_developers)

*   Initial [Open Web App support](https://web.archive.org/web/20190117093115/https://developer.mozilla.org/en-US/docs/Web/Apps/Getting_Started "External link (opens in new tab)") has been implemented in the desktop versions of Firefox (that is, on Windows, Mac OS X, and Linux).

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

### [Interface changes](#interface_changes)

`nsIPrivateDOMEvent` has been merged into `nsIDOMEvent`. ([Firefox bug 761613](https://bugzil.la/761613 "External link (opens in new tab)"))
