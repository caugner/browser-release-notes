# Firefox 43 release notes for developers

[To test the latest developer features of Firefox, install Firefox Developer Edition](https://www.firefox.com/en-US/channel/desktop/developer/ "External link (opens in new tab)") Firefox 43 was released on December 15, 2015. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   [Server logging in the Web Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#server "External link (opens in new tab)")
*   [Quickly find the rule that overrode a CSS declaration](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#overridden-declarations "External link (opens in new tab)")
*   ["Use in Console" context menu item in Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_html/index.html#element-popup-menu "External link (opens in new tab)")
*   ["Strict" option for filtering in the Rules view](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#strict-search "External link (opens in new tab)")
*   [Network entries in the Console now link to the Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#network "External link (opens in new tab)")
*   [Markup view shows indicators for pseudo-classes locked for elements](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#setting-hover-active-focus "External link (opens in new tab)")
*   New sidebar UI for WebIDE

### [CSS](#css)

*   Support for the standard, unprefixed version of [`hyphens`](/en-US/docs/Web/CSS/Reference/Properties/hyphens) has been landed ([Firefox bug 953408](https://bugzil.la/953408 "External link (opens in new tab)")).
*   The shorthand property [`font`](/en-US/docs/Web/CSS/Reference/Properties/font) has been updated to accept [`font-stretch`](/en-US/docs/Web/CSS/Reference/Properties/font-stretch) values ([Firefox bug 1057680](https://bugzil.la/1057680 "External link (opens in new tab)")).
*   To match the latest evolution of the specification, the [`:fullscreen`](/en-US/docs/Web/CSS/Reference/Selectors/:fullscreen) pseudo-class now selects the whole stack of elements in full screen, and not only the top-level one ([Firefox bug 1199522](https://bugzil.la/1199522 "External link (opens in new tab)")).
*   The deprecated SVG values for the [`writing-mode`](/en-US/docs/Web/CSS/Reference/Properties/writing-mode), `lr`, `lr-tb`, `rl`, `tb`, and `tb-rl`, have been added in CSS as aliases to standard properties ([Firefox bug 1205787](https://bugzil.la/1205787 "External link (opens in new tab)")).

### [HTML](#html)

*   For [`<img>`](/en-US/docs/Web/HTML/Reference/Elements/img) with ICO image containing multiple frames, the intrinsic dimension of the image is set to the one of the largest frame, and no more of the smallest frame [Firefox bug 1201796](https://bugzil.la/1201796 "External link (opens in new tab)").
*   The value of the document's viewport (defined with `<meta name="viewport>`)can now dynamically be changed via JavaScript ([Firefox bug 976616](https://bugzil.la/976616 "External link (opens in new tab)")).

### [JavaScript](#javascript)

#### New APIs

*   The new ES2016 methods [`Array.prototype.includes()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/includes) and [`TypedArray.prototype.includes()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/includes) are now enabled by default ([Firefox bug 1070767](https://bugzil.la/1070767 "External link (opens in new tab)")).

#### Changes regarding the `arguments` object

*   To match the ES2015 specification, [arrow functions](/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions) no longer have their own [`arguments`](/en-US/docs/Web/JavaScript/Reference/Functions/arguments) object. The `arguments` object is now lexically bound (inherited from the outer function). In most cases, [rest parameters](/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters) are a good alternative `(...args) => args[i]`, see [Firefox bug 889158](https://bugzil.la/889158 "External link (opens in new tab)").
*   The [arguments](/en-US/docs/Web/JavaScript/Reference/Functions/arguments) object is now allowed in conjunction with [rest parameters](/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters) ([Firefox bug 1133298](https://bugzil.la/1133298 "External link (opens in new tab)")).
*   From now on, a mapped [`arguments`](/en-US/docs/Web/JavaScript/Reference/Functions/arguments) object in non-strict functions is only provided if the function does **not** contain any [rest parameters](/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters), any [default parameters](/en-US/docs/Web/JavaScript/Reference/Functions/Default_parameters) or any [destructured parameters](/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring) ([Firefox bug 1175394](https://bugzil.la/1175394 "External link (opens in new tab)")).

#### Other changes

*   [Generators](/en-US/docs/Web/JavaScript/Reference/Statements/function*) and [generator methods](/en-US/docs/Web/JavaScript/Reference/Functions/Method_definitions) are no longer constructable as per ES2016 ([Firefox bug 1191486](https://bugzil.la/1191486 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

#### DOM & HTML DOM

_No change._

#### IndexedDB

*   A new feature called locale-aware sorting has been added allowing for the creation of indexes with a locale specified, which can then be used to sort data according to the rules of that locale ([Firefox bug 871846](https://bugzil.la/871846 "External link (opens in new tab)")). This is a non-standard Firefox-specific feature.

#### Service Workers

*   As per the specification, if [`ExtendableEvent.waitUntil()`](/en-US/docs/Web/API/ExtendableEvent/waitUntil) is called outside of the [`ExtendableEvent`](/en-US/docs/Web/API/ExtendableEvent) handler, Firefox will now throw an `InvalidStateError`; in addition, multiple calls to [`waitUntil()`](/en-US/docs/Web/API/ExtendableEvent/waitUntil "waitUntil()") will now stack up, and the resulting promises will be added to the list of [extend lifetime promises](https://slightlyoff.github.io/ServiceWorker/spec/service_worker/index.html#dfn-extend-lifetime-promises "External link (opens in new tab)") ([Firefox bug 1180274](https://bugzil.la/1180274 "External link (opens in new tab)")).
*   [`PushMessageData`](/en-US/docs/Web/API/PushMessageData) methods have been implemented ([Firefox bug 1149195](https://bugzil.la/1149195 "External link (opens in new tab)")).

#### WebRTC

*   The [`HTMLCanvasElement.captureStream()`](/en-US/docs/Web/API/HTMLCanvasElement/captureStream) method has been activated by default ([Firefox bug 1177276](https://bugzil.la/1177276 "External link (opens in new tab)")).
*   The non-standard constraint style option list for `RTCOfferOptions` has been deprecated and will be removed entirely in Firefox 44.

#### Miscellaneous

*   The [Battery Status API](/en-US/docs/Web/API/Battery_Status_API) now uses the new promise syntax for [`Navigator.getBattery()`](/en-US/docs/Web/API/Navigator/getBattery), as specified in the recent evolution of the specification ([Firefox bug 1050749](https://bugzil.la/1050749 "External link (opens in new tab)")).
*   The `User-Agent` header is no longer in the list of [forbidden request headers](/en-US/docs/Glossary/Forbidden_request_header) so it can now be set in a [Fetch](/en-US/docs/Web/API/Fetch_API) [`Headers`](/en-US/docs/Web/API/Headers) object, via XHR [`XMLHttpRequest.setRequestHeader()`](/en-US/docs/Web/API/XMLHttpRequest/setRequestHeader),… ([Firefox bug 1188932](https://bugzil.la/1188932 "External link (opens in new tab)")).
*   The [`MediaRecorder()`](/en-US/docs/Web/API/MediaRecorder/MediaRecorder "MediaRecorder()") constructor can now accept an options dictionary as a parameter, which allows you to set custom bitrates for the audio/video to be recorded ([Firefox bug 1161276](https://bugzil.la/1161276 "External link (opens in new tab)")).
*   The [`PerformanceObserver`](/en-US/docs/Web/API/PerformanceObserver) interface, belonging to the [Performance APIs](/en-US/docs/Web/API/Performance_API) has been implemented ([Firefox bug 1165796](https://bugzil.la/1165796 "External link (opens in new tab)")).
*   The Frame Timing API has been added: the `PerformanceRenderTiming` and `PerformanceCompositeTiming` interfaces are now available ([Firefox bug 1191178](https://bugzil.la/1191178 "External link (opens in new tab)")).
*   The modern [Screen Orientation API](/en-US/docs/Web/API/Screen_Orientation_API) has been implemented: unprefixed [`Screen.orientation`](/en-US/docs/Web/API/Screen/orientation) and the [`ScreenOrientation`](/en-US/docs/Web/API/ScreenOrientation) interface are now available ([Firefox bug 1131470](https://bugzil.la/1131470 "External link (opens in new tab)")). The non-standard `Screen.mozOrientation`, `Screen.onmozorientationchange`, `Screen.mozLockOrientation()`, and `Screen.mozUnlockOrientation()` will be removed in the future.
*   Under Linux, like under Windows, [`Event.timeStamp`](/en-US/docs/Web/API/Event/timeStamp) now returns a [`DOMHighResTimeStamp`](/en-US/docs/Web/API/DOMHighResTimeStamp) ([Firefox bug 1026803](https://bugzil.la/1026803 "External link (opens in new tab)")).
*   Experimental support for [`Selection`](/en-US/docs/Web/API/Selection) events [`selectionchange`](/en-US/docs/Web/API/Document/selectionchange_event "selectionchange") and [`selectstart`](/en-US/docs/Web/API/Node/selectstart_event "selectstart"), as well as the [`Document.onselectionchange`](/en-US/docs/Web/API/Document/selectionchange_event "Document.onselectionchange") and [`HTMLInputElement.onselectstart`](/en-US/docs/Web/API/Node/selectstart_event "HTMLInputElement.onselectstart") event handlers property has been added ([Firefox bug 571294](https://bugzil.la/571294 "External link (opens in new tab)")). The `selectionchange` event is fired on the [`Document`](/en-US/docs/Web/API/Document) if the associated `Selection` object is concerned, or on the specific [`HTMLInputElement`](/en-US/docs/Web/API/HTMLInputElement) or [`HTMLTextAreaElement`](/en-US/docs/Web/API/HTMLTextAreaElement) ([Firefox bug 1196479](https://bugzil.la/1196479 "External link (opens in new tab)")). This feature is controlled by the `dom.select_events.enabled` preference, which defaults to `false`, except on Nightly.
*   Support for [`MouseEvent.offsetX`](/en-US/docs/Web/API/MouseEvent/offsetX) and [`MouseEvent.offsetY`](/en-US/docs/Web/API/MouseEvent/offsetY) have been activated on Firefox for Android and Firefox OS ([Firefox bug 1204841](https://bugzil.la/1204841 "External link (opens in new tab)")).
*   The `HTMLCanvasElement.mozFetchAsStream()` method has been removed ([Firefox bug 1206030](https://bugzil.la/1206030 "External link (opens in new tab)")).
*   The constructor [`Request()`](/en-US/docs/Web/API/Request/Request "Request()") as well as [`fetch()`](/en-US/docs/Web/API/Window/fetch "fetch()") will now raise a [`TypeError`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypeError) exception when used with a URL containing a username and password ([Firefox bug 1195820](https://bugzil.la/1195820 "External link (opens in new tab)")).

## [Security](#security)

*   Access to Web Storage (i.e., `localStorage` and `sessionStorage`) from third-party IFrames is now denied if the user has [disabled third-party cookies](https://support.mozilla.org/en-US/kb/third-party-cookies-firefox-tracking-protection "External link (opens in new tab)") ([Firefox bug 536509](https://bugzil.la/536509 "External link (opens in new tab)")).
*   This whitelist has even been removed in Nightly and Aurora/Dev Edition of the browser ([Firefox bug 1201023](https://bugzil.la/1201023 "External link (opens in new tab)")). It is currently scheduled that this removal will also happen for Beta and Release versions for the next version (Firefox 44).
*   Subresource integrity has been implemented for [`<script>`](/en-US/docs/Web/HTML/Reference/Elements/script) and [`<link>`](/en-US/docs/Web/HTML/Reference/Elements/link) that links to stylesheets ([Firefox bug 992096](https://bugzil.la/992096 "External link (opens in new tab)")).
