# Firefox 24 release notes for developers

Firefox 24 was released on September 17, 2013. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   The Network inspector now lets you filter by content type (CSS/image/font etc.) and see the relevant size and load times.
*   The DevTools options panel to the left lets you disable/enable JavaScript temporarily.
*   Extension developers may use the new [Browser Console](https://mihai.sucan.ro/mihai/blog/the-browser-console-is-replacing-the-error-console/ "External link (opens in new tab)") for Chrome-level scripts (Replaces Error Console).
*   The source map syntax has been changed to use `//#` instead of `//@` ([Firefox bug 870361](https://bugzil.la/870361 "External link (opens in new tab)")).

### [CSS](#css)

*   The two values `-moz-zoom-in` and `-moz-zoom-out` of the [`cursor`](/en-US/docs/Web/CSS/Reference/Properties/cursor) property have been unprefixed to `zoom-in` and `zoom-out` ([Firefox bug 772153](https://bugzil.la/772153 "External link (opens in new tab)")).
*   To match the specification, the keywords `not`, `only`, `and`, and `or` cannot be used as media types anymore ([Firefox bug 757554](https://bugzil.la/757554 "External link (opens in new tab)")).

### [HTML](#html)

*   The [`<track>`](/en-US/docs/Web/HTML/Reference/Elements/track) element has been implemented behind the `media.webvtt.enabled` preference, and is disabled by default. ([Firefox bug 833385](https://bugzil.la/833385 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   [Arrow functions](/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions) are no longer automatically in strict mode unless explicitly requested with `"use strict"` ([Firefox bug 852762](https://bugzil.la/852762 "External link (opens in new tab)")).
*   The [`String.prototype.repeat`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/repeat) JS method has been implemented ([Firefox bug 815431](https://bugzil.la/815431 "External link (opens in new tab)")).
*   The [`Set.prototype.values()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/values), [`Set.prototype.keys()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/values) and [`Set.prototype.entries()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/entries) methods on [`Set`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set) objects have been implemented ([Firefox bug 869996](https://bugzil.la/869996 "External link (opens in new tab)")).

### [DOM](#dom)

*   Support for the [`Range()`](/en-US/docs/Web/API/Range/Range "Range()") constructor has been added ([Firefox bug 868999](https://bugzil.la/868999 "External link (opens in new tab)")).
*   Support for the [`Text()`](/en-US/docs/Web/API/Text/Text "Text()") constructor has been added ([Firefox bug 869000](https://bugzil.la/869000 "External link (opens in new tab)")).
*   Support for the [`Comment()`](/en-US/docs/Web/API/Comment/Comment "Comment()") constructor has been added ([Firefox bug 869006](https://bugzil.la/869006 "External link (opens in new tab)")).
*   Support for the [`DocumentFragment()`](/en-US/docs/Web/API/DocumentFragment/DocumentFragment "DocumentFragment()") constructor has been added ([Firefox bug 869002](https://bugzil.la/869002 "External link (opens in new tab)")).
*   The [`FocusEvent`](/en-US/docs/Web/API/FocusEvent) interface has been implemented ([Firefox bug 855741](https://bugzil.la/855741 "External link (opens in new tab)")).
*   Support for the [`ChildNode.remove()`](/en-US/docs/Web/API/Element/remove "ChildNode.remove()") method has been added ([Firefox bug 856629](https://bugzil.la/856629 "External link (opens in new tab)")).
*   The WebVTT interfaces related to the [`<track>`](/en-US/docs/Web/HTML/Reference/Elements/track) element, [`HTMLTrackElement`](/en-US/docs/Web/API/HTMLTrackElement), [`TextTrack`](/en-US/docs/Web/API/TextTrack), [`TextTrackCue`](/en-US/docs/Web/API/TextTrackCue), [`TextTrackList`](/en-US/docs/Web/API/TextTrackList), and [`TextTrackCueList`](/en-US/docs/Web/API/TextTrackCueList) have been implemented behind the `media.webvtt.enabled` property, defaulting to `false` ([Firefox bug 833385](https://bugzil.la/833385 "External link (opens in new tab)")).
*   The [`Gamepad`](/en-US/docs/Web/API/Gamepad) interface, and [`Navigator.getGamepads`](/en-US/docs/Web/API/Navigator/getGamepads) have been implemented behind the `dom.gamepad.enabled` property, defaulting to `false` ([Firefox bug 690935](https://bugzil.la/690935 "External link (opens in new tab)")).
*   On desktop Firefox only, `HTMLCanvasElement.getContext()` can now take the `webgl` value, in addition to `experimental-webgl` ([Firefox bug 870232](https://bugzil.la/870232 "External link (opens in new tab)")).
*   The non-standard method `mozLoadFrom()` of [`HTMLMediaElement`](/en-US/docs/Web/API/HTMLMediaElement) has been removed ([Firefox bug 877135](https://bugzil.la/877135 "External link (opens in new tab)")).

### [MathML](#mathml)

*   The `dir` attribute for controlling directionality of formulas on e.g., [`<math>`](/en-US/docs/Web/MathML/Reference/Element/math "<math>") or [`<mrow>`](/en-US/docs/Web/MathML/Reference/Element/mrow "<mrow>") elements is now equivalent to using the [`direction`](/en-US/docs/Web/CSS/Reference/Properties/direction) CSS property.
*   The equal sign ("=") is now [stretchable](/en-US/docs/Web/MathML/Reference/Element/mo#stretchy).
*   The `"updiagonalarrow"` value for the `notation` attribute on [`<menclose>`](/en-US/docs/Web/MathML/Reference/Element/menclose "<menclose>") elements has been added.

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

*   Doc Shells have now the `allowMedia` attribute to disable media playing ([Firefox bug 759964](https://bugzil.la/759964 "External link (opens in new tab)")).
*   Sherlock search plugins in the application directory or profile won't be loaded anymore ([Firefox bug 862143](https://bugzil.la/862143 "External link (opens in new tab)")).
