# Firefox 85 release notes for developers

This article provides information about the changes in Firefox 85 that will affect developers. Firefox 85 was released on January 26, 2021.

**Note:** See also [January brings us Firefox 85](https://hacks.mozilla.org/2021/01/january-brings-us-firefox-85/ "External link (opens in new tab)") on Mozilla Hacks.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   Developers can now use the [Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#viewing-common-pseudo-classes "External link (opens in new tab)") to toggle the [`:focus-visible`](/en-US/docs/Web/CSS/Reference/Selectors/:focus-visible) pseudo-class for the currently selected element (in addition to the pseudo classes that were previously supported: [`:hover`](/en-US/docs/Web/CSS/Reference/Selectors/:hover), [`:active`](/en-US/docs/Web/CSS/Reference/Selectors/:active) and [`:focus`](/en-US/docs/Web/CSS/Reference/Selectors/:focus), [`:focus-within`](/en-US/docs/Web/CSS/Reference/Selectors/:focus-within), and [`:visited`](/en-US/docs/Web/CSS/Reference/Selectors/:visited)). ([Firefox bug 1617608](https://bugzil.la/1617608 "External link (opens in new tab)")).

### [HTML](#html)

*   [`<link rel="preload">`](/en-US/docs/Web/HTML/Reference/Attributes/rel/preload) is now enabled. ([Firefox bug 1626997](https://bugzil.la/1626997 "External link (opens in new tab)")).

#### Removals

*   The `<menuitem>` HTML element is no longer available — it has been hidden behind the `dom.menuitem.enabled flag`. ([Firefox bug 1680596](https://bugzil.la/1680596 "External link (opens in new tab)")).

### [CSS](#css)

*   The [`:focus-visible`](/en-US/docs/Web/CSS/Reference/Selectors/:focus-visible) pseudo-class is now enabled. ([Firefox bug 1445482](https://bugzil.la/1445482 "External link (opens in new tab)")).
*   The `pinch-zoom` value for the [`touch-action`](/en-US/docs/Web/CSS/Reference/Properties/touch-action) property is now enabled. ([Firefox bug 1329241](https://bugzil.la/1329241 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The `collation` property can now be specified in the options passed to the [`Intl.Collator()` constructor](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Collator/Collator) ([Firefox bug 1670062](https://bugzil.la/1670062 "External link (opens in new tab)")). This allows developers to write code with greater clarity:
    
    js
    
    ```
    // Old method
    let pinyin = new Intl.Collator(["zh-u-co-pinyin"]);
    // New method
    let pinyin = new Intl.Collator("zh", { collation: "pinyin" });
    ```
    

### [Plugins](#plugins)

*   Flash support has been completely removed from Firefox ([Firefox bug 1675349](https://bugzil.la/1675349 "External link (opens in new tab)")).

### [APIs](#apis)

_No changes._

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Fixed a potential page load timeout situation when `WebDriver:ElementClick` is called for a link with a `target` other than `_blank` ([Firefox bug 1678455](https://bugzil.la/1678455 "External link (opens in new tab)")).
*   Using web element references on browsing contexts other than the originating one now correctly returns a `no such element` error instead of a `stale element reference` error ([Firefox bug 1684827](https://bugzil.la/1684827 "External link (opens in new tab)")).

#### Known bugs

*   WebDriver commands following a call to `WebDriver:SwitchToFrame` can fail with a "no such window" error if the frame's content hasn't yet finished loading ([Firefox bug 1691348](https://bugzil.la/1691348 "External link (opens in new tab)")).
*   After a [cross-group page navigation](https://firefox-source-docs.mozilla.org/dom/navigation/nav_replace.html#cross-group-navigations "External link (opens in new tab)"), accessing a previously-retrieved element might not always raise a "stale element" error, and can also lead to a "no such element" error. To prevent this, set the `marionette.actors.enabled` preference to `false` ([Firefox bug 1690308](https://bugzil.la/1690308 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

_No changes._
