# Firefox 83 release notes for developers

This article provides information about the changes in Firefox 83 that will affect developers. Firefox 83 was released on November 17, 2020.

**Note:** See also [Firefox 83 is upon us](https://hacks.mozilla.org/2020/11/firefox-83-is-upon-us/ "External link (opens in new tab)") on Mozilla hacks

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

*   When using the `:screenshot` [helper command](https://firefox-source-docs.mozilla.org/devtools-user/web_console/helpers/index.html "External link (opens in new tab)") in the [Web Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html "External link (opens in new tab)"), the `--dpr` parameter is no longer ignored when taking a fullscreen screenshot using `--fullpage` ([Firefox bug 1645284](https://bugzil.la/1645284 "External link (opens in new tab)")).
*   Developers can use the `scroll` badge in the [Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html "External link (opens in new tab)") to [Debug scrollable overflow](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/debug_scrollable_overflow/index.html "External link (opens in new tab)"). Selecting the badge highlights elements that are _causing_ overflow and marks them with the `overflow` badge ([Firefox bug 1669129](https://bugzil.la/1669129 "External link (opens in new tab)")).

### [HTML/XML](#htmlxml)

*   The `crossorigin` attribute is now supported for `<link rel=icon>` ([Firefox bug 1661075](https://bugzil.la/1661075 "External link (opens in new tab)")).
*   The `displaystyle` [attribute](/en-US/docs/Web/MathML/Reference/Attribute) is now implemented for all MathML elements ([Firefox bug 1666075](https://bugzil.la/1666075 "External link (opens in new tab)")).

### [CSS](#css)

*   The vendor prefixed `:-moz-any()` is now aliased to the standard [`:is()`](/en-US/docs/Web/CSS/Reference/Selectors/:is) CSS pseudo-class function ([Firefox bug 1666086](https://bugzil.la/1666086 "External link (opens in new tab)")).
*   We've added support for [CSS Conic Gradients](/en-US/docs/Web/CSS/Reference/Values/gradient/conic-gradient) ([Firefox bug 1632351](https://bugzil.la/1632351 "External link (opens in new tab)")) and ([Firefox bug 1175958](https://bugzil.la/1175958 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   [`Intl[@@toStringTag]`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol/toStringTag) has been added, returning a default value of `Intl` (recent addition to the ECMA spec). ([Firefox bug 1670053](https://bugzil.la/1670053 "External link (opens in new tab)"))

### [HTTP](#http)

_No changes._

### [APIs](#apis)

_No changes._

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   We've removed preliminary support for `WebDriver:SwitchToShadowRoot`, which hasn't been added to the WebDriver specification yet ([Firefox bug 1662468](https://bugzil.la/1662468 "External link (opens in new tab)")).
*   We fixed a bug in `WebDriver:Back` and `WebDriver:Forward` that caused Marionette to hang when the navigation was triggered from within an [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) that gets removed ([Firefox bug 1672758](https://bugzil.la/1672758 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

_No changes._
