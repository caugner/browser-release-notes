# Firefox 32 release notes for developers

Firefox 32 was released on September 2, 2014. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

Highlights:

*   [Web Audio Editor](https://firefox-source-docs.mozilla.org/devtools-user/web_audio_editor/index.html "External link (opens in new tab)")
*   _Code completion and inline documentation in Scratchpad\]_
*   [User agent styles in the Inspector's Rules view](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html#rules-view "External link (opens in new tab)")
*   [Element picker button has moved](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html#firefox-32-onwards-2 "External link (opens in new tab)")
*   [Node dimensions added to the Inspector's infobar](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html#firefox-32-onwards "External link (opens in new tab)")
*   [Full page screenshot button added](https://firefox-source-docs.mozilla.org/devtools-user/tools_toolbox/index.html#extra-tools "External link (opens in new tab)")
*   HiDPI images added to the tools
*   Nodes that have `display:none` are shown differently in the Inspector

[All devtools bugs fixed between Firefox 31 and Firefox 32](https://bugzilla.mozilla.org/buglist.cgi?resolution=FIXED&classification=Client%20Software&chfieldto=2014-06-09&chfield=resolution&query_format=advanced&chfieldfrom=2014-04-28&chfieldvalue=FIXED&bug_status=RESOLVED&bug_status=VERIFIED&component=Developer%20Tools&component=Developer%20Tools%3A%203D%20View&component=Developer%20Tools%3A%20App%20Manager&component=Developer%20Tools%3A%20Canvas%20Debugger&component=Developer%20Tools%3A%20Console&component=Developer%20Tools%3A%20Debugger&component=Developer%20Tools%3A%20Framework&component=Developer%20Tools%3A%20Graphic%20Commandline%20and%20Toolbar&component=Developer%20Tools%3A%20Inspector&component=Developer%20Tools%3A%20Memory&component=Developer%20Tools%3A%20Netmonitor&component=Developer%20Tools%3A%20Object%20Inspector&component=Developer%20Tools%3A%20Profiler&component=Developer%20Tools%3A%20Responsive%20Mode&component=Developer%20Tools%3A%20Scratchpad&component=Developer%20Tools%3A%20Source%20Editor&component=Developer%20Tools%3A%20Style%20Editor&component=Developer%20Tools%3A%20User%20Stories&component=Developer%20Tools%3A%20WebGL%20Shader%20Editor&product=Firefox "External link (opens in new tab)").

### [CSS](#css)

*   Enabled [`mix-blend-mode`](/en-US/docs/Web/CSS/Reference/Properties/mix-blend-mode) by default ([Firefox bug 952643](https://bugzil.la/952643 "External link (opens in new tab)")).
*   Enabled `position:sticky` by default in release builds (only enabled on Nightly and Aurora before) ([Firefox bug 916315](https://bugzil.la/916315 "External link (opens in new tab)")).
*   Implemented [`box-decoration-break`](/en-US/docs/Web/CSS/Reference/Properties/box-decoration-break) and removed the non-standard `-moz-background-inline-policy` ([Firefox bug 613659](https://bugzil.la/613659 "External link (opens in new tab)")).
*   Allowed [`flex-grow`](/en-US/docs/Web/CSS/Reference/Properties/flex-grow) and [`flex-shrink`](/en-US/docs/Web/CSS/Reference/Properties/flex-shrink) to transition between zero and nonzero values, like 'flex-grow: 0.6'([Firefox bug 996945](https://bugzil.la/996945 "External link (opens in new tab)")).

### [HTML](#html)

*   Experimentally implemented, behind a pref, [`<img>`](/en-US/docs/Web/HTML/Reference/Elements/img) [`srcset`](/en-US/docs/Web/HTML/Reference/Elements/img#srcset) property, To activate it set `dom.image.srcset.enable` to `true` ([Firefox bug 870021](https://bugzil.la/870021 "External link (opens in new tab)")).
*   [**id**](/en-US/docs/Web/HTML/Reference/Global_attributes/id) and [**class**](/en-US/docs/Web/HTML/Reference/Global_attributes/class) are now true [global attributes](/en-US/docs/Web/HTML/Reference/Global_attributes) and also apply to XML elements, in a namespace or not ([Firefox bug 741295](https://bugzil.la/741295 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The following new ECMAScript 2015 built-in methods got implemented:
    *   [`Array.from()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/from) ([Firefox bug 904723](https://bugzil.la/904723 "External link (opens in new tab)")),
    *   [`Array.prototype.copyWithin()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/copyWithin) ([Firefox bug 934423](https://bugzil.la/934423 "External link (opens in new tab)")),
    *   [`Number.isSafeInteger()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/isSafeInteger) ([Firefox bug 1003764](https://bugzil.la/1003764 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   The [`Navigator.languages`](/en-US/docs/Web/API/Navigator/languages) property and [`languagechange`](/en-US/docs/Web/API/Window/languagechange_event "languagechange") event have been implemented ([Firefox bug 889335](https://bugzil.la/889335 "External link (opens in new tab)")).
*   The [`Navigator.vibrate()`](/en-US/docs/Web/API/Navigator/vibrate) method behavior has been adapted to the latest specification: too long vibrations are now truncated ([Firefox bug 1014581](https://bugzil.la/1014581 "External link (opens in new tab)")).
*   The [`KeyboardEvent.getModifierState()`](/en-US/docs/Web/API/KeyboardEvent/getModifierState) and [`MouseEvent.getModifierState()`](/en-US/docs/Web/API/MouseEvent/getModifierState) methods have been extended to support the `Accel` virtual modifier ([Firefox bug 1009388](https://bugzil.la/1009388 "External link (opens in new tab)")).
*   The [`KeyboardEvent.code`](/en-US/docs/Web/API/KeyboardEvent/code) property have been experimentally implemented: it is disabled on release build ([Firefox bug 865649](https://bugzil.la/865649 "External link (opens in new tab)")).
*   Scoped selectors for [`Document.querySelector()`](/en-US/docs/Web/API/Document/querySelector) and [`Document.querySelectorAll()`](/en-US/docs/Web/API/Document/querySelectorAll), for example `querySelector(":scope > li")` have been implemented ([Firefox bug 528456](https://bugzil.la/528456 "External link (opens in new tab)")).
*   The experimental implementation of the [`Document.timeline`](/en-US/docs/Web/API/Document/timeline) interface, related to the [Web Animations API](/en-US/docs/Web/API/Web_Animations_API), has been added ([Firefox bug 998246](https://bugzil.la/998246 "External link (opens in new tab)")). It is controlled by `layout.web-animations.api.enabled` preference, enabled only on Nightly and Aurora for the moment.
*   The [Data Store API](https://web.archive.org/web/20210613234447/https://developer.mozilla.org/en-US/docs/Archive/B2G_OS/API/Data_Store_API "External link (opens in new tab)") has been made available to [Web Workers](/en-US/docs/Web/API/Web_Workers_API/Using_web_workers) ([Firefox bug 949325](https://bugzil.la/949325 "External link (opens in new tab)")). It still is only activated for certified applications.
*   The [ServiceWorker](/en-US/docs/Web/API/Service_Worker_API) `InstallPhaseEvent` and [`InstallEvent`](/en-US/docs/Web/API/InstallEvent) interfaces have been implemented ([Firefox bug 967264](https://bugzil.la/967264 "External link (opens in new tab)")).
*   The MSISDN Verification API, only activated for privileged apps, has been added ([Firefox bug 988469](https://bugzil.la/988469 "External link (opens in new tab)")).
*   The [Gamepad API](/en-US/docs/Web/API/Gamepad_API) is now supported on Firefox for Android ([Firefox bug 852935](https://bugzil.la/852935 "External link (opens in new tab)")).
*   To match the spec and the evolution of the CSS syntax, minor changes have been done to [`CSS.escape()`](/en-US/docs/Web/API/CSS/escape_static "CSS.escape()"). The identifier now can begins with `'--'` and the second dash must not be escaped. Also vendor identifier are no more escaped. ([Firefox bug 1008719](https://bugzil.la/1008719 "External link (opens in new tab)"))
*   To complete our Hit Regions implementation, `MouseEvent.region` has been implemented ([Firefox bug 979692](https://bugzil.la/979692 "External link (opens in new tab)")).
*   The [`CanvasRenderingContext2D.drawFocusIfNeeded()`](/en-US/docs/Web/API/CanvasRenderingContext2D/drawFocusIfNeeded) method is now enabled by default ([Firefox bug 1004579](https://bugzil.la/1004579 "External link (opens in new tab)")).
*   The [`Navigator.doNotTrack`](/en-US/docs/Web/API/Navigator/doNotTrack) property now returns `'1'` or `'0'`, reflecting the HTTP value, instead of `'yes'` or `'no'` ([Firefox bug 887703](https://bugzil.la/887703 "External link (opens in new tab)")).
*   [XMLHttpRequest.responseURL](/en-US/docs/Web/API/XMLHttpRequest/responseURL) was implemented ([Firefox bug 998076](https://bugzil.la/998076 "External link (opens in new tab)")).

### [MathML](#mathml)

*   Add support for the [`<menclose>`](/en-US/docs/Web/MathML/Reference/Element/menclose "<menclose>") notation `phasorangle`.

### [SVG](#svg)

_No change._

### [WebRTC](#webrtc)

*   New constraints for [WebRTC](/en-US/docs/Glossary/WebRTC)'s [`getUserMedia()`](/en-US/docs/Web/API/Navigator/getUserMedia "getUserMedia()"), `width`, `height`, and `framerate`, have been added, to limit stream dimensions and frame rate ([Firefox bug 907352](https://bugzil.la/907352 "External link (opens in new tab)")):
    
    js
    
    ```
    const constraints = {
      mandatory: {
        width: { min: 640 },
        height: { min: 480 },
      },
      optional: [
        { width: 650 },
        { width: { min: 650 } },
        { frameRate: 60 },
        { width: { max: 800 } },
      ],
    };
    ```
    
*   WebRTC methods which previously used callback functions as input parameters are now also available using JavaScript [promises](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise).
    

### [Audio/Video](#audiovideo)

_No change._

## [Security](#security)

*   [Privileged code now gets Xray vision for JavaScript `Object` and `Array` instances](https://firefox-source-docs.mozilla.org/dom/scriptSecurity/xray_vision.html#xray-semantics-for-object-and-array "External link (opens in new tab)").

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

Xray vision is now applied to JavaScript objects that are not themselves DOM objects: [Xrays for JavaScript objects](https://firefox-source-docs.mozilla.org/dom/scriptSecurity/xray_vision.html#xrays-for-javascript-objects "External link (opens in new tab)").

A `getDataDirectory()` method has been added to `Addon` instances. This method returns the preferred location, within the current profile, for add-ons to store data.

### [Add-on SDK](#add-on_sdk)

#### Highlights

*   Added [`exclude`](https://web.archive.org/web/20210216122834/https://developer.mozilla.org/en-US/docs/Archive/Add-ons/Add-on_SDK/High-Level_APIs/page-mod#pagemod%28options%29 "External link (opens in new tab)") option to `PageMod`.
*   Added [`anonymous`](https://web.archive.org/web/20201201022954/https://developer.mozilla.org/en-US/docs/Archive/Add-ons/Add-on_SDK/High-Level_APIs/request#request%28options%29 "External link (opens in new tab)") option to `Request`.
*   [Add-on Debugger](https://extensionworkshop.com/documentation/develop/debugging/ "External link (opens in new tab)") now includes a Console and a Scratchpad.

#### Details

[GitHub commits made between Firefox 31 and Firefox 32](https://github.com/mozilla/addon-sdk/compare/firefox31...firefox32 "External link (opens in new tab)"). This will not include any uplifts made after this release entered Aurora.

[Bugs fixed between Firefox 31 and Firefox 32](https://bugzilla.mozilla.org/buglist.cgi?resolution=FIXED&chfieldto=2014-06-09&chfield=resolution&query_format=advanced&chfieldfrom=2014-04-28&chfieldvalue=FIXED&bug_status=RESOLVED&bug_status=VERIFIED&bug_status=CLOSED&product=Add-on%20SDK&list_id=10493962 "External link (opens in new tab)"). This will not include any uplifts made after this release entered Aurora.

### [XPCOM](#xpcom)

*   The `nsIUDPSocket` interface now provides multicast support through the addition of the new `nsIUDPSocket.multicastLoopback`, `nsIUDPSocket.multicastInterface`, and `nsIUDPSocket.multicastInterfaceAddr` attributes, as well as the `nsIUDPSocket.joinMulticast()` and `nsIUDPSocket.leaveMulticast()` methods.
