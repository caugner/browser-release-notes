# Firefox 137 release notes for developers

This article provides information about the changes in Firefox 137 that affect developers. Firefox 137 was released on [April 1, 2025](https://whattrainisitnow.com/release/?version=137 "External link (opens in new tab)").

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

No notable changes

### [CSS](#css)

*   The [`hyphenate-limit-chars`](/en-US/docs/Web/CSS/Reference/Properties/hyphenate-limit-chars) CSS property provides you with fine-grained control over hyphenation in text. It is used to specify the minimum word length for hyphenation as well as the number of characters before and after the hyphen. ([Firefox bug 1947183](https://bugzil.la/1947183 "External link (opens in new tab)")).
*   The [`text-decoration-line`](/en-US/docs/Web/CSS/Reference/Properties/text-decoration-line) CSS property now accepts the values `spelling-error` and `grammar-error`. These values use the browser's styling for spelling and grammar errors and disregard the other properties in the [`text-decoration`](/en-US/docs/Web/CSS/Reference/Properties/text-decoration) shorthand. ([Firefox bug 1950844](https://bugzil.la/1950844 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The [`Math.sumPrecise()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/sumPrecise) static method is now supported. This takes an [iterable](/en-US/docs/Web/JavaScript/Reference/Iteration_protocols#the_iterable_protocol) (such as an [`Array`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)) of numbers and returns their sum. It is more precise than summing the numbers in a loop because it avoids floating point precision loss in intermediate results. ([Firefox bug 1943120](https://bugzil.la/1943120 "External link (opens in new tab)")).
*   The [`Atomics.pause()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Atomics/pause) static method is now supported. This method provides a hint to the CPU that the current thread is in a spinlock while waiting on access to a shared resource. The system can then reduce the resources allocated to the core (such as power) or thread, without yielding the current thread. ([Firefox bug 1937805](https://bugzil.la/1937805 "External link (opens in new tab)")).

### [APIs](#apis)

*   The [`getPathData()`](/en-US/docs/Web/API/SVGPathElement/getPathData "getPathData()"), [`setPathData()`](/en-US/docs/Web/API/SVGPathElement/setPathData "setPathData()"), and [`getPathSegmentAtLength()`](/en-US/docs/Web/API/SVGPathElement/getPathSegmentAtLength "getPathSegmentAtLength()") methods of the [`SVGPathElement`](/en-US/docs/Web/API/SVGPathElement) interface are now supported. These methods provide a convenient way to work with SVG path data instead of parsing raw string data. ([Firefox bug 1945312](https://bugzil.la/1945312 "External link (opens in new tab)")).

#### Media, WebRTC, and Web Audio

*   [HEVC (H.265)](/en-US/docs/Web/Media/Guides/Formats/Video_codecs#hevc_h.265) is now hardware enabled on Android, and hardware and software enabled on Linux. This adds to existing hardware and software support on Windows and macOS. ([Firefox bug 1950032](https://bugzil.la/1950032 "External link (opens in new tab)")).

#### Removals

*   The following non-standard events are now deprecated and proposed for removal: [`afterscriptexecute`](/en-US/docs/Web/API/Document/afterscriptexecute_event) and [`beforescriptexecute`](/en-US/docs/Web/API/Document/beforescriptexecute_event) in [`Document`](/en-US/docs/Web/API/Document), and [`afterscriptexecute`](/en-US/docs/Web/API/Element/afterscriptexecute_event), and [`beforescriptexecute`](/en-US/docs/Web/API/Element/beforescriptexecute_event) in [`Element`](/en-US/docs/Web/API/Element). A console warning is displayed when they are used. ([Firefox bug 1949373](https://bugzil.la/1949373 "External link (opens in new tab)")).

### [WebDriver conformance (WebDriver BiDi, Marionette)](#webdriver_conformance_webdriver_bidi_marionette)

#### General

*   Input sources of type `mouse` and `touch` now support fractional numbers for x and y positions for the `pointerMove` action ([Firefox bug 1946774](https://bugzil.la/1946774 "External link (opens in new tab)")).

#### WebDriver BiDi

*   Implemented new `webExtension.install` ([Firefox bug 1934551](https://bugzil.la/1934551 "External link (opens in new tab)")) and `webExtension.uninstall` ([Firefox bug 1934553](https://bugzil.la/1934553 "External link (opens in new tab)")) commands, enabling clients to install and uninstall web extensions in the browser.
*   Added support for `userContexts` argument to `sessions.subscribe` command, which allows clients subscribing to a list of user contexts (also known as Firefox containers) ([Firefox bug 1938604](https://bugzil.la/1938604 "External link (opens in new tab)")).
*   `script.addPreloadScript` command is updated to throw an `invalid argument` error when both `contexts` and `userContexts` arguments are provided ([Firefox bug 1945554](https://bugzil.la/1945554 "External link (opens in new tab)")).
*   `browsingContext.navigate` command will not return immediately anymore when `wait` argument equals `none` and beforeunload prompt opens. That's the first step of updating the logic behind `wait` argument equals `none` ([Firefox bug 1948700](https://bugzil.la/1948700 "External link (opens in new tab)")).

#### Marionette

*   From now on, a `javascript error` from a syntax error raised by script evaluation will contain line and column number ([Firefox bug 1865146](https://bugzil.la/1865146 "External link (opens in new tab)")).
*   Performing actions with async events enabled will not fail anymore with a `Cyclic object value` error message ([Firefox bug 1947112](https://bugzil.la/1947112 "External link (opens in new tab)")). Async events were enabled since Firefox 135. See more details in [the release notes](/en-US/docs/Mozilla/Firefox/Releases/135#webdriver_conformance_webdriver_bidi_marionette).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   Adds [`commands.openShortcutSettings`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/commands/openShortcutSettings) that opens the Manage Extension Shortcuts page of Manage Your Extensions (`about:addons`) and, if the extension has shortcuts, scrolls to and highlights the extension's shortcut key options. ([Firefox bug 1538451](https://bugzil.la/1538451 "External link (opens in new tab)"))
*   The 10 MB quota for data stored by the [`storage.session`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/storage/session) API is now enforced. ([Firefox bug 1915688](https://bugzil.la/1915688 "External link (opens in new tab)"))

## [Experimental web features](#experimental_web_features)

These features are newly shipped in Firefox 137 but are disabled by default. To experiment with them, search for the appropriate preference on the `about:config` page and set it to `true`. You can find more such features on the [Experimental features](/en-US/docs/Mozilla/Firefox/Experimental_features) page.

*   **Temporal API** (Nightly release): is now enabled in Firefox Nightly by default. The [Temporal object](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal) aims to simplify working with dates and times in various scenarios, with built-in time zone and calendar representations. ([Firefox bug 1946823](https://bugzil.la/1946823 "External link (opens in new tab)")).
