# Firefox 92 release notes for developers

This article provides information about the changes in Firefox 92 that will affect developers. Firefox 92 was released on September 7, 2021.

**Note:** See also [Time for a review of Firefox 92](https://hacks.mozilla.org/2021/09/time-for-a-review-of-firefox-92/ "External link (opens in new tab)") on Mozilla Hacks.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

No changes

### [CSS](#css)

*   The keywords `avoid-page` and `avoid-column` are now supported for the [`break-inside`](/en-US/docs/Web/CSS/Reference/Properties/break-inside) property ([Firefox bug 1722945](https://bugzil.la/1722945 "External link (opens in new tab)")).
*   The two-value syntax for the [`font-size-adjust`](/en-US/docs/Web/CSS/Reference/Properties/font-size-adjust) property is now supported ([Firefox bug 1720131](https://bugzil.la/1720131 "External link (opens in new tab)")).
*   The [`size-adjust`](/en-US/docs/Web/CSS/Reference/At-rules/@font-face/size-adjust) descriptor is now supported ([Firefox bug 1720131](https://bugzil.la/1720131 "External link (opens in new tab)")).
*   The CSS [`accent-color`](/en-US/docs/Web/CSS/Reference/Properties/accent-color) property has been implemented ([Firefox bug 1722031](https://bugzil.la/1722031 "External link (opens in new tab)")).
*   The `system-ui` value is now supported for the [`font-family`](/en-US/docs/Web/CSS/Reference/Properties/font-family) property ([Firefox bug 1226042](https://bugzil.la/1226042 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   [`Object.hasOwn()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/hasOwn) can be used to test whether a property was defined on an object or inherited ([Firefox bug 1721149](https://bugzil.la/1721149 "External link (opens in new tab)")).
*   The default 5MB storage quota is now available to each origin. The quota previously applied to an entire domain group (also known as [registrable domain](/en-US/docs/Glossary/Registrable_domain); e.g., `*.wikipedia.org`). ([Firefox bug 1064466](https://bugzil.la/1064466 "External link (opens in new tab)")).
*   Storage quotas for [`Window.localStorage`](/en-US/docs/Web/API/Window/localStorage) are now shared with [IndexedDB API](/en-US/docs/Web/API/IndexedDB_API) and [`Cache`](/en-US/docs/Web/API/Cache) ([Firefox bug 742822](https://bugzil.la/742822 "External link (opens in new tab)")).

### [HTTP](#http)

*   Firefox will automatically upgrade an HTTP request to HTTPS when a usable [HTTPS RR](/en-US/docs/Glossary/HTTPS_RR) is available. It will also use information provided in an _HTTPS RR_ to optimize the process of establishing HTTPS connections⁠—this is conceptually similar to using the [`Alt-Svc`](/en-US/docs/Web/HTTP/Reference/Headers/Alt-Svc) header. ([Firefox bug 1721132](https://bugzil.la/1721132 "External link (opens in new tab)")).

### [APIs](#apis)

*   The `disabledFeatures` static property has been implemented for Custom Elements ([Firefox bug 1723396](https://bugzil.la/1723396 "External link (opens in new tab)")).

#### DOM

*   The [Imperative Slotting API](/en-US/docs/Web/API/HTMLSlotElement) (part of the [Shadow DOM API](/en-US/docs/Web/API/Web_components/Using_shadow_DOM)) Has been implemented. ([Firefox bug 1705141](https://bugzil.la/1705141 "External link (opens in new tab)"))
*   You can now monitor for changes to text selections in [`<input>`](/en-US/docs/Web/HTML/Reference/Elements/input) or [`<textarea>`](/en-US/docs/Web/HTML/Reference/Elements/textarea) by listening for `selectionchange` events in [`HTMLInputElement`](/en-US/docs/Web/API/HTMLInputElement/selectionchange_event "HTMLInputElement") and [`HTMLTextAreaElement`](/en-US/docs/Web/API/HTMLTextAreaElement/selectionchange_event "HTMLTextAreaElement"), respectively ([Firefox bug 1648944](https://bugzil.la/1648944 "External link (opens in new tab)")).

#### Media, WebRTC, and Web Audio

*   Access to audio output devices, like speakers and headphones, is now protected by the [speaker-selection](/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/speaker-selection) feature policy ([Firefox bug 1577199](https://bugzil.la/1577199 "External link (opens in new tab)")).

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Improved support for the `webSocketUrl` capability, which now returns the WebDriver BiDi websocket URL if `true` was passed and if BiDi is supported. ([Firefox bug 1692984](https://bugzil.la/1692984 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   Support for `cookieStoreId` is added to [`downloads.download`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/download), [`downloads.DownloadQuery`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadQuery), and [`downloads.DownloadItem`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadItem). The addition to the types [`downloads.DownloadQuery`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadQuery) and [`downloads.DownloadItem`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadItem) provides support in [`downloads.search`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/search) and [`downloads.erase`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/erase). Web extensions can now associate downloads with specific cookie stores, such as container tabs ([contextual identities](/en-US/docs/Mozilla/Add-ons/WebExtensions/Work_with_contextual_identities)). ([Firefox bug 1669566](https://bugzil.la/1669566 "External link (opens in new tab)"))
