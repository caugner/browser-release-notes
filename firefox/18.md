# Firefox 18 release notes for developers

Firefox 18 was released on January 8, 2013. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

*   The [`reversed`](/en-US/docs/Web/HTML/Reference/Elements/ol#reversed) attribute of the [`<ol>`](/en-US/docs/Web/HTML/Reference/Elements/ol) element is now supported ([Firefox bug 601912](https://bugzil.la/601912 "External link (opens in new tab)")).
*   The [`crossorigin`](/en-US/docs/Web/HTML/Reference/Elements/link#crossorigin) attribute of the [`<link>`](/en-US/docs/Web/HTML/Reference/Elements/link) element is now supported ([Firefox bug 786564](https://bugzil.la/786564 "External link (opens in new tab)")).
*   The [`allowfullscreen`](/en-US/docs/Web/HTML/Reference/Elements/iframe#allowfullscreen) attribute of the [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) has been implemented and its prefixed predecessor `mozallowfullscreen` is now deprecated.

### [CSS](#css)

*   The [`min-width`](/en-US/docs/Web/CSS/Reference/Properties/min-width) and [`min-height`](/en-US/docs/Web/CSS/Reference/Properties/min-height) now uses the `auto` keyword as _initial value_ (This has an effect only on flex items as it resolves to `0`, the previous initial value, for other items). ([Firefox bug 763689](https://bugzil.la/763689 "External link (opens in new tab)"))
*   The cascade has been updated: now author `!important` rules override [CSS animations](/en-US/docs/Web/CSS/Guides/Animations/Using). ([Firefox bug 783714](https://bugzil.la/783714 "External link (opens in new tab)"))
*   The [`background`](/en-US/docs/Web/CSS/Reference/Properties/background) shorthand property now recognizes CSS3 [`background-size`](/en-US/docs/Web/CSS/Reference/Properties/background-size) property specified inside. ([Firefox bug 570326](https://bugzil.la/570326 "External link (opens in new tab)"))
*   Initial support for the CSS Flexbox Module has been landed. It is disabled by default but can be enabled by setting `layout.css.flexbox.enabled` to true ([Firefox bug 666041](https://bugzil.la/666041 "External link (opens in new tab)")).

### [DOM/APIs](#domapis)

*   `navigator.mozPay` has been landed. ([Firefox bug 767818](https://bugzil.la/767818 "External link (opens in new tab)"))
*   `window.devicePixelRatio` has been landed. ([Firefox bug 564815](https://bugzil.la/564815 "External link (opens in new tab)"))
*   The OS X backend for `window.navigator.battery` has been implemented. ([Firefox bug 696045](https://bugzil.la/696045 "External link (opens in new tab)"))
*   `MozBlobBuilder` is removed. Developers need to use [`Blob`](/en-US/docs/Web/API/Blob) constructor for creating a `Blob` object. ([Firefox bug 744907](https://bugzil.la/744907 "External link (opens in new tab)"))
*   The [`visibilitychange`](/en-US/docs/Web/API/Document/visibilitychange_event "visibilitychange") event and the [Page Visibility API](/en-US/docs/Web/API/Page_Visibility_API) has been unprefixed ([Firefox bug 812086](https://bugzil.la/812086 "External link (opens in new tab)")).
*   [`TextDecoder`](/en-US/docs/Web/API/TextDecoder) and [`TextEncoder`](/en-US/docs/Web/API/TextEncoder) have been added. Note that the implementation and spec of these evolved and have been changed in Firefox 19 ([Firefox bug 764234](https://bugzil.la/764234 "External link (opens in new tab)")).
*   `HTMLMediaElement.src` has been separate in two properties: the standard `src` property, dealing with strings, and the prefixed `mozSrcObject` property, dealing with [media streams](/en-US/docs/Web/API/Media_Capture_and_Streams_API) ([Firefox bug 792665](https://bugzil.la/792665 "External link (opens in new tab)")).
*   Support for [transferable objects](/en-US/docs/Web/API/Web_Workers_API/Transferable_objects) has been added.
*   The [`Screen.lockOrientation()`](/en-US/docs/Web/API/Screen/lockOrientation) method now supports an `Array` of strings as argument ([Firefox bug 784549](https://bugzil.la/784549 "External link (opens in new tab)").

### [JavaScript](#javascript)

*   Harmony's (ECMAScript 2015) [Direct Proxies](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy) have been landed ([Firefox bug 703537](https://bugzil.la/703537 "External link (opens in new tab)")). Warning: the implementation contains a couple of known bugs, missing features and misalignments with the current state of the spec. Do not rely on it for production code.
*   The ECMAScript 2015 `contains()` method is now implemented on strings. This is unfortunately not compatible with Mootools 1.2, which expects different behavior from `contains()` on strings but does not ensure it. Newer versions of Mootools fix this issue; sites should upgrade their Mootools version to something newer than 1.2.

### [WebGL](#webgl)

*   The prefixed version of the [`EXT_texture_filter_anisotropic`](/en-US/docs/Web/API/EXT_texture_filter_anisotropic) WebGL extension, "MOZ\_EXT\_texture\_filter\_anisotropic" has been removed ([Firefox bug 790946](https://bugzil.la/790946 "External link (opens in new tab)")).

### [Network](#network)

*   Quality factors ("q-values") are now clamped to 2 digits (e.g., in HTTP [`Accept-Language`](/en-US/docs/Web/HTTP/Reference/Headers/Accept-Language) headers) ([Firefox bug 672448](https://bugzil.la/672448 "External link (opens in new tab)")).
*   The `ALLOW-FROM` syntax of the [`X-FRAME-OPTIONS`](/en-US/docs/Web/HTTP/Reference/Headers/X-Frame-Options) HTTP Response header is now supported ([Firefox bug 690168](https://bugzil.la/690168 "External link (opens in new tab)")).

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

### [Interface changes](#interface_changes)

[`nsIStreamListener`](#nsistreamlistener)

The 4th parameter (`aOffset`) of `onDataAvailable()` method changes to `unsigned long long`. ([Firefox bug 784912](https://bugzil.la/784912 "External link (opens in new tab)"))

[`nsIUploadChannel`](#nsiuploadchannel)

`setUploadStream()` supports over 2GB content-length ([Firefox bug 790617](https://bugzil.la/790617 "External link (opens in new tab)"))

[`nsIEditor`](#nsieditor)

`addEditorObserver()` has been removed, use `setEditorObserver()` instead, `removeEditorObserver()` no longer takes a `nsIEditorObserver` parameter ([Firefox bug 785091](https://bugzil.la/785091 "External link (opens in new tab)"))

[`nsIHttpProtocolHandler`](#nsihttpprotocolhandler)

`http-on-modify-request` observers are no longer guaranteed to be called synchronously during `nsIChannel.asyncOpen()`. For observers that need to be called during `asyncOpen()`, the new `http-on-opening-request` observer topic has been added. See ([Firefox bug 800799](https://bugzil.la/800799 "External link (opens in new tab)"))

[`nsIProtocolProxyService`](#nsiprotocolproxyservice)

The `resolve` method has been removed. Now, only the `asyncResolve` method can be used. See ([Firefox bug 769764](https://bugzil.la/769764 "External link (opens in new tab)"))
