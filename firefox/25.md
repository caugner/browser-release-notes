# Firefox 25 release notes for developers

## [Changes for web developers](#changes_for_web_developers)

### [New in Firefox DevTools](#new_in_firefox_devtools)

*   The inspector now features autocompletion for CSS names and values.
*   The debugger now lets you "black box" script files, to prevent breakpoints from stopping in library code you're not interested in debugging.
*   The Profiler can now save and import profiling results. "Show Gecko Platform Data" is now an option in the Firefox DevTools options.
*   The Network panel has a right-click context menu, with copy and resend URL commands.
*   Numerous under-the-hood changes may make some rewriting necessary for add-ons that modify the DevTools.

### [CSS](#css)

*   The support for the keyword `local` as a value of the [`background-attachment`](/en-US/docs/Web/CSS/Reference/Properties/background-attachment) CSS property has been added ([Firefox bug 483446](https://bugzil.la/483446 "External link (opens in new tab)")).
*   Support for a non-standard Mozilla-only media query to determine the operating system version has been added: `-moz-os-version` ([Firefox bug 810399](https://bugzil.la/810399 "External link (opens in new tab)")). The property is currently only implemented on Windows.
*   The `-moz-osx-font-smoothing` CSS property has been added ([Firefox bug 857142](https://bugzil.la/857142 "External link (opens in new tab)")).
*   Our experimental support for [`filter`](/en-US/docs/Web/CSS/Reference/Properties/filter) now supports the `hue-rotate()` functional notation ([Firefox bug 897392](https://bugzil.la/897392 "External link (opens in new tab)")). It is still disabled by default.
*   `page-break-inside`: `avoid` is now working with the height of a block ([Firefox bug 883676](https://bugzil.la/883676 "External link (opens in new tab)")).

### [HTML](#html)

*   The [`srcdoc`](/en-US/docs/Web/HTML/Reference/Elements/iframe#srcdoc) attribute of [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe), allowing the inline specification of the content of an [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe), is now supported ([Firefox bug 802895](https://bugzil.la/802895 "External link (opens in new tab)")).
*   When used with a `"image/jpeg"` type, the method `HTMLCanvasElement.toBlob` now accepts a third attribute defining the quality of the image ([Firefox bug 891884](https://bugzil.la/891884 "External link (opens in new tab)")).

### [JavaScript](#javascript)

ECMAScript 2015 implementation continues!

*   The method [`Array.of()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/of) is now implemented on [`Array`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) ([Firefox bug 866849](https://bugzil.la/866849 "External link (opens in new tab)")).
*   Support for the methods [`Array.prototype.find()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/find) and [`Array.prototype.findIndex()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/findIndex) has been added ([Firefox bug 885553](https://bugzil.la/885553 "External link (opens in new tab)")).
*   The methods [`Number.parseInt()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/parseInt) and [`Number.parseFloat()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/parseFloat) have been implemented ([Firefox bug 886949](https://bugzil.la/886949 "External link (opens in new tab)")).
*   The methods [`Map.prototype.forEach()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/forEach) and [`Set.prototype.forEach()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/forEach) are now implemented ([Firefox bug 866847](https://bugzil.la/866847 "External link (opens in new tab)")).
*   New mathematical methods have been implemented on [`Math`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math): `Math.log10()`, `Math.log2()`, `Math.log1p()`, `Math.expm1()`, `Math.cosh()`, `Math.sinh()`, `Math.tanh()`, `Math.acosh()`, `Math.asinh()`, `Math.atanh()`, `Math.trunc()`, `Math.sign()` and `Math.cbrt()` ([Firefox bug 717379](https://bugzil.la/717379 "External link (opens in new tab)")).
*   Support for binary and octal integer literals has been added: `0b10101010`, `0B1010`, `0o777`, `0O237` are now valid ([Firefox bug 894026](https://bugzil.la/894026 "External link (opens in new tab)")).
*   The machine epsilon constant, that is the smallest representable number that, when added to 1, does not equal 1, is now available as [`Number.EPSILON`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/EPSILON) ([Firefox bug 885798](https://bugzil.la/885798 "External link (opens in new tab)")).
*   [Typed arrays](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray) have been updated to [no longer search in the prototype chain for indexed properties](/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray#property_access) ([Firefox bug 829896](https://bugzil.la/829896 "External link (opens in new tab)")).

### [Interfaces/APIs/DOM](#interfacesapisdom)

*   The [Web Audio API](/en-US/docs/Web/API/Web_Audio_API) is now supported. An incomplete implementation was previously available behind a preference ([Firefox bug 779297](https://bugzil.la/779297 "External link (opens in new tab)")).
*   Some IME-related keys on Windows are supported by `KeyboardEvent.key` ([Firefox bug 865565](https://bugzil.la/865565 "External link (opens in new tab)")), see [the key name table](/en-US/docs/Web/API/UI_Events/Keyboard_event_key_values) for details.
*   Firefox for Metro now dispatches key events in the same way as the desktop version ([Firefox bug 843236](https://bugzil.la/843236 "External link (opens in new tab)")).
*   `keypress` event is no longer dispatched if `preventDefault()` of preceding `keydown` event is called ([Firefox bug 501496](https://bugzil.la/501496 "External link (opens in new tab)")).
*   Renamed the `Future` interface to `Promise` ([Firefox bug 884279](https://bugzil.la/884279 "External link (opens in new tab)")).
*   The `srcDoc` property on the [`HTMLIFrameElement`](/en-US/docs/Web/API/HTMLIFrameElement) interface, allowing the inline specification of the content of an [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe), is now supported ([Firefox bug 802895](https://bugzil.la/802895 "External link (opens in new tab)")).
*   The `createTBody()` method on the [`HTMLTableElement`](/en-US/docs/Web/API/HTMLTableElement) interface, allowing retrieval of its [`<tbody>`](/en-US/docs/Web/HTML/Reference/Elements/tbody), is now supported ([Firefox bug 813034](https://bugzil.la/813034 "External link (opens in new tab)")).
*   The [`Range.collapse()`](/en-US/docs/Web/API/Range/collapse) method `toStart` parameter is now optional and defaults to `false`, as defined in the spec ([Firefox bug 891340](https://bugzil.la/891340 "External link (opens in new tab)")).
*   Support for the `ParentNode` mixin on [`Document`](/en-US/docs/Web/API/Document) and [`DocumentFragment`](/en-US/docs/Web/API/DocumentFragment) has been added ([Firefox bug 895974](https://bugzil.la/895974 "External link (opens in new tab)")).
*   The `previousElementSibling` and `nextElementSibling` have been moved to the `ChildNode` mixin allowing them to be called not only on an [`Element`](/en-US/docs/Web/API/Element) object but also on a [`CharacterData`](/en-US/docs/Web/API/CharacterData) or [`DocumentType`](/en-US/docs/Web/API/DocumentType) object ([Firefox bug 895974](https://bugzil.la/895974 "External link (opens in new tab)")).
*   The `navigator.geolocation` property has been updated to match the spec. It never returns `null`. When the preference `geo.enabled` is set to `false`, it now returns `undefined` ([Firefox bug 884921](https://bugzil.la/884921 "External link (opens in new tab)")).
*   The `videoPlaybackQuality` attribute on the [`HTMLVideoElement`](/en-US/docs/Web/API/HTMLVideoElement) interface has been changed to the `getVideoPlaybackQuality` method. ([Firefox bug 889205](https://bugzil.la/889205 "External link (opens in new tab)"))
*   The non-standard `GlobalObjectConstructor` interface has been removed ([Firefox bug 898136](https://bugzil.la/898136 "External link (opens in new tab)")). This interface was used to add arguments to the constructors of APIs that Firefox [add-ons](/en-US/docs/Mozilla/Add-ons) were exposing on the global object. This capability has been removed; note that at this time there's no replacement for this functionality.
