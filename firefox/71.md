# Firefox 71 release notes for developers

This article provides information about the changes in Firefox 71 that will affect developers. Firefox 71 was released on December 3, 2019.

## [Changes for web developers](#changes_for_web_developers)

### [Developer tools](#developer_tools)

[Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html "External link (opens in new tab)"):

*   The Console's [multi-line mode](https://firefox-source-docs.mozilla.org/devtools-user/web_console/the_command_line_interpreter/index.html#multi-line-mode "External link (opens in new tab)") is now available by default.
*   Console configuration options are now combined in a new [toolbar settings menu](https://firefox-source-docs.mozilla.org/devtools-user/web_console/ui_tour/index.html#toolbar "External link (opens in new tab)") ([Firefox bug 1523868](https://bugzil.la/1523868 "External link (opens in new tab)")).

[JavaScript debugger](https://firefox-source-docs.mozilla.org/devtools-user/debugger/index.html "External link (opens in new tab)"):

*   [Inline variable preview](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/set_a_breakpoint/index.html#inline-variable-preview "External link (opens in new tab)") has been enabled ([Firefox bug 1576679](https://bugzil.la/1576679 "External link (opens in new tab)")).
*   [Logging on events](https://firefox-source-docs.mozilla.org/devtools-user/debugger/set_event_listener_breakpoints/index.html#logging-on-events "External link (opens in new tab)") is now available ([Firefox bug 1110276](https://bugzil.la/1110276 "External link (opens in new tab)")), as is the ability to [filter by event type](https://firefox-source-docs.mozilla.org/devtools-user/debugger/set_event_listener_breakpoints/index.html#filter-by-event-type "External link (opens in new tab)").
*   The new debugger [paused overlay](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/step_through_code/index.html#pause-on-breakpoints-overlay "External link (opens in new tab)") can now be disabled using the `devtools.debugger.features.overlay` pref ([Firefox bug 1579768](https://bugzil.la/1579768 "External link (opens in new tab)")).
*   We've got new [keyboard shortcuts](https://firefox-source-docs.mozilla.org/devtools-user/keyboard_shortcuts/index.html "External link (opens in new tab)") for opening the debugger: `Ctrl` + `Shift` + `Z` on Linux/Windows and `Cmd` + `Opt` + `Z` on macOS ([Firefox bug 1583042](https://bugzil.la/1583042 "External link (opens in new tab)")).
*   Pausing on a [DOM Mutation Breakpoints](https://firefox-source-docs.mozilla.org/devtools-user/debugger/break_on_dom_mutation/index.html "External link (opens in new tab)") now mentions the DOM node that has the breakpoint and, if available, the child node that was added/removed ([Firefox bug 1576145](https://bugzil.la/1576145 "External link (opens in new tab)")).
*   Locations in [pretty printed sources](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/pretty-print_a_minified_file/index.html "External link (opens in new tab)") are now correct after pretty-printing and when jumping to the source from the Inspector's [events listener tooltip](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_event_listeners/index.html "External link (opens in new tab)") ([Firefox bug 1500222](https://bugzil.la/1500222 "External link (opens in new tab)")).

[Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/index.html "External link (opens in new tab)"):

*   The [Web sockets inspector](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/inspecting_web_sockets/index.html "External link (opens in new tab)") is now enabled by default ([Firefox bug 1573805](https://bugzil.la/1573805 "External link (opens in new tab)")).
*   You can now do a [full-text search](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_list/index.html#search-in-requests "External link (opens in new tab)") of request/response bodies, headers, and cookies.
*   You can now enter patterns to [block specific URLs](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_list/index.html#blocking-specific-urls "External link (opens in new tab)") from loading.
*   The [Timings tab](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_details/index.html#timings "External link (opens in new tab)") now exposes timing data sent in the [`Server-Timing`](/en-US/docs/Web/HTTP/Reference/Headers/Server-Timing) header ([Firefox bug 1403051](https://bugzil.la/1403051 "External link (opens in new tab)")).

[Page Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html "External link (opens in new tab)"):

*   Color swatches are now shown next to CSS variable definitions that have color values ([Firefox bug 1456167](https://bugzil.la/1456167 "External link (opens in new tab)")).
*   [`:visited`](/en-US/docs/Web/CSS/Reference/Selectors/:visited) styles are now shown in the CSS rules view ([Firefox bug 713106](https://bugzil.la/713106 "External link (opens in new tab)")).

### [CSS](#css)

*   Added the [subgrid](/en-US/docs/Web/CSS/Guides/Grid_layout/Subgrid) value from CSS Grid Level 2 to [`grid-template-columns`](/en-US/docs/Web/CSS/Reference/Properties/grid-template-columns) and [`grid-template-rows`](/en-US/docs/Web/CSS/Reference/Properties/grid-template-rows) ([Firefox bug 1580894](https://bugzil.la/1580894 "External link (opens in new tab)"))
*   Added support for the [`column-span`](/en-US/docs/Web/CSS/Reference/Properties/column-span) property to [Multiple-column Layout](/en-US/docs/Web/CSS/Guides/Multicol_layout) ([Firefox bug 1426010](https://bugzil.la/1426010 "External link (opens in new tab)"))
*   Added support for the `path()` value of [`clip-path`](/en-US/docs/Web/CSS/Reference/Properties/clip-path) ([Firefox bug 1488530](https://bugzil.la/1488530 "External link (opens in new tab)"))
*   Mapped the `height` and `width` HTML attributes on the [`<img>`](/en-US/docs/Web/HTML/Reference/Elements/img) element to an internal [`aspect-ratio`](/en-US/docs/Web/CSS/Reference/Properties/aspect-ratio) property ([Firefox bug 1585637](https://bugzil.la/1585637 "External link (opens in new tab)")). [See the guide to this feature on MDN](/en-US/docs/Learn_web_development/Extensions/Performance/Multimedia#rendering_strategy_preventing_jank_when_loading_images).

#### Removals

*   CSS Radial Gradients no longer accept negative radii ([Firefox bug 1583736](https://bugzil.la/1583736 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   The [`Promise.allSettled()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/allSettled) method is now supported ([Firefox bug 1549176](https://bugzil.la/1549176 "External link (opens in new tab)")). This method lets you easily wait until every promise in a set of promises is either fulfilled or rejected before running further code.

#### Removals

*   The non-standard Array generic methods have been removed in Firefox 71 ([Firefox bug 1222547](https://bugzil.la/1222547 "External link (opens in new tab)")). They were first introduced in Firefox 1.5 and deprecated from Firefox 68 onwards. If your use case is to use array generics on array-like objects, you can convert your object to a proper array using [`Array.from()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/from) and then use standard array methods.

### [MathML](#mathml)

*   [MathML elements](/en-US/docs/Web/MathML/Reference/Element) now implement a MathML DOM and their class is [`MathMLElement`](/en-US/docs/Web/API/MathMLElement). With a proper MathML DOM, you can now use `mathmlEl.style`, or global event handlers, for example. Prior to this change, MathML elements only implemented the [`Element`](/en-US/docs/Web/API/Element) class ([Firefox bug 1571487](https://bugzil.la/1571487 "External link (opens in new tab)")).

### [APIs](#apis)

#### New APIs

The [Media Session API](/en-US/docs/Web/API/Media_Session_API) is now partially implemented. This API provides a standard mechanism for your content to share with the underlying operating system information about the state of media it's playing. This includes metadata such as artist, album, and track name, as well as potentially album artwork ([Firefox bug 1580602](https://bugzil.la/1580602 "External link (opens in new tab)")).

The API also provides a way to receive notifications when the device's media controls (such as play, pause, and seek buttons) are activated by the user. To that end, the [`MediaSession`](/en-US/docs/Web/API/MediaSession) interface is now partially implemented, with support for setting and fetching the currently-playing media's metadata and for the [`setActionHandler()`](/en-US/docs/Web/API/MediaSession/setActionHandler "setActionHandler()") method. To access the `MediaSession` API, use the [`navigator.mediaSession`](/en-US/docs/Web/API/Navigator/mediaSession) property.

#### DOM

*   The [`StaticRange()`](/en-US/docs/Web/API/StaticRange/StaticRange "StaticRange()") constructor is now supported ([Firefox bug 1575980](https://bugzil.la/1575980 "External link (opens in new tab)")).
*   The MathML [`MathMLElement`](/en-US/docs/Web/API/MathMLElement) interface has been implemented ([Firefox bug 1571487](https://bugzil.la/1571487 "External link (opens in new tab)")).

#### Media, Web Audio, and WebRTC

*   The [`MediaRecorder`](/en-US/docs/Web/API/MediaRecorder) interface now implements the [`audioBitsPerSecond`](/en-US/docs/Web/API/MediaRecorder/audioBitsPerSecond "audioBitsPerSecond") and [`videoBitsPerSecond`](/en-US/docs/Web/API/MediaRecorder/videoBitsPerSecond "videoBitsPerSecond") properties ([Firefox bug 1514158](https://bugzil.la/1514158 "External link (opens in new tab)")).

#### Canvas and WebGL

*   The [`OVR_multiview2`](/en-US/docs/Web/API/OVR_multiview2) and [`OES_fbo_render_mipmap`](/en-US/docs/Web/API/OES_fbo_render_mipmap) WebGL extensions are now exposed by default ([Firefox bug 1584277](https://bugzil.la/1584277 "External link (opens in new tab)"), [Firefox bug 1583878](https://bugzil.la/1583878 "External link (opens in new tab)")).

#### Removals

The following non-standard [`DataTransfer`](/en-US/docs/Web/API/DataTransfer) members have been removed ([Firefox bug 1345192](https://bugzil.la/1345192 "External link (opens in new tab)")):

*   `DataTransfer.mozItemCount`
*   `DataTransfer.mozClearDataAt()`
*   `DataTransfer.mozGetDataAt()`
*   `DataTransfer.mozSetDataAt()`
*   `DataTransfer.mozTypesAt()`

### [WebDriver conformance (Marionette)](#webdriver_conformance_marionette)

*   Both the `WebDriver:TakeScreenshot` and `WebDriver:TakeElementScreenshot` commands have been updated to respect the unhandled prompt behavior setting ([Firefox bug 1584927](https://bugzil.la/1584927 "External link (opens in new tab)")).
*   The command `Marionette:Quit` has been updated to also allow quitting or restarting of other Gecko-driven applications besides Firefox ([Firefox bug 1298921](https://bugzil.la/1298921 "External link (opens in new tab)")).
*   For GeckoView-based browsers on Android, the returned `browserName` in the session capabilities will now always be `firefox` ([Firefox bug 1587364](https://bugzil.la/1587364 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

### [API changes](#api_changes)

*   [`downloads.download`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/download) now identifies and reports as errors the following HTTP response codes:
    
    *   404 returning `SERVER_BAD_CONTENT`
    *   403 returning `SERVER_FORBIDDEN`
    *   402 and Proxy 407 returning `SERVER_UNAUTHORIZED`
    *   Anything else above 400 returning `SERVER_FAILED` ([Firefox bug 1576333](https://bugzil.la/1576333 "External link (opens in new tab)"))
*   [`downloads.download`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/download) now includes the optional `options` parameter property `allowHttpErrors`. When set to `true`, this `boolean` flag enables a download to continue after encountering an HTTP error. When set to `false`, a download is canceled when an HTTP error is encountered. Default value: `false`. ([Firefox bug 1578955](https://bugzil.la/1578955 "External link (opens in new tab)"))
    

#### Removals

*   The [`proxy.register()`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/proxy) and [`proxy.unregister()`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/proxy) functions have been removed ([Firefox bug 1443259](https://bugzil.la/1443259 "External link (opens in new tab)")). [`proxy.onRequest`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/proxy/onRequest) should now be used to handle the proxying of requests.
