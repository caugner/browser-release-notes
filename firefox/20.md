# Firefox 20 release notes for developers

Firefox 20 was released on April, 2nd 2013. This article provides information about the changes in this release that will affect developers.

## [Changes for web developers](#changes_for_web_developers)

### [HTML](#html)

*   Support for the [`download`](/en-US/docs/Web/HTML/Reference/Elements/a#download) attribute on the [`<a>`](/en-US/docs/Web/HTML/Reference/Elements/a) and [`<area>`](/en-US/docs/Web/HTML/Reference/Elements/area) element has been added ([Firefox bug 676619](https://bugzil.la/676619 "External link (opens in new tab)")).
*   The value `auto` for the [global attribute](/en-US/docs/Web/HTML/Reference/Global_attributes) [`dir`](/en-US/docs/Web/HTML/Reference/Global_attributes/dir) has been implemented ([Firefox bug 548206](https://bugzil.la/548206 "External link (opens in new tab)")).
*   The [global attribute](/en-US/docs/Web/HTML/Reference/Global_attributes) `contextmenu` now works on Firefox for Android ([Firefox bug 736321](https://bugzil.la/736321 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   Support for the `WeakMap.prototype.clear()` method, recently added to the Harmony (ECMAScript 2015) draft proposal has been added ([Firefox bug 814562](https://bugzil.la/814562 "External link (opens in new tab)")).
*   Support for the [`Math.imul()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/imul) method, a C-style 32-bit multiplication function. Though proposed for Harmony (ECMAScript 2015) it has not yet been accepted and still is non-standard ([Firefox bug 808148](https://bugzil.la/808148 "External link (opens in new tab)")).
*   Web apps using draggable text with Kinetic 3.x are working, even when using the Cairo canvas backend ([Firefox bug 835064](https://bugzil.la/835064 "External link (opens in new tab)")).
*   The [`for each...in`](/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#statements_2) statement has been deprecated and should not be used. Consider using the new [`for...of`](/en-US/docs/Web/JavaScript/Reference/Statements/for...of) statement ([Firefox bug 804834](https://bugzil.la/804834 "External link (opens in new tab)")).
*   Support for the [`Map.prototype.keys()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/keys), [`Map.prototype.values()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/values), and [`Map.prototype.entries()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/entries) has been added ([Firefox bug 817368](https://bugzil.la/817368 "External link (opens in new tab)")).

### [CSS](#css)

*   [CSS Flexbox](/en-US/docs/Web/CSS/Guides/Flexible_box_layout/Basic_concepts) is now available by default in pre-release builds only (excluding beta versions). It can be enabled in release and beta versions by setting the `layout.css.flexbox.enabled` about:config preference to `true`.
*   The [`mask-type`](/en-US/docs/Web/CSS/Reference/Properties/mask-type) property has been added ([Firefox bug 793617](https://bugzil.la/793617 "External link (opens in new tab)")).
*   Experimental support for the [`:scope`](/en-US/docs/Web/CSS/Reference/Selectors/:scope) pseudo-class has been added. Enabled by default in Aurora and Nightly, it can be enabled in release and beta versions by setting the `layout.css.scope-pseudo.enabled` about:config preference to `true` ([Firefox bug 648722](https://bugzil.la/648722 "External link (opens in new tab)")).

### [DOM/APIs](#domapis)

*   [`HTMLMediaElement`](/en-US/docs/Web/API/HTMLMediaElement) supports now `playbackRate` (both read and write), with pitch correction. Pitch correction can be controlled using the property `mozPreservesPitch` ([Firefox bug 495040](https://bugzil.la/495040 "External link (opens in new tab)")).
*   CSSOM: Support for the new [`CSSGroupingRule`](/en-US/docs/Web/API/CSSGroupingRule) and [`CSSConditionRule`](/en-US/docs/Web/API/CSSConditionRule) has been added ([Firefox bug 814907](https://bugzil.la/814907 "External link (opens in new tab)")).
*   CSSOM: On [`CSSRule`](/en-US/docs/Web/API/CSSRule) the constant CSSRule.MOZ\_KEYFRAME\_RULE and CSSRule.MOZ\_KEYFRAMES\_RULE have been unprefixed to CSSRule.KEYFRAME\_RULE and CSSRule.KEYFRAMES\_RULE. The prefixed version is temporarily kept for helping Web author to transition their code ([Firefox bug 816431](https://bugzil.la/816431 "External link (opens in new tab)")).
*   CSSOM: It is now possible to set the value of `conditionText` for [`CSSMediaRule`](/en-US/docs/Web/API/CSSMediaRule) ([Firefox bug 815021](https://bugzil.la/815021 "External link (opens in new tab)")).
*   The [`DOMParser`](/en-US/docs/Web/API/DOMParser) `parseFromStream` and `parseFromBuffer` methods are no longer available from web content ([Firefox bug 816410](https://bugzil.la/816410 "External link (opens in new tab)")).
*   The [`XMLSerializer`](/en-US/docs/Web/API/XMLSerializer) `serializeToStream` method is no longer available from web content ([Firefox bug 816410](https://bugzil.la/816410 "External link (opens in new tab)")).
*   [`TextDecoder`](/en-US/docs/Web/API/TextDecoder) and [`TextEncoder`](/en-US/docs/Web/API/TextEncoder) interfaces are now available in Workers ([Firefox bug 795542](https://bugzil.la/795542 "External link (opens in new tab)")).
*   Support for the `CSS.supports()` method has been added, behind the `layout.css.supports-rule.enabled` pref (off by default) ([Firefox bug 779917](https://bugzil.la/779917 "External link (opens in new tab)")).
*   Support for UndoManager has been added ([Firefox bug 617532](https://bugzil.la/617532 "External link (opens in new tab)")).
*   The CSSOM [`Document.caretPositionFromPoint()`](/en-US/docs/Web/API/Document/caretPositionFromPoint) method, which returns a [`CaretPosition`](/en-US/docs/Web/API/CaretPosition) has been implemented.
*   The index argument of the [`HTMLTableRowElement.insertCell()`](/en-US/docs/Web/API/HTMLTableRowElement/insertCell) and [`HTMLTableElement.insertRow()`](/en-US/docs/Web/API/HTMLTableElement/insertRow) methods has been made optional as per HTML specification.
*   [`Navigator.getUserMedia`](/en-US/docs/Web/API/Navigator/getUserMedia), still prefixed as `Navigator.mozGetUserMedia` is now activated by default.
*   The third, optional, `transfer` argument of [`Window.postMessage`](/en-US/docs/Web/API/Window/postMessage) is now supported. It allows you to transfer a sequence of [transferable objects](/en-US/docs/Web/API/Web_Workers_API/Transferable_objects) to the destination ([Firefox bug 822094](https://bugzil.la/822094 "External link (opens in new tab)")).
*   The non-standard [`Window.sizeToContent()`](/en-US/docs/Web/API/Window/sizeToContent) method now clamps the minimal size: the window cannot be forced anymore to small sizes preventing the user from interacting with ([Firefox bug 764240](https://bugzil.la/764240 "External link (opens in new tab)")).
*   Blend modes, such as `overlay`, `color-burn`, `hue`, etc. have been added to the Canvas [`CanvasRenderingContext2D.globalCompositeOperation`](/en-US/docs/Web/API/CanvasRenderingContext2D/globalCompositeOperation) property ([Firefox bug 748433](https://bugzil.la/748433 "External link (opens in new tab)")).
*   The prefixed version of [`window.indexedDB`](/en-US/docs/Web/API/Window/indexedDB) — `window.mozIndexedDB` — was reintroduced to Gecko, so that bad cross-browser prefixing code (such as `var indexedDB = window.indexedDB || window.webkitIndexedDB …`) doesn't break in Firefox. A better approach is `window.indexedDB = window.indexedDB || window.webkitIndexedDB …` (see [Firefox bug 770844](https://bugzil.la/770844 "External link (opens in new tab)").)

### [SVG](#svg)

*   The implementation of the `contentScriptType` and `contentStyleType` properties has been removed from [`SVGSVGElement`](/en-US/docs/Web/API/SVGSVGElement) along with the removal from SVG2 ([Firefox bug 819731](https://bugzil.la/819731 "External link (opens in new tab)")).

### [MathML](#mathml)

*   To help MathML authors debugging "invalid-markup" errors in their documents, MathML parsing errors (such as having too many / too few child elements) and warnings about deprecated attributes or wrong attribute values are now reported to the error console.
*   The `scriptminsize` attribute now accepts unitless values and percent values. They are interpreted as multiples of the default value (`8pt`).
*   Unitless values are now also allowed for the `mathsize` and `fontsize` attributes; they multiply the default value.

## [Changes for add-on and Mozilla developers](#changes_for_add-on_and_mozilla_developers)

*   ECMAScript for XML (E4X) is now fully disabled for all chrome and content scripts. It was previously disabled for content in Firefox 17 and has been removed entirely for Firefox 21. Use DOMParser/DOMSerializer or a non-native JXON algorithm instead.
*   The `nsIDOMParserJS` interface no longer exists ([Firefox bug 816410](https://bugzil.la/816410 "External link (opens in new tab)")). See `nsIDOMParser` for alternatives.
*   Content Preferences: The `nsIContentPrefService` interface is now deprecated and the asynchronous `nsIContentPrefService2` storage API has been implemented.
*   The `nsIProfile` and `nsIProfileChangeStatus` interfaces have been removed, along with other code supporting the pre-Firefox profile management system. You probably weren't using these interfaces, but if you were, you should stop doing so. This prevents defunct parts of the profile management system from vetoing the shutdown process.
*   The `nsIEventSource` interface no longer exists ([Firefox bug 819639](https://bugzil.la/819639 "External link (opens in new tab)")).
