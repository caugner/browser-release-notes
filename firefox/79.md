# Firefox 79 release notes for developers

This article provides information about the changes in Firefox 79 that will affect developers. Firefox 79 was released on July 28, 2020.

See also [Firefox 79: The safe return of shared memory, new tooling, and platform updates](https://hacks.mozilla.org/2020/07/firefox-79/ "External link (opens in new tab)") on Mozilla hacks.

## [Changes for web developers](#changes_for_web_developers)

### [Developer Tools](#developer_tools)

#### Console

*   Network messages with response codes in the 400-499 and 500-599 ranges are now considered errors, and are displayed [even if Response or XHR filters are disabled](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#filtering-by-category "External link (opens in new tab)"). ([Firefox bug 1635460](https://bugzil.la/1635460 "External link (opens in new tab)"))
*   Network messages for requests that are blocked (by the browser or an extension) are now styled with a "prohibited" icon in the [Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html "External link (opens in new tab)"). ([Firefox bug 1629875](https://bugzil.la/1629875 "External link (opens in new tab)"))

#### Debugger

*   ["Blackbox" a source file](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/ignoring_sources/index.html "External link (opens in new tab)") is now called "ignore" a source file. ([Firefox bug 1642811](https://bugzil.la/1642811 "External link (opens in new tab)"))
*   Inline preview is now available on [exceptions](https://firefox-source-docs.mozilla.org/devtools-user/debugger/how_to/breaking_on_exceptions/index.html "External link (opens in new tab)"). ([Firefox bug 1581708](https://bugzil.la/1581708 "External link (opens in new tab)"))
*   Items in the Watch Expressions and Scopes sections now have tooltips on hover, showing their values ([Firefox bug 1631545](https://bugzil.la/1631545 "External link (opens in new tab)"))
*   In the [Call Stack section](https://firefox-source-docs.mozilla.org/devtools-user/debugger/ui_tour/index.html#call-stack "External link (opens in new tab)"), there is now a context menu option to **Restart Frame**, to execute the current stack frame from its beginning. ([Firefox bug 1594467](https://bugzil.la/1594467 "External link (opens in new tab)"))

#### Other tools

*   The new [Application panel](https://firefox-source-docs.mozilla.org/devtools-user/application/index.html "External link (opens in new tab)") is now available, which initially provides inspection and debugging support for [service workers](/en-US/docs/Web/API/Service_Worker_API) and [web app manifests](/en-US/docs/Web/Progressive_web_apps/Manifest).
*   The Messages tab of the Network Monitor has been merged with the [Responses tab](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/request_details/index.html#response-tab "External link (opens in new tab)"). ([Firefox bug 1636421](https://bugzil.la/1636421 "External link (opens in new tab)"))
*   The Accessibility Inspector is automatically turned on when you access its tab; you no longer need to explicitly enable it. ([Firefox bug 1602075](https://bugzil.la/1602075 "External link (opens in new tab)"))
*   In [Responsive Design Mode](https://firefox-source-docs.mozilla.org/devtools-user/responsive_design_mode/index.html#controlling-responsive-design-mode "External link (opens in new tab)"), when touch simulation is enabled, mouse-drag events are now interpreted as touch-drag or swipe events. ([Firefox bug 1621781](https://bugzil.la/1621781 "External link (opens in new tab)"))
*   When [remote debugging](https://firefox-source-docs.mozilla.org/devtools-user/about_colon_debugging/index.html#connecting-to-a-remote-device "External link (opens in new tab)"), the URL bar now has **Back** and **Forward** buttons to help with navigation on the remote browser. ([Firefox bug 1639425](https://bugzil.la/1639425 "External link (opens in new tab)"))

### [HTML](#html)

*   The [`<iframe>`](/en-US/docs/Web/HTML/Reference/Elements/iframe) element's `sandbox` attribute now supports the `allow-top-navigation-by-user-activation` token ([Firefox bug 1359867](https://bugzil.la/1359867 "External link (opens in new tab)")).
*   Setting `target="_blank"` on [`<a>`](/en-US/docs/Web/HTML/Reference/Elements/a) and [`<area>`](/en-US/docs/Web/HTML/Reference/Elements/area) elements implicitly provides the same behavior as also setting `rel="noopener"` ([Firefox bug 1522083](https://bugzil.la/1522083 "External link (opens in new tab)")).

### [CSS](#css)

*   External style sheets are now cached per document group ([Firefox bug 1599160](https://bugzil.la/1599160 "External link (opens in new tab)")). Firefox will minimize retrieval and revalidation of cached style sheets when navigating pages on the same origin. A simple reload (for example, `F5`) will not revalidate the cached CSS files. To load current versions of the style sheets, reload the page bypassing the cache (`Cmd`/`Ctrl` + `F5`).

#### Removals

*   The [`prefers-color-scheme`](/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme) media feature's `no-preference` value has been removed from the [media queries spec](https://drafts.csswg.org/mediaqueries-5/#descdef-media-prefers-color-scheme "External link (opens in new tab)"), and from Firefox ([Firefox bug 1643656](https://bugzil.la/1643656 "External link (opens in new tab)")).

### [JavaScript](#javascript)

*   [`SharedArrayBuffer`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/SharedArrayBuffer) has been re-enabled in a post-Spectre-safe manner. It is available to cross-origin isolated sites ([Firefox bug 1619649](https://bugzil.la/1619649 "External link (opens in new tab)")).
    
    *   To cross-origin isolate your site, you need to set the new [`Cross-Origin-Embedder-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Cross-Origin-Embedder-Policy) (COEP) and [`Cross-Origin-Opener-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Cross-Origin-Opener-Policy) (COOP) headers.
*   [`Promise.any()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/any) is now available ([Firefox bug 1599769](https://bugzil.la/1599769 "External link (opens in new tab)")).
    
*   [`WeakRef`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakRef) objects have been implemented ([Firefox bug 1639246](https://bugzil.la/1639246 "External link (opens in new tab)")).
    
*   [Logical assignment operators](https://github.com/tc39/proposal-logical-assignment "External link (opens in new tab)") are now supported ([Firefox bug 1639591](https://bugzil.la/1639591 "External link (opens in new tab)"))
    
    *   [Logical nullish assignment (`??=`)](/en-US/docs/Web/JavaScript/Reference/Operators/Nullish_coalescing_assignment)
    *   [Logical AND assignment (`&&=`)](/en-US/docs/Web/JavaScript/Reference/Operators/Logical_AND_assignment)
    *   [Logical OR assignment (`||=`)](/en-US/docs/Web/JavaScript/Reference/Operators/Logical_OR_assignment)
*   [`Atomics`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Atomics) objects now also work with non-shared memory ([Firefox bug 1630706](https://bugzil.la/1630706 "External link (opens in new tab)")).
    
*   The [`Intl.DateTimeFormat()` constructor](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat) now supports the `dateStyle` and `timeStyle` options ([Firefox bug 1557718](https://bugzil.la/1557718 "External link (opens in new tab)")).
    
*   The [`Intl.NumberFormat()` constructor](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat) now supports more numbering systems ([Firefox bug 1413504](https://bugzil.la/1413504 "External link (opens in new tab)")).
    

### [HTTP](#http)

*   Cross-origin isolation has been implemented using the new [`Cross-Origin-Embedder-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Cross-Origin-Embedder-Policy) (COEP) and [`Cross-Origin-Opener-Policy`](/en-US/docs/Web/HTTP/Reference/Headers/Cross-Origin-Opener-Policy) (COOP) headers. This allows you to access certain features such as [`SharedArrayBuffer`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/SharedArrayBuffer) objects and unthrottled timers in [`Performance.now()`](/en-US/docs/Web/API/Performance/now).

### [APIs](#apis)

#### DOM

*   The [`FileReader`](/en-US/docs/Web/API/FileReader) interface's [`loadstart` event](/en-US/docs/Web/API/FileReader/loadstart_event) is now dispatched asynchronously, as per the spec ([Firefox bug 1502403](https://bugzil.la/1502403 "External link (opens in new tab)")).
*   [`CanvasPattern.setTransform()`](/en-US/docs/Web/API/CanvasPattern/setTransform) now supports a [`DOMMatrix`](/en-US/docs/Web/API/DOMMatrix) object as an input parameter, as well as an `SVGMatrix` object ([Firefox bug 1565997](https://bugzil.la/1565997 "External link (opens in new tab)")).

#### Media, WebRTC, and Web Audio

*   Firefox now supports remote timestamps on statistics records whose [`RTCStats.type`](/en-US/docs/Web/API/RTCStatsReport "RTCStats.type") is `remote-outbound-rtp`. The [`RTCRemoteOutboundRtpStreamStats`](/en-US/docs/Web/API/RTCRemoteOutboundRtpStreamStats) dictionary which is used to provide these statistics now includes the [`remoteTimestamp`](/en-US/docs/Web/API/RTCRemoteOutboundRtpStreamStats/remoteTimestamp "remoteTimestamp") property, which states the timestamp on the remote peer at which the statistics were collected or generated ([Firefox bug 1615191](https://bugzil.la/1615191 "External link (opens in new tab)")).

#### Removals

*   A number of internal Gecko events — including `DOMWindowClose` — which were accidentally exposed to the web, are now internal-only as intended ([Firefox bug 1557407](https://bugzil.la/1557407 "External link (opens in new tab)")).

### [WebAssembly](#webassembly)

*   [WebAssembly Bulk memory operations](/en-US/docs/WebAssembly/Guides/Understanding_the_text_format#bulk_memory_operations) are now shipped ([Firefox bug 1528294](https://bugzil.la/1528294 "External link (opens in new tab)")).
*   [WebAssembly Reference types](/en-US/docs/WebAssembly/Guides/Understanding_the_text_format#reference_types) are now shipped ([Firefox bug 1637884](https://bugzil.la/1637884 "External link (opens in new tab)")).
*   [WebAssembly Threads](/en-US/docs/WebAssembly/Guides/Understanding_the_text_format#webassembly_threads) (Shared memory & Atomics) are now shipped ([Firefox bug 1389458](https://bugzil.la/1389458 "External link (opens in new tab)"), [Firefox bug 1648685](https://bugzil.la/1648685 "External link (opens in new tab)")).

## [Changes for add-on developers](#changes_for_add-on_developers)

*   New API: [`tabs.warmup()`](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/tabs/warmup) ([bug 1402256](https://bugzil.la/1402256 "External link (opens in new tab)"))
*   [Storage quotas are now enforced for the `sync` storage area](/en-US/docs/Mozilla/Add-ons/WebExtensions/API/storage/sync#storage_quotas_for_sync_data) ([bug 1634615](https://bugzil.la/1634615 "External link (opens in new tab)")) ([addons.mozilla.org blog post](https://blog.mozilla.org/addons/2020/07/09/changes-to-storage-sync-in-firefox-79/ "External link (opens in new tab)"))
