# Opera 10.50 Final for Windows Is Out!

This morning, we've released the much anticipated [final version of Opera 10.50](http://www.opera.com/browser/) for Windows — work on Mac and Linux versions is still ongoing, so [stay tuned](http://my.opera.com/desktopteam/blog/).

Over the last couple of weeks, we've gradually lifted the veil on new features and standards support, but here are a couple of highlights:

*   Super-fast JavaScript with **[Carakan](http://my.opera.com/core/blog/2009/12/22/carakan-revisited)**.
*   Our **Vega** graphics engine, which adds support for [CSS3 Backgrounds and Borders](https://dev.opera.com/articles/view/css3-border-background-boxshadow/), [Transitions and 2D Transforms](https://dev.opera.com/articles/view/css3-transitions-and-2d-transforms/) and much more.
*   **HTML5 `<video>`**: Bruce and Patrick have written an [introductory article](https://dev.opera.com/articles/view/introduction-html5-video/) and done a [JavaScripted based captions experiment](https://dev.opera.com/articles/view/accessible-html5-video-with-javascripted-captions/). There's also a superbly detailed article by Simon Pieters, who works in Quality Assurance for HTML5 video and audio at Opera, called [Everything you need to know about HTML5 video and audio](http://my.opera.com/core/blog/2010/03/03/everything-you-need-to-know-about-html5-video-and-audio-2).
*   **Web Storage**: Shwetank's [article on Local and Session storage](https://dev.opera.com/articles/view/web-storage/) was just published today. Web SQL is supported as well — we have an article in the pipeline.
*   **Standalone Opera Widgets**: widgets can now be run as standalone applications with or without native chrome, which means you can effectively build cross-platform apps using Web Standards. If you want to play around with this, have a look at our newly released [eBook Reader](http://widgets.opera.com/widget/15552/), a [Unite Media Player](http://widgets.opera.com/widget/15592/), or Vadim's [SVG-Edit](http://widgets.opera.com/widget/15321/) app. For more info, check out Daniel's [recent Widgets post](http://my.opera.com/ODIN/blog/widgets-updated-with-opera-10-50).
*   An **"Inspect Element"** menu option that allows you to immediately analyze any element on a page. David has posted an overview of all changes in our debugging tools on the [Opera Dragonfly blog](http://my.opera.com/dragonfly/blog/opera-dragonfly-alpha-for-presto-2-5).
*   A **revamped menu structure**: especially note the Developer Tools menu (under Opera → Page), which includes Opera Dragonfly, Source, Page Info and more.
*   **Windows 7 tricks**: Aero Peek, Jump List support and Aero Glass effects.
*   And last but not least, the `@font-face` issues we've had in the [past](http://my.opera.com/ODIN/blog/2010/02/11/opera-10-50-beta-is-out) are now resolved :-)

For those interested, there is a [extensive changelog](http://www.opera.com/docs/changelogs/windows/1050/) available in the Documentation section on the (renewed) Opera site.

If you haven't done so, **grab Opera 10.50 from [our site](http://www.opera.com/browser/)**, and let us know what you think!
