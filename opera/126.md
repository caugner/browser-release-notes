Hello!

The **initial 126 stable update** is now available!

This release is based on **Chromium version 142.0.7444.243**.

### What’s new and fixed

*   Fixed multiple crashes, including issues related to view handling and installing extensions in private windows.
*   Restored missing checkboxes in DevTools and on affected websites.
*   Fixed Speed Dial editing so the existing URL is properly displayed.
*   Resolved an issue where the system theme option incorrectly applied light mode instead of system dark mode.
*   Improved toolbar layout by adjusting spacing around the AI button and other bars.
*   Fixed tab tooltips appearing over tabs and blocking actions like focusing or closing tabs.

For a complete rundown, take a look at the [changelog](http://blogs.opera.com/desktop/changelog-for-126/).

Happy browsing!
