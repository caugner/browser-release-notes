Hi everyone,

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/04/Stable-86-Initial-release-700x394.jpg)

Opera has been updated to version 86, with Chromium 100.0.4896.127. We’ve got quite a few useful changes in this update, so let’s dive right in.

**Categories in Address Bar dropdown**

The Address Bar dropdown now shows results in categories, such as History, Bookmarks and Search. This makes it quick and intuitive to find the result you’re looking for.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/04/Stable-86-Address-bar-dropdown-categories-2-700x394.jpg)

**Snapshot**

A Snapshot shortcut has been added when copying text. Now, when selecting three or more words, a **Snapshot** option will appear in the popup. Clicking it snaps the selected text and surrounding area.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/04/Stable-86-Snapshot-from-text-selection-700x394.jpg)

Additionally, within the Snapshot feature itself, we’ve added a nice **Crop Tool**. This makes it super easy to further crop and refine the image that you’ve already snapped. The new tool is located to the right of the text tool.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/04/Stable-86-Snapshot-crop-1-700x394.jpg)

**[Crypto Wallet in Sidebar](https://blogs.opera.com/crypto/2022/04/opera-desktop-crypto-wallet-upgrade/)**

The Opera Crypto Wallet, previously only available in our Crypto Browser, can now be enabled in your desktop Opera Browser by going to **Settings** and searching for **Crypto Wallet**. This will add a Crypto Wallet icon to your sidebar, in the Features section.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/04/Stable-86-Crypto-wallet-700x394.jpg)

For the rest of the tweaks, fixes and changes in this update, you’re welcome to review the [full Opera 86 changelog](https://blogs.opera.com/desktop/changelog-for-86/). We hope you’ve found this update helpful. Stay tuned for more updates and, as always, happy browsing!
