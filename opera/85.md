Greetings everyone, 

It’s time for an Opera Initial update.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/03/Stable-85-Initial-release-700x394.jpg)

Opera 85 enters the stable stage today, with small but helpful additions. This includes crash fixes for Mac and Linux, text cropping in Snapshot Meme Generator, and Tab Audio Indicator state changing.

Chromium is updated to version 99.0.4844.51.

All changes are available in the [changelog](https://blogs.opera.com/desktop/changelog-for-85/).

Happy browsing!
