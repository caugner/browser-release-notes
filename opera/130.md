Dear Opera Users!

Today we’re introducing **Opera 130** on the stable channel.

## What’s new?

### Chromium update:

*   Opera 130 is based on the Chromium version: **146.0.7680.178**

### Stability and crash fixes:

*   This release includes a number of fixes targeting crashes reported in previous builds, regarding:
    *   Tab interactions and hover previews
    *   UI rendering and view conversions

### User interface improvements:

*   Improved **settings design and descriptions**
*   Fixes for **Easy Setup UI**, including layout gaps and visual inconsistencies
*   Better positioning of the **download popup in Split Screen mode**
*   Fixes for **tab island controls**, including the “+” button behavior
*   Corrections to **miniplayer text layout**
*   Improved visibility of the cursor in **History search (dark mode)**
*   Fixes for **extension notification popup visuals**

### Sidebar and integrations:

*   Updated **messenger landing page URL**
*   Early Bird users can now access:
    *   Threads in the sidebar
    *   Twitch in the sidebar

### Fixes for browsing and features:

*   Fixed **YouTube push notifications**
*   Improved behavior during **onboarding and tab import**
*   Addressed issues with **adblock custom lists and UI display**
*   Fixed incorrect **browser icon in task manager**
*   Resolved issues with **downloads, extensions, and new tab behavior on Windows**

For a complete rundown, take a look at the [changelog](http://blogs.opera.com/desktop/changelog-for-130/).

As always, we appreciate your feedback and support.

Happy browsing!
