Hello Opera Fans!

Today we are very pleased to announce the release of a new version of Opera.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/05/Stable-87-700x394.jpg)

It’s based on Chromium version **101.0.4951.64**.

What’s new?

With this release we would like to make Easy Files even easier for your daily routine, so we’re introducing the ability to select multiple files. Easy Files now shows a checkbox when a file is hovered over. Clicking a checkbox makes Easy Files enter Multi-select mode, letting you choose multiple files and upload them all at once.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2022/05/Stable-87-Initial-release-700x394.jpg)

Happy browsing and check the full [changelog](https://blogs.opera.com/desktop/changelog-for-87/) for the full details of this release.
