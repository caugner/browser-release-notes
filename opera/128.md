Hello!

We’re happy to announce the release of **Opera 128 Stable**!

This update includes a **Chromium upgrade to version 144.0.7559.173** and a broad set of **stability and quality fixes**, with a strong focus on Enhanced Split Screen reliability (restoring, workspaces/tab islands interactions, and crash fixes).

## Key highlights:

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2026/02/image-3-1.jpg)

**Enhanced Split Screen**

Enhanced Split Screen has graduated from Early Bird and is now fully available to all users. This revamp introduces significant updates to split screen including:

*   **Support of up to 4 tabs:** Split screen supports up to four active tabs simultaneously within a single Split Screen instance instead of only 2.
*   **Customisable layout:** In addition to the standard vertical side-by-side view, users can now create a horizontal layout or a grid layout when handling three or four tabs. It is still  fully resizable via draggable separators across all layouts.
*   **Unified address bar:** To reduce visual overhead and clutter. Experience has been consolidated to feature a single address bar. Active web domains appear as domain chips on the address bar.  Users can interact with these domain chips to expand the full URL, rearrange, or remove a tab from split screen.
*   **State & Workspace Logic:** Alongside the rollout, this update improves Split Screen behavior in everyday scenarios such as restoring from Recently Closed, working across workspaces, and handling edge cases that previously caused crashes.

![](https://www-static-blogs.operacdn.com/desktop/wp-content/uploads/sites/3/2026/02/image-4-1.jpg)

**Sharing Point in Early Bird**

You can now easily share opera with friends and family. Sharing Point is now enabled in the Early Bird. Click the share (gift) icon on the bottom left of the sidebar to easily share a link and a customisable message to download Opera.

**Stability improvements**

Several crash fixes across sync, Split Screen, sidebar overlay, and some page/video-related areas.

**Known issues:**

*   The Recently Closed menu may generate a duplicate entry after closing a Split Screen in a second window. We’re working on a fix.

For a complete rundown, take a look at the [changelog](http://blogs.opera.com/desktop/changelog-for-128/).

Happy browsing!

**Update 2/27/2026: Distribution of the latest version on hold due to issues**

We would like to inform you that due to some issues, we are temporarily suspending the distribution of the latest version of the Opera browser. Our team is currently working to resolve the errors, and we will notify you as soon as the updated version is available.

Thank you for your understanding and patience.
