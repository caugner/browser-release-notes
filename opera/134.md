Hi, Dear Opera Users!

We’ve rolled out a new Opera Stable release built on Chromium 150, plus a broad round of polish and stability fixes.

**Key highlights**

*   Updated to Chromium 150.0.7871.212.
*   Vertical Tabs are now available for everyone, including the new pinned tab grid layout.
*   Google Lens image search from the Start Page is now available for everyone. You can search using a URL, an uploaded file, or a pasted image, and the Start Page search now uses the refreshed Google icon.
*   Refreshed Google service icons across the sidebar, sidebar setup, and Speed Dials.
*   A round of Split Screen fixes, including a crash, an icon-centring bug, and tabs being incorrectly marked as pinned or active after certain actions.
*   Tab reliability improvements: fixed crashes in the tab cycler and when reloading multiple selected tabs, plus fixes for the Google Meet recording indicator.
*   Themes no longer freeze when the browser window loses focus, and the theme gallery now adapts to the monitor size.
*   Fixes for pop-out and fullscreen behaviour on Windows and Mac
*   Various smaller fixes across DevTools, Bookmarks, Browser Connector, Settings, Easy Setup, Speed Dial, and the SoundCloud player icon in Dark Theme.
*   Fixed MV2 extensions being blocked on each browser startup and a crash when using a custom search engine.

If you haven’t yet, be sure to check out our dedicated posts on Vertical Tabs and Google Lens, they walk through everything the new features have to offer: \[[Vertical Tabs and an Upgraded Google Lens land in Opera One](https://blogs.opera.com/desktop/2026/07/vertical-tabs-upgraded-google-lens/)\] and \[[How Vertical Tabs work in Opera One](https://blogs.opera.com/desktop/2026/07/how-vertical-tabs-work-in-opera-one/)\].

**Known issue:** We’re aware of the crash that happens when using snapshot tool. We’re working on a fix and hope to have it resolved soon.

You can find the full list in the [changelog](http://blogs.opera.com/desktop/changelog-for-134/).

Happy browsing!
