## 在 Android 裝置上選擇不使用自動深色主題

在 Chrome 96 中，我們開始進行 [Android 上的自動深色主題](https://developer.chrome.com/blog/auto-dark-theme/?hl=zh-tw)來源試用。

有了這項功能，如果您的網站採用淺色主題，且使用者的作業系統處於深色模式，瀏覽器就會將自動產生的深色主題套用至您的網站。

如果您已註冊來源試用版，且想為特定網頁停用自動產生的深色主題，可以使用中繼標記。

```
<meta name="color-scheme" content="only light">
```

或者，您也可以在 `:root` 元素上設定 `color-scheme: only light`，選擇不參與。

```
:root {
  color-scheme: only light;
}
```

不過，這個方法的主要優點是，您可以為每個元素套用特定樣式，藉此選擇不套用。

```
.only-light,
#my-element {
  color-scheme: only light;
}
```

如需完整詳細資料，請參閱「[Android 的自動深色主題](https://developer.chrome.com/blog/auto-dark-theme/?hl=zh-tw)」中的「[如何選擇停用自動深色主題](https://developer.chrome.com/blog/auto-dark-theme/?hl=zh-tw#per-element-opt-out)」一節。

## COLRv1 字型支援

Chrome 98 現已[支援 COLRv1](https://developer.chrome.com/blog/colrv1-fonts/?hl=zh-tw)，這是 COLRv0 字型格式的進階版本。它會新增漸層、合成和混合功能，並改善形狀重用功能，讓字型檔案更清晰、精簡且壓縮效果更好。

使用彩色字型，可讓醒目顯示、標題和橫幅更加醒目。

![使用 COLRv1 字型的廣告標題](https://developer.chrome.com/static/blog/new-in-chrome-98/image/headline-using-colrv1-fon-b74153836c423.png?hl=zh-tw)

我最喜歡的 COLRv1 用途之一，就是在所有平台上顯示一致的表情符號。您不需要將表情符號替換為圖片檔，因為字型檔案會變小，更容易納入網頁。

![使用一致表情符號的字型檔案](https://developer.chrome.com/static/blog/new-in-chrome-98/image/font-file-using-consisten-c776281289132.png?hl=zh-tw)

我們正在努力改善功能偵測方式，因為這項功能的偵測方式還不夠簡單。但這仍是需要留意的項目。

請參閱 [Chrome 98 中的 COLRv1 彩色漸層向量字型](https://developer.chrome.com/blog/colrv1-fonts/?hl=zh-tw)，進一步瞭解相關細節，以及如何自行建立字型。

## 在使用者代理程式字串中模擬 Chrome 100

幾個月後，Chrome 將推出第 100 版，也就是**三位數**版本號碼。請檢查所有檢查版本號碼或剖析 UA 字串的程式碼，確保這些程式碼可處理三位數。

有一個名為 [`#force-major-version-to-100`](https://developer.chrome.com/blog/force-major-version-to-100/?hl=zh-tw) 的標記，會將目前的版本號碼變更為 100，讓您確保一切運作正常。

![Chrome 旗標頁面，強調新的 #force-major-version-to-100 選項](https://developer.chrome.com/static/blog/new-in-chrome-98/image/chrome-flags-page-highlig-52fc224ae88a4.png?hl=zh-tw)

## 還有其他眾多資源！

當然，還有更多功能。

[CORS 預檢要求](https://chromestatus.com/feature/5737414355058688)現在會在私人網路要求子資源之前傳送，要求目標伺服器提供明確的權限。

[Region Capture](https://developer.chrome.com/origintrials/?hl=zh-tw#/view_trial/2257429313219461121) 是用於裁剪自拍影片音軌的 API，現在推出新的來源試用版。在視訊會議應用程式中分享螢幕畫面時，這項功能非常實用，可避免產生鏡廳效果！

我們原先計劃在 Chrome 98 中加入視窗重疊控制項，但由於在最後一刻發現問題，因此未能加入。我們仍在進行相關作業，預計在接下來幾個版本中推出。
