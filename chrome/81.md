## Pengujian hit WebXR

![](https://developer.chrome.com/static/blog/new-in-chrome-81/image/ZQU1XkZB415LOjJZ11L4.jpg?hl=id) %}

Ada beberapa aplikasi native yang memungkinkan Anda melihat tampilan sofa atau kursi baru di rumah Anda. Dengan update pada Web XR Device API, kini Anda juga dapat melakukannya di web.

Dengan Web XR Hit Test API, Anda dapat menempatkan objek virtual ke dalam tampilan kamera dari dunia nyata.

Lihat [Contoh Hit Testing](https://immersive-web.github.io/webxr-samples/hit-test.html) ([kode](https://github.com/immersive-web/webxr-samples/blob/master/hit-test.html)) dari Immersive Web Working Group tempat Anda dapat menempatkan bunga matahari virtual di permukaan di dunia nyata, atau [Memposisikan objek virtual dalam tampilan dunia nyata](https://web.dev/ar-hit-test/?hl=id) untuk mengetahui detail selengkapnya.

  

## Badge ikon aplikasi

Badge ikon aplikasi beralih dari Uji Coba Origin ke stabil, yang berarti Anda kini dapat menggunakannya di situs mana pun, tanpa token.

![](https://developer.chrome.com/static/blog/new-in-chrome-81/image/OYVASlDc4gtR75yunTHh.jpg?hl=id)

Badge ikon aplikasi memudahkan untuk memberi tahu pengguna secara halus bahwa ada beberapa aktivitas baru yang mungkin memerlukan perhatian mereka, atau untuk menunjukkan jumlah informasi yang kecil, seperti jumlah yang belum dibaca.

Lebih mudah digunakan daripada notifikasi. Selain itu, karena tidak mengganggu pengguna, data ini dapat diperbarui dengan frekuensi yang jauh lebih tinggi. Ini sangat cocok untuk aplikasi chat atau email untuk menunjukkan jumlah pesan yang belum dibaca. Aplikasi media sosial dapat menggunakannya untuk menunjukkan frekuensi Anda diberi tag di postingan orang lain. Atau untuk game, untuk menunjukkan kepada pengguna bahwa giliran mereka.

Baca artikel [Badging API](https://web.dev/badging-api/?hl=id) saya di web.dev untuk mengetahui detail selengkapnya.

## Uji coba origin baru

### NFC Web

[NFC Web memulai uji coba origin](https://developer.chrome.com/origintrials?hl=id#/view_trial/236438980436951041) di Chrome 81. NFC web memungkinkan aplikasi web membaca dan menulis ke tag NFC. Hal ini membuka kasus penggunaan baru, termasuk memberikan detail selengkapnya tentang pameran museum, pengelolaan inventaris, membaca informasi dari badge konferensi, dan lainnya.

Sangat mudah digunakan. Untuk membaca tag, buat instance baru objek `NDEFReader`, lalu mulai pemindaian.

```
const reader = new NDEFReader();

async function startScan() {
  await reader.scan();
  reader.onreading = (e) => {
    console.log(e.message);
  };
}
```

Kemudian, saat tag NFC dipindai, pembaca akan memicu peristiwa `reading` yang dapat Anda gunakan untuk melakukan loop pada pesan yang masuk.

Francois memiliki [postingan](https://web.dev/nfc/?hl=id) yang bagus yang membahas semua detail dan menyertakan sejumlah pola umum yang mungkin ingin Anda gunakan.
