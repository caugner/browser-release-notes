## Version 107.0.1418.24: October 27, 2022

Stable channel security updates are listed [here](/en-us/deployedge/microsoft-edge-relnotes-security#october-27-2022).

### Feature updates

*   **Microsoft Edge sidebar.** The Microsoft Edge sidebar lets users access productivity tools side-by-side with their browsing window. For enterprise customers, the following experiences are currently turned on by default: Search, Discover, Office.com, and Outlook. Administrators can control the availability and configure the Microsoft Edge sidebar using the [HubsSidebarEnabled](/en-us/deployedge/microsoft-edge-policies#hubssidebarenabled), [ExtensionInstallBlockList](/en-us/deployedge/microsoft-edge-policies#extensioninstallblocklist), and [ExtensionInstallForceList](/en-us/deployedge/microsoft-edge-policies#extensioninstallforcelist) policies. The extension ID for each sidebar app can be found at _edge://sidebar-internals_. For more information, see [Manage the sidebar in Microsoft Edge](/en-us/DeployEdge/microsoft-edge-sidebar).
    
*   **New policy to give more flexibility in Microsoft Edge startup.** The [RestoreOnStartupUserURLsEnabled](/en-us/deployedge/microsoft-edge-policies#restoreonstartupuserurlsenabled) policy lets users add and remove their own URLs to open when starting Microsoft Edge while maintaining the mandatory list of sites specified by the admin.
    

### Policy updates

#### New policies

*   [EdgeWorkspacesEnabled](/en-us/DeployEdge/microsoft-edge-policies#edgeworkspacesenabled) - Enable Workspaces
*   [EnhanceSecurityModeBypassIntranet](/en-us/DeployEdge/microsoft-edge-policies#enhancesecuritymodebypassintranet) - Enhanced Security Mode configuration for Intranet zone sites
*   [EventPathEnabled](/en-us/DeployEdge/microsoft-edge-policies#eventpathenabled) - Re-enable the Event.path API until Microsoft Edge version 115
*   [InternetExplorerIntegrationLocalMhtFileAllowed](/en-us/DeployEdge/microsoft-edge-policies#internetexplorerintegrationlocalmhtfileallowed) - Allow local MHTML files to open automatically in Internet Explorer mode
*   [LinkedAccountEnabled](/en-us/DeployEdge/microsoft-edge-policies#linkedaccountenabled) - Enable the linked account feature
*   [PerformanceDetectorEnabled](/en-us/DeployEdge/microsoft-edge-policies#performancedetectorenabled) - Performance Detector Enabled
*   [RestoreOnStartupUserURLsEnabled](/en-us/DeployEdge/microsoft-edge-policies#restoreonstartupuserurlsenabled) - Allow users to add and remove their own sites during startup when the RestoreOnStartupURLs policy is configured
*   [DefaultShareAdditionalOSRegionSetting](/en-us/DeployEdge/microsoft-edge-policies#defaultshareadditionalosregionsetting) - Set the default "share additional operating system region" setting
*   [WebSelectEnabled](/en-us/DeployEdge/microsoft-edge-policies#webselectenabled) - Web Select Enabled
*   [WebSQLAccess](/en-us/DeployEdge/microsoft-edge-policies#websqlaccess) - Force WebSQL to be enabled
*   [WebSQLNonSecureContextEnabled](/en-us/DeployEdge/microsoft-edge-policies#websqlnonsecurecontextenabled) - Force WebSQL in non-secure contexts to be enabled

#### Deprecated policy

*   [MicrosoftOfficeMenuEnabled](/en-us/DeployEdge/microsoft-edge-policies#microsoftofficemenuenabled) - Allow users to access the Microsoft Office menu

#### Obsoleted policy

*   [BuiltinCertificateVerifierEnabled](/en-us/DeployEdge/microsoft-edge-policies#builtincertificateverifierenabled) - Determines whether the built-in certificate verifier will be used to verify server certificates
