## Version 101.0.1210.32: April 28

Stable channel security updates are listed [here](/en-us/deployedge/microsoft-edge-relnotes-security#april-28-2022).

### Feature updates

*   **Ability to set the default profile.** The [EdgeDefaultProfileEnabled](/en-us/DeployEdge/microsoft-edge-policies#edgedefaultprofileenabled) policy lets you set a default profile to use when opening the browser instead of the last profile that was used. This policy won't be applicable if the `--profile-directory` parameter has been specified.
    
*   **Launch Progressive Web Apps (PWAs) from the favorites bar.** Improvements to the PWA launch experience starts appearing with an Apps icon that can be added to the toolbar.
    
*   **Manage the "Allow extensions from other stores" setting.** Now you can use the [ControlDefaultStateOfAllowExtensionFromOtherStoresSettingEnabled](/en-us/DeployEdge/microsoft-edge-policies#controldefaultstateofallowextensionfromotherstoressettingenabled) policy to set the default state of the "Allow extensions from other stores" setting.
    
*   **Improvements to the Enterprise Site List Manager.** Now you can configure shared cookies between Microsoft Edge and Internet Explorer on your enterprise site list. You can access the [Enterprise Site List Manager](/en-us/deployedge/edge-ie-mode-site-list-manager) at _edge://compat/SiteListManager_.
    

### Policy updates

#### New policies

*   [ConfigureKeyboardShortcuts](/en-us/DeployEdge/microsoft-edge-policies#configurekeyboardshortcuts) - Configure the list of commands for which to disable keyboard shortcuts
*   [ControlDefaultStateOfAllowExtensionFromOtherStoresSettingEnabled](/en-us/DeployEdge/microsoft-edge-policies#controldefaultstateofallowextensionfromotherstoressettingenabled) - Configure default state of Allow extensions from other stores setting
*   [EdgeAssetDeliveryServiceEnabled](/en-us/DeployEdge/microsoft-edge-policies#edgeassetdeliveryserviceenabled) - Allow features to download assets from the Asset Delivery Service
*   [EdgeDefaultProfileEnabled](/en-us/DeployEdge/microsoft-edge-policies#edgedefaultprofileenabled) - Default Profile Setting Enabled
*   [InternetExplorerModeEnableSavePageAs](/en-us/DeployEdge/microsoft-edge-policies#internetexplorermodeenablesavepageas) - Allow Save page as in Internet Explorer mode
*   [KioskSwipeGesturesEnabled](/en-us/DeployEdge/microsoft-edge-policies#kioskswipegesturesenabled) - Swipe gestures in Microsoft Edge kiosk mode enabled
*   [MicrosoftOfficeMenuEnabled](/en-us/DeployEdge/microsoft-edge-policies#microsoftofficemenuenabled) - Allow users to access the Microsoft Office menu
*   [SiteSafetyServicesEnabled](/en-us/DeployEdge/microsoft-edge-policies#sitesafetyservicesenabled) - Allow users to configure Site safety services

#### Deprecated policies

*   [ForceCertificatePromptsOnMultipleMatches](/en-us/DeployEdge/microsoft-edge-policies#forcecertificatepromptsonmultiplematches) - Configure whether Microsoft Edge should automatically select a certificate when there are multiple certificate matches for a site configured with "AutoSelectCertificateForUrls"

#### Obsoleted policies

*   [WebSQLInThirdPartyContextEnabled](/en-us/DeployEdge/microsoft-edge-policies#websqlinthirdpartycontextenabled) - Force WebSQL in third-party contexts to be re-enabled
